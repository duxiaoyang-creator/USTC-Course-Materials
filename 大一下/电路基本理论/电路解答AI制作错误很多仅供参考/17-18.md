1. 电路如图1-1所示，端口等效电阻 $R_{ab} =$ ___，3Ω电阻消耗的功率为 ___。   

- 

  **解析：** 观察图1-1右侧的电阻网络，节点a和b之间存在交叉连接 。通过节点分析可以看出，12Ω、4Ω、6Ω、3Ω四个电阻实际上是**全并联**在节点a和节点b之间的 。  

  - 等效电阻 $R_{ab} = 12 \parallel 4 \parallel 6 \parallel 3$。
  - 计算得：$12 \parallel 4 = 3\Omega$，$6 \parallel 3 = 2\Omega$，$3 \parallel 2 = 1.2\Omega$。所以 $R_{ab} = 1.2\Omega$。 对于左侧电路，1A的电流源与1V的电压源串联构成一条支路 。根据串联电路特性，该支路向右侧节点a注入的恒定电流即为 1A。  
  - 并联网络两端的电压 $U_{ab} = I \times R_{ab} = 1 \times 1.2 = 1.2\text{V}$。
  - 3Ω电阻消耗的功率 $P = \frac{U_{ab}^2}{R} = \frac{1.2^2}{3} = 0.48\text{W}$。

- **答案：** $1.2\Omega$ ； $0.48\text{W}$

- 电路如图1-2所示，电压源 $U_{S1}$ 和 $U_{S2}$ 始终保持不变，当 $I_S=0$ 时，$I=2\text{A}$。则当 $I_S=8\text{A}$ 时，8A电流源发出的功率为 ___。   

- **解析：** 由叠加定理，支路电流 $I$ 可表示为 $I = I^{(U)} + I^{(I_S)}$。已知当 $I_S = 0$ 时，$I^{(U)} = 2\text{A}$ 。 当仅有 $I_S$ 作用时，将电压源 $U_{S1}$、$U_{S2}$ 置零（短路） 。此时15Ω电阻被短路 ，左侧两个3Ω电阻串联后（共6Ω）与右侧的6Ω电阻并联 。  
  - $I_S$ 电流向上流出，在顶部节点分流，根据分流公式，向下流过6Ω电阻的电流为 $-I_S \times \frac{6}{6+6} = -0.5 I_S$ （因定义的 $I$ 方向向上，故为负）。
  - 当 $I_S = 8\text{A}$ 时，$I = 2 - 0.5 \times 8 = -2\text{A}$。
  - 6Ω电阻两端的电压（上正下负）为 $U = -I \times 6 = -(-2) \times 6 = 12\text{V}$。
  - 该电压即为8A电流源两端的电压，且电流源电流从正端流出，发出功率 $P = U \times I_S = 12 \times 8 = 96\text{W}$。
  
- **答案：** $96\text{W}$

- 电路如图1-3所示，已知电流源有效值相量 $\dot{I}_S = 10\angle 0^\circ\text{A}$，则电压有效值相量 $\dot{U}_1 =$ ___，$\dot{U}_2 =$ ___。

  - 次级负载阻抗 $Z_L = j4 + (-j2 \parallel 2) = j4 + \frac{-j4}{2-j2} = j4 + (1 - j) = 1 + j3 \Omega$ 。  
  - 次级电压 $\dot{U}_2 = \dot{I}_2 \times Z_L = 2 \times (1 + j3) = 2 + j6 \text{ V}$。
  - 初级电压 $\dot{U}_1 = \frac{1}{5} \dot{U}_2 = 0.4 + j1.2 \text{ V}$。

  ### 第 3 题：理想变压器电路

  **1. 求副边负载的等效阻抗 $Z_L$**

  观察副边电路，电容与（电阻+电感）支路是**并联**关系。

  已知各元件阻抗为：电容 $-j2\Omega$，电感 $j4\Omega$，电阻 $2\Omega$。

  负载等效阻抗 $Z_L$ 为：

  $$Z_L = (-j2) \parallel (2 + j4) = \frac{(-j2) \cdot (2 + j4)}{-j2 + (2 + j4)}$$

  $$Z_L = \frac{-j4 - j^2 8}{2 + j2} = \frac{8 - j4}{2 + j2}$$

  分子分母同乘共轭复数 $(2 - j2)$ 进行化简：

  $$Z_L = \frac{(8 - j4)(2 - j2)}{2^2 + 2^2} = \frac{16 - j16 - j8 + j^2 8}{8} = \frac{16 - j24 - 8}{8} = \frac{8 - j24}{8} = 1 - j3 \, \Omega$$

  **2. 求原边电压 $\dot{U}_1$**

  将副边阻抗折算到原边。已知变压器匝数比 $n = N_1 : N_2 = 1 : 5$。

  折算到原边的等效阻抗 $Z_{in}$ 为：

  $$Z_{in} = n^2 Z_L = \left(\frac{1}{5}\right)^2 \cdot (1 - j3) = \frac{1}{25} (1 - j3) = 0.04 - j0.12 \, \Omega$$

  原边电流有效值相量 $\dot{I}_S = 10\angle 0^\circ \text{ A}$。

  根据欧姆定律，原边电压为：

  $$\dot{U}_1 = \dot{I}_S \cdot Z_{in} = 10 \cdot (0.04 - j0.12) = \mathbf{0.4 - j1.2 \, \text{V}}$$

  **3. 求副边电压 $\dot{U}_2$**

  **特别注意图中同名端（带 \* 号的一端）的位置：**

  - 原边的同名端在**上方**（对应 $\dot{U}_1$ 的正极）。

  - 副边的同名端在**下方**（对应 $\dot{U}_2$ 的负极）。

    因为同名端位置相反，所以电压变换关系带有负号：

    $$\frac{\dot{U}_1}{\dot{U}_2} = -\frac{N_1}{N_2} = -\frac{1}{5}$$

    由此可得：

    $$\dot{U}_2 = -5 \dot{U}_1 = -5 \cdot (0.4 - j1.2) = \mathbf{-2 + j6 \, \text{V}}$$

  ### 第 4 题：RLC 串联电路

  **1. 提取已知条件**

  由电压源表达式 $u_S = 10\sqrt{2}\cos(5t + 15^\circ) \text{ V}$ 可知：

  - 电源角频率 $\omega = 5 \text{ rad/s}$
  - 电压有效值相量 $\dot{U}_S = 10\angle 15^\circ \text{ V}$

  **2. 计算各元件阻抗及总阻抗 $Z$**

  - 电阻：$Z_R = R = 8 \, \Omega$

  - 电感：$Z_L = j\omega L = j(5 \times 0.8) = j4 \, \Omega$

  - 电容：$Z_C = \frac{1}{j\omega C} = \frac{1}{j(5 \times 0.02)} = \frac{1}{j0.1} = -j10 \, \Omega$

    由于是串联电路，总等效阻抗为：

    $$Z = Z_R + Z_L + Z_C = 8 + j4 - j10 = 8 - j6 \, \Omega$$

  **3. 求电压源发出的复功率 $\tilde{S}$**

  复功率可以通过公式 $\tilde{S} = \frac{|\dot{U}_S|^2}{Z^*}$ 直接计算（其中 $Z^*$ 为阻抗的共轭复数）：

  $$Z^* = 8 + j6 \, \Omega$$

  $$\tilde{S} = \frac{10^2}{8 + j6} = \frac{100}{8 + j6} = \frac{100(8 - j6)}{8^2 + 6^2} = \frac{100(8 - j6)}{100} = \mathbf{8 - j6 \, \text{VA}}$$

  **4. 求功率因数角 $\varphi$**

  功率因数角 $\varphi$ 等于等效阻抗 $Z$ 的阻抗角：

  $$\varphi = \arctan\left(\frac{X}{R}\right) = \arctan\left(\frac{-6}{8}\right) = \arctan(-0.75)$$

  $$\mathbf{\varphi \approx -36.87^\circ}$$

  *(注：角度为负表示该电路呈容性，电流超前于电压)*

- 电路如图1-4所示，已知 $u_s = 10\sqrt{2}\cos(5t+15^\circ)\text{V}$，则电压源发出的复功率为 ___，RLC串联电路的功率因数角为 ___。   

- **解析：**

  角频率 $\omega = 5\text{ rad/s}$。电压相量 $\dot{U}_S = 10\angle 15^\circ\text{V}$（有效值）。

  - 感抗 $X_L = \omega L = 5 \times 0.8 = 4\Omega$ 。  
  - 容抗 $X_C = \frac{1}{\omega C} = \frac{1}{5 \times 0.02} = 10\Omega$ 。  
  - 总阻抗 $Z = R + j(X_L - X_C) = 8 + j(4 - 10) = 8 - j6 \Omega = 10\angle -36.87^\circ \Omega$ 。  
  - 电流相量 $\dot{I} = \frac{\dot{U}_S}{Z} = \frac{10\angle 15^\circ}{10\angle -36.87^\circ} = 1\angle 51.87^\circ \text{ A}$。
  - 复功率 $\tilde{S} = \dot{U}_S \dot{I}^* = (10\angle 15^\circ) \times (1\angle -51.87^\circ) = 10\angle -36.87^\circ \text{ VA} = 8 - j6 \text{ VA}$。
  - 功率因数角 $\varphi = \varphi_u - \varphi_i = 15^\circ - 51.87^\circ = -36.87^\circ$ （或 $-\arctan(3/4)$）。

- **答案：** $8 - j6 \text{ VA}$ ； $-36.87^\circ$

- 电路如图1-6所示，当 $u_s = \epsilon(t)\text{V}$ 时，单位阶跃响应 $u =$ ___；当 $u_s = \delta(t)\text{V}$ 时，单位冲激响应 $i =$ ___。

  - **阶跃响应 (电压 $u$)**：$u(0^+) = 0$，$u(\infty) = 1\text{V}$。利用三要素法得 $u(t) = (1 - e^{-10t})\epsilon(t)\text{V}$。
  - **冲激响应 (电流 $i$)**：冲激响应是阶跃响应的导数。阶跃电流 $i_{step}(t) = \frac{1}{R}e^{-t/\tau} = 0.1e^{-10t}\epsilon(t)$。求导得单位冲激电流响应 $i(t) = 0.1\delta(t) - e^{-10t}\epsilon(t)\text{A}$。

- 非常好的思路！使用拉普拉斯变换（复频域分析）来求解这类动态电路的阶跃响应和冲激响应，往往比在时域解微分方程更加系统和直观。

  下面为您详细展示如何使用拉普拉斯变换解答**第 6 题**。

  ### 第一步：建立 s 域等效电路模型

  由图 1-6 可知，这是一个由电压源 $u_S$、电阻 $R=10\Omega$ 和电容 $C=0.01\text{F}$ 构成的串联电路。

  在复频域（s 域）中，各元件的阻抗表示为：

  - **电阻阻抗：** $Z_R(s) = R = 10\Omega$
  - **电容阻抗：** $Z_C(s) = \frac{1}{sC} = \frac{1}{0.01s} = \frac{100}{s} \Omega$

  根据串联电路的 KVL（基尔霍夫电压定律）和分压/欧姆定律，我们可以直接写出响应量 $U(s)$ 和 $I(s)$ 与激励量 $U_S(s)$ 之间的关系（即传递函数）：

  1. **电容电压 $U(s)$ 的表达式：**

     $$U(s) = \frac{Z_C(s)}{Z_R(s) + Z_C(s)} U_S(s) = \frac{\frac{100}{s}}{10 + \frac{100}{s}} U_S(s)$$

     上下同乘 $s$ 并化简：

     $$U(s) = \frac{100}{10s + 100} U_S(s) = \mathbf{\frac{10}{s + 10} U_S(s)}$$

  2. **回路电流 $I(s)$ 的表达式：**

     $$I(s) = \frac{U_S(s)}{Z_R(s) + Z_C(s)} = \frac{1}{10 + \frac{100}{s}} U_S(s)$$

     上下同乘 $s$ 并化简：

     $$I(s) = \frac{s}{10s + 100} U_S(s) = \mathbf{\frac{0.1s}{s + 10} U_S(s)}$$

  接下来，我们只需将不同激励的拉普拉斯变换代入上述公式即可求解。

  ### 第二步：求单位阶跃响应 $u$

  当激励为单位阶跃电压 $u_S = \varepsilon(t)\text{V}$ 时，其拉普拉斯变换为：

  $$U_S(s) = \frac{1}{s}$$

  将其代入 $U(s)$ 的表达式中：

  $$U(s) = \frac{10}{s + 10} \cdot \frac{1}{s} = \frac{10}{s(s + 10)}$$

  为了进行拉普拉斯反变换，我们需要使用**部分分式展开**：

  设 $U(s) = \frac{A}{s} + \frac{B}{s + 10}$，

  - $A = \left. \frac{10}{s + 10} \right|_{s=0} = \frac{10}{10} = 1$
  - $B = \left. \frac{10}{s} \right|_{s=-10} = \frac{10}{-10} = -1$

  所以：

  $$U(s) = \frac{1}{s} - \frac{1}{s + 10}$$

  查表进行拉普拉斯反变换，得到时域的单位阶跃响应：

  $$\mathbf{u(t) = (1 - e^{-10t})\varepsilon(t) \text{ V}}$$

  ### 第三步：求单位冲激响应 $i$

  当激励为单位冲激电压 $u_S = \delta(t)\text{V}$ 时，其拉普拉斯变换为：

  $$U_S(s) = 1$$

  将其代入 $I(s)$ 的表达式中：

  $$I(s) = \frac{0.1s}{s + 10} \cdot 1 = \frac{0.1s}{s + 10}$$

  这是一个假分式（分子分母同阶），为了反变换，我们需要将其化为**多项式与真分式之和**。技巧是“凑分母”：

  $$I(s) = 0.1 \cdot \frac{s + 10 - 10}{s + 10} = 0.1 \left( \frac{s + 10}{s + 10} - \frac{10}{s + 10} \right)$$

  $$I(s) = 0.1 \left( 1 - \frac{10}{s + 10} \right) = 0.1 - \frac{1}{s + 10}$$

  对该式进行拉普拉斯反变换（注意 $1$ 的反变换是 $\delta(t)$）：

  $$\mathbf{i(t) = 0.1\delta(t) - e^{-10t}\varepsilon(t) \text{ A}}$$

  *(物理意义提示：在施加电压冲激 $\delta(t)$ 的瞬间，电容相当于短路，因此产生了一个极大的冲激电流 $0.1\delta(t)$；随后冲激电源消失，电容通过电阻放电，产生一个按指数衰减的负向电流。)*

  **最终答案填写：**

  - 单位阶跃响应 $u = \mathbf{(1 - e^{-10t})\varepsilon(t) \text{ V}}$
  - 单位冲激响应 $i = \mathbf{0.1\delta(t) - e^{-10t}\varepsilon(t) \text{ A}}$
