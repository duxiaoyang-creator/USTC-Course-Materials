### 一、填空题

**1. 题目：**

电路如图1-1所示，已知 $I_1=2\text{A}$， $I_2=1\text{A}$。则电阻 $R=$ ______，电压源 $U_s=$ ______。

**解答：**

分析图1-1电路，设 $4\Omega$ 电阻上方的节点为A，下方的参考节点（底边整条导线）电位为 $0\text{V}$。

根据KCL（基尔霍夫电流定律），流入节点A的电流为 $I_1$，流出的电流分为两路，一路经过 $4\Omega$ 电阻到地，另一路为 $I_2$。

因此，流过 $4\Omega$ 电阻的电流为：

$$I_{4\Omega} = I_1 - I_2 = 2\text{A} - 1\text{A} = 1\text{A}$$

节点A的电位 $V_A$ 为：

$$V_A = I_{4\Omega} \times 4\Omega = 1\text{A} \times 4\Omega = 4\text{V}$$

对于包含电压源 $U_s$ 和 $6\Omega$ 电阻的左侧支路，由KVL（基尔霍夫电压定律）可得：

$$U_s - I_1 \times 6\Omega = V_A \Rightarrow U_s = 4\text{V} + 2\text{A} \times 6\Omega = 16\text{V}$$

对于包含电阻 $R$ 和 $2\text{V}$ 电压源的右侧支路，由KVL可得：

$$V_A - I_2 \times R = 2\text{V} \Rightarrow 4\text{V} - 1\text{A} \times R = 2\text{V} \Rightarrow R = 2\Omega$$

**答案：** $2\Omega$ ， $16\text{V}$

**2. 题目：**

电路如图1-2所示，端口等效电感 $L_{eq}=$ ______。

**解答：**

图1-2中包含一个 $9\text{H}$ 的电感和一个 $8\text{H}$ 的电感，互感 $M = 6\text{H}$。

仔细观察拓扑结构可知， $9\text{H}$ 电感的左端和右端被其上方的导线短接。设总电流为 $I$，流过 $9\text{H}$ 电感的电流为 $i_1$，流过 $8\text{H}$ 电感的电流为 $I$。

由于 $9\text{H}$ 电感被短路，其两端电压 $u_1 = 0$。根据同名端位置（ $9\text{H}$ 右侧为星号， $8\text{H}$ 左侧为星号）， $i_1$ 从非同名端流入， $I$ 从同名端流入，故互感项取负号：

$$u_1 = L_1 \frac{di_1}{dt} - M \frac{dI}{dt} = 9 \frac{di_1}{dt} - 6 \frac{dI}{dt} = 0$$

由此解得： $\frac{di_1}{dt} = \frac{2}{3} \frac{dI}{dt}$

端口总电压 $u$ 等于 $8\text{H}$ 电感两端电压 $u_2$：

$$u = u_2 = L_2 \frac{dI}{dt} - M \frac{di_1}{dt} = 8 \frac{dI}{dt} - 6 \left( \frac{2}{3} \frac{dI}{dt} \right) = (8 - 4) \frac{dI}{dt} = 4 \frac{dI}{dt}$$

因此，等效电感 $L_{eq} = 4\text{H}$。

**答案：** $4\text{H}$

**3. 题目：**

电路如图1-3所示，已知电压源振幅相量 $\dot{U}_{mS}=10\angle0^\circ\text{V}$，则电流表A的读数为 ______。

**解答：**

这是一个含理想变压器的相量模型电路。已知变比为 $n = \frac{N_1}{N_2} = \frac{4}{1} = 4$。

由于同名端分别位于原边上方和副边下方，故副边（右侧）反射到原边（左侧）时的阻抗变换公式为：

$$Z_{\text{in}} = n^2 Z_2$$

右侧回路含有 $10\Omega$ 的电阻和电压源。根据理想变压器等效原理，将右侧的 $10\Omega$ 电阻和电压源反射到左侧（电流表所在的一次侧）。

反射后的等效电压源（振幅） $\dot{U}_{mS}' = n \dot{U}_{mS} = 4 \times 10\angle0^\circ = 40\angle0^\circ \text{V}$。

反射后的等效电阻 $R' = n^2 \times 10\Omega = 16 \times 10\Omega = 160\Omega$。

左侧回路原有阻抗为电容 $Z_C = -j10\Omega$。

因此，左侧原边回路的总阻抗模值为：

$$|Z_{\text{total}}| = \sqrt{R'^2 + X_C^2} = \sqrt{160^2 + (-10)^2} = \sqrt{25600 + 100} = \sqrt{25700} = 10\sqrt{257}\Omega$$

左侧回路电流的振幅值为：

$$I_{m1} = \frac{U_{mS}'}{|Z_{\text{total}}|} = \frac{40}{10\sqrt{257}} = \frac{4}{\sqrt{257}} \text{A}$$

交流电流表读数为有效值：

$$I_A = \frac{I_{m1}}{\sqrt{2}} = \frac{4}{\sqrt{2} \times \sqrt{257}} = \frac{2\sqrt{2}}{\sqrt{257}} \text{A} \approx 0.176\text{A}$$

**答案：** $\frac{2\sqrt{2}}{\sqrt{257}}\text{A}$ （或约 $0.176\text{A}$）

**4. 题目：**

电路如图1-4所示，已知 $u_s(t)=10\sqrt{2}\cos(2500t+15^\circ)\text{V}$，当 $C=8\mu\text{F}$ 时，电阻 $R$ 消耗的功率达到最大，其值为 $P_{\max}=100\text{W}$，此时电感 $L=$ ______，电路的品质因数 $Q=$ ______。

**解答：**

该电路为 RLC 串联电路。当电阻 $R$ 消耗的功率最大时，电路处于串联谐振状态。

由 $u_s(t)$ 可知角频率 $\omega = 2500\text{ rad/s}$，电压有效值 $U = 10\text{V}$。

1. 谐振条件为 $\omega L = \frac{1}{\omega C}$，由此可求电感 $L$：

   $$L = \frac{1}{\omega^2 C} = \frac{1}{2500^2 \times 8 \times 10^{-6}} = \frac{1}{6.25 \times 10^6 \times 8 \times 10^{-6}} = \frac{1}{50} = 0.02\text{H}$$

2. 谐振时，电路总阻抗 $Z = R$。最大功率 $P_{\max} = \frac{U^2}{R}$：

   $$100 = \frac{10^2}{R} \Rightarrow R = 1\Omega$$

3. 品质因数 $Q$ 定义为：

   $$Q = \frac{\omega L}{R} = \frac{2500 \times 0.02}{1} = 50$$

   **答案：** $0.02\text{H}$， $50$

**5. 题目：**

电路如图1-5所示，已知 $i_L(0)=0$，电压源 $u_s(t)=10e^{-100t}\epsilon(t)\text{V}$。则 $t=0.01$ 时电感储存的磁场能量是 ______。

**解答：**

观察图1-5，电压源 $u_s$、电阻 $8\Omega$ 和电感 $5\text{H}$ 是并联关系（接在共同的两条水平导线之间）。

因此电感两端的电压即为电压源的电压： $u_L(t) = u_s(t) = 10e^{-100t}$（ $t \ge 0$ ）。

根据电感的伏安特性公式 $u_L(t) = L \frac{di_L}{dt}$，积分求电感电流：

$$i_L(t) = \frac{1}{L} \int_0^t u_L(\tau) d\tau + i_L(0) = \frac{1}{5} \int_0^t 10e^{-100\tau} d\tau = 2 \left[ \frac{e^{-100\tau}}{-100} \right]_0^t = 0.02(1 - e^{-100t})\text{ A}$$

当 $t=0.01\text{s}$ 时，代入得：

$$i_L(0.01) = 0.02(1 - e^{-1})\text{ A}$$

此时电感储存的磁场能量为：

$$W_L = \frac{1}{2} L i_L^2 = \frac{1}{2} \times 5 \times [0.02(1 - e^{-1})]^2 = 2.5 \times 0.0004 \times (1 - e^{-1})^2 = 0.001 (1 - e^{-1})^2\text{ J}$$

**(注： $1 - e^{-1} \approx 0.6321$，最终能量约为 $3.996 \times 10^{-4} \text{J}$)**

**答案：** $0.001(1 - e^{-1})^2\text{ J}$

**6. 题目：**

电路如图1-6所示，已知网络N内仅含线性电阻，在图(a)中开路电压 $U_1=6\text{V}$， $U_2=2\text{V}$；则在图(b)中电压 $U_3=$ ______。

**解答：**

由于网络N为仅含线性电阻的三端口网络，根据线性叠加定理和互易定理，可设它的端口特性方程为：

$$\begin{cases} V_1 = R_{11}I_1 + R_{12}I_2 + R_{13}I_3 \\ V_2 = R_{21}I_1 + R_{22}I_2 + R_{23}I_3 \\ V_3 = R_{31}I_1 + R_{32}I_2 + R_{33}I_3 \end{cases}$$

在图(a)中：端口1、2开路，即 $I_1=0$、 $I_2=0$。顶端口（端口3）外接 $4\text{A}$ 电流源与电阻 $R$ 并联。

由于 $4\text{A}$ 电流源向左注入端口3左端，根据KCL，流入端口3的电流为 $I_3^{(a)} = 4 - \frac{V_3^{(a)}}{R}$。

已知 $V_1^{(a)} = U_1 = 6\text{V}$， $V_2^{(a)} = U_2 = 2\text{V}$，由此可得：

$$R_{13} I_3^{(a)} = 6 \quad \Rightarrow \quad R_{13} = R_{31} = \frac{6}{I_3^{(a)}}$$

$$R_{23} I_3^{(a)} = 2 \quad \Rightarrow \quad R_{23} = R_{32} = \frac{2}{I_3^{(a)}}$$

且 $V_3^{(a)} = R_{33} I_3^{(a)}$，代入流入电流表达式得： $I_3^{(a)} = 4 - \frac{R_{33}I_3^{(a)}}{R} \Rightarrow I_3^{(a)}\left(1 + \frac{R_{33}}{R}\right) = 4$。

在图(b)中：左端口接入向上的 $4\text{A}$ 电流源，即 $I_1^{(b)} = 4\text{A}$；右端口接入向下的 $2\text{A}$ 电流源，即 $I_2^{(b)} = -2\text{A}$。

顶端口仅接电阻 $R$，则 $I_3^{(b)} = -\frac{V_3^{(b)}}{R}$。此时 $U_3 = V_3^{(b)}$。

根据第三个方程：

$$U_3 = R_{31}I_1^{(b)} + R_{32}I_2^{(b)} + R_{33}I_3^{(b)} = \frac{6}{I_3^{(a)}}(4) + \frac{2}{I_3^{(a)}}(-2) - R_{33}\frac{U_3}{R}$$

整理得：

$$U_3 \left(1 + \frac{R_{33}}{R}\right) = \frac{24 - 4}{I_3^{(a)}} = \frac{20}{I_3^{(a)}}$$

将前面得到的 $\left(1 + \frac{R_{33}}{R}\right) = \frac{4}{I_3^{(a)}}$ 代入上式：

$$U_3 \left(\frac{4}{I_3^{(a)}}\right) = \frac{20}{I_3^{(a)}} \Rightarrow 4 U_3 = 20 \Rightarrow U_3 = 5\text{V}$$

**答案：** $5\text{V}$

### 二、计算题

**1. 题目 (10分)：**

电路如图2-1所示，求电压 $u_1$ 和 $u_2$。

**解答：**

对图2-1进行节点电压分析。设定电路最下方的连线为参考节点 (0V)。

设 $30\text{V}$ 独立电压源上方的节点为节点1（电位为 $30\text{V}$），包含 $u_2$ 正极的中间节点为节点2（电位为 $u_2$），包含 $u_1$ 正极的节点为节点3（电位为 $u_1$）。

首先考察受控电流源 $2u$ 及其控制量 $u$：

$u$ 定义在 $6\Omega$ 电阻两端（左正右负）。从节点3经过 $6\Omega$ 电阻和 $2\Omega$ 电阻到地构成串联分压支路，由此可求得该支路电流为 $\frac{u_1}{6+2} = \frac{u_1}{8}$。

因此，控制量 $u = 6 \times \frac{u_1}{8} = 0.75 u_1$。受控电流源的值为 $2u = 1.5 u_1$。

对节点3（电位 $u_1$）列写KCL方程（所有流出节点的电流之和等于流入的电流）：

$$\frac{u_1 - u_2}{4} + \frac{u_1}{4} + \frac{u_1}{8} = 1.5 u_1$$

两边同乘 $8$ 进行化简：

$$2(u_1 - u_2) + 2u_1 + u_1 = 12 u_1$$

$$5u_1 - 2u_2 = 12u_1 \quad \Rightarrow \quad u_2 = -3.5 u_1 \quad \text{---(式1)}$$

对节点2（电位 $u_2$）列写KCL方程：

$$\frac{u_2 - 30}{4} + \frac{u_2}{2} + \frac{u_2 - u_1}{4} = 0$$

两边同乘 $4$ 进行化简：

$$(u_2 - 30) + 2u_2 + (u_2 - u_1) = 0 \quad \Rightarrow \quad 4u_2 - u_1 = 30 \quad \text{---(式2)}$$

将(式1)代入(式2)：

$$4(-3.5 u_1) - u_1 = 30 \quad \Rightarrow \quad -14u_1 - u_1 = 30 \quad \Rightarrow \quad -15u_1 = 30 \quad \Rightarrow \quad u_1 = -2\text{V}$$

然后回代求得 $u_2$：

$$u_2 = -3.5 \times (-2\text{V}) = 7\text{V}$$

**答案：** $u_1 = -2\text{V}$， $u_2 = 7\text{V}$。

**2. 题目 (10分)：**

电路如图2-2所示，已知电压源有效值相量 $\dot{U}_S=6\angle0^\circ\text{V}$，电流源有效值相量 $\dot{I}_S=(4+j2)\text{A}$。求电流 $\dot{I}_1$、 $\dot{I}_2$ 和 $\dot{I}_3$。

**解答：**

设底部含有独立源连接线的导线为参考节点（地）。

定义节点1为电压源正极（电位 $V_1 = 6\text{V}$）。

定义节点2为 $-j4\Omega$ 电容和 $j2\Omega$ 电感的交点（电位 $V_2$）。

定义节点3为右侧垂直支路所在的节点（电位 $V_3$）。图中顶层和中层的 $2\Omega$ 电阻均连接至节点3，节点3随后经由恒流源 $\dot{I}_S$ 流回地。

在节点3处，流出的总电流已被 $\dot{I}_S$ 固定。对节点3列写KCL方程：

$$\frac{6 - V_3}{2} + \frac{V_2 - V_3}{2} = \dot{I}_S = 4 + j2$$

整理得：

$$6 - V_3 + V_2 - V_3 = 8 + j4 \quad \Rightarrow \quad V_2 - 2V_3 = 2 + j4 \quad \Rightarrow \quad V_2 = 2V_3 + 2 + j4 \quad \text{---(式1)}$$

对节点2列写KCL方程：

$$\frac{6 - V_2}{-j4} = \frac{V_2 - V_3}{2} + \frac{V_2}{j2}$$

两边同乘以 $j4$：

$$-(6 - V_2) = j2(V_2 - V_3) + 2V_2 \quad \Rightarrow \quad -6 + V_2 = j2V_2 - j2V_3 + 2V_2$$

化简得：

$$V_2(-1 - j2) + j2V_3 = 6 \quad \text{---(式2)}$$

将(式1)代入(式2)：

$$(-1 - j2)(2V_3 + 2 + j4) + j2V_3 = 6$$

$$-2V_3 - 2 - j4 - j4V_3 - j4 - j^2 8 + j2V_3 = 6$$

$$(-2 - j2)V_3 + (6 - j8) = 6 \quad \Rightarrow \quad (-2 - j2)V_3 = j8$$

$$V_3 = \frac{j8}{-2 - j2} = \frac{-j4}{1 + j} = -j2(1 - j) = -2 - j2 \text{ (V)}$$

回代求 $V_2$：

$$V_2 = 2(-2 - j2) + 2 + j4 = -4 - j4 + 2 + j4 = -2 \text{ (V)}$$

据此计算所求电流：

$$\dot{I}_3 = \frac{V_2}{j2} = \frac{-2}{j2} = j \text{ (A)}$$

$$\dot{I}_2 = \frac{6 - V_3}{2} = \frac{6 - (-2 - j2)}{2} = \frac{8 + j2}{2} = 4 + j \text{ (A)}$$

$\dot{I}_1$ 为由源流出的总电流，分流至电容及顶层电阻：

$$\dot{I}_1 = \frac{6 - V_2}{-j4} + \dot{I}_2 = \frac{6 - (-2)}{-j4} + (4 + j) = \frac{8}{-j4} + 4 + j = j2 + 4 + j = 4 + j3 \text{ (A)}$$

**答案：** $\dot{I}_1 = 4 + j3\text{ A}$， $\dot{I}_2 = 4 + j\text{ A}$， $\dot{I}_3 = j\text{ A}$。

**3. 题目 (12分)：**

电路如图2-3所示，电路原处于稳态， $t=0$ 时开关S由位置1合向位置2，求换路后电容电压 $u_C$ 和电流 $i_C$ 的变化规律。

**解答：**

（1）换路前（ $t < 0$ ），开关接在位置1。

此时电容与右侧的 $6\text{V}$ 电压源和 $2\Omega$ 电阻相连，电路处于直流稳态，电容相当于开路。

因此初始状态电容两端电压： $u_C(0^-) = 6\text{V}$。由换路定律可知 $u_C(0^+) = u_C(0^-) = 6\text{V}$。

（2）换路后（ $t \ge 0$ ），开关接在位置2。

电容脱离右侧支路，并联到由 $2\text{A}$ 电流源、受控电压源等组成的左侧电路中。

采用戴维南等效定理求解电容左侧二端网络的等效模型（设开关2处为端口，参考地为下部连接线）：

**求开路电压 $U_{oc}$：** 断开电容时，流过顶端 $4\Omega$ 的电流为0。

设左上角节点电压为 $V_L$，左下角受控源 $2i_1$ 节点电压即为 $2i_1$。

则向下流过中间 $4\Omega$ 电阻的电流 $i_1 = \frac{V_L - 2i_1}{4} \Rightarrow 4i_1 = V_L - 2i_1 \Rightarrow 6i_1 = V_L$。

在左上角应用KCL（只有 $2\text{A}$ 输入）： $2\text{A} = i_1 \Rightarrow i_1 = 2\text{A}$。

则 $V_L = 6 \times 2 = 12\text{V}$，由此开路电压 $U_{oc} = 12\text{V}$。

**求等效电阻 $R_{eq}$：** 将独立电流源 $2\text{A}$ 置零（开路），在端口施加测试电压 $V_T$，设流入电流为 $I_T$。

此时， $I_T$ 全部流过顶端 $4\Omega$ 然后注入左上节点，因此流过中间 $4\Omega$ 的电流 $i_1 = I_T$。

左上节点电压 $V_L = 6i_1 = 6I_T$。

端口电压方程式为 $V_T = 4I_T + V_L = 4I_T + 6I_T = 10I_T$。

因此，戴维南等效内阻 $R_{eq} = \frac{V_T}{I_T} = 10\Omega$。

（3）求解响应方程：

电路时间常数 $\tau = R_{eq}C = 10\Omega \times 0.01\text{F} = 0.1\text{s}$。

稳态电压 $u_C(\infty) = U_{oc} = 12\text{V}$。

利用三要素法公式：

$$u_C(t) = u_C(\infty) + [u_C(0^+) - u_C(\infty)] e^{-t/\tau} = 12 + (6 - 12) e^{-10t} = 12 - 6e^{-10t} \text{ (V)} \quad (t \ge 0)$$

电容电流为：

$$i_C(t) = C \frac{du_C}{dt} = 0.01 \times (-6) \times (-10) e^{-10t} = 0.6e^{-10t} \text{ (A)} \quad (t \ge 0)$$

**答案：** 换路后变化规律为 $u_C(t) = 12 - 6e^{-10t}\text{ V}$， $i_C(t) = 0.6e^{-10t}\text{ A} \quad (t \ge 0)$。

**4. 题目 (15分)：**

电路如图2-4所示，(1)求二端口网络的Z参数；(2)求二端口网络的T形等效电路参数。

**解答：**

**(1) 求Z参数**

设底层导线为参考地(0V)。

由定义可知，端口1输入电流 $I_1$，端口2输入电流 $I_2$，响应电压分别为 $U_1, U_2$。

设中间 $U_3$ 电阻与受控源 $3I_2$ 之间的节点为A， $3I_2$ 与端口2顶端相连节点之前的交叉点为B (节点B对地电压为 $U_3$)，端口2顶端为节点C (电位为 $U_2$)。

根据KCL分析节点B（包含端口2电流流入分析）：

节点C处，KCL：$I_2 = 2U_3 + \frac{U_2 - U_3}{2} \Rightarrow I_2 = 1.5U_3 + 0.5U_2 \Rightarrow 2I_2 = 3U_3 + U_2 \Rightarrow U_2 = 2I_2 - 3U_3$

构建包含 $3I_2$ 的超节点 (A和B)：流入 A 的电流有 $I_1$ 与 $2U_3$。流出 B 的电流为 $\frac{U_3}{2}$（垂直向地）与 $\frac{U_3 - U_2}{2}$（水平向右）。

超节点KCL方程：$I_1 + 2U_3 = \frac{U_3}{2} + \frac{U_3 - U_2}{2} \Rightarrow I_1 + 2U_3 = U_3 - 0.5U_2 \Rightarrow I_1 = -U_3 - 0.5U_2$

将前述 $0.5U_2 = I_2 - 1.5U_3$ 代入：

$$I_1 = -U_3 - (I_2 - 1.5U_3) = 0.5U_3 - I_2 \quad \Rightarrow \quad 0.5U_3 = I_1 + I_2 \quad \Rightarrow \quad U_3 = 2I_1 + 2I_2$$

反代求得 $U_2$ 与 $U_1$ 关于 $I_1, I_2$ 的关系式：

$$U_2 = 2I_2 - 3(2I_1 + 2I_2) = -6I_1 - 4I_2$$

电压 $U_1 = I_1 \times 1\Omega + V_A$。已知受控电压源方程 $V_A - U_3 = 3I_2 \Rightarrow V_A = U_3 + 3I_2$。

$$U_1 = I_1 + U_3 + 3I_2 = I_1 + (2I_1 + 2I_2) + 3I_2 = 3I_1 + 5I_2$$

由此得到Z参数矩阵：

$$\begin{bmatrix} Z_{11} & Z_{12} \\ Z_{21} & Z_{22} \end{bmatrix} = \begin{bmatrix} 3 & 5 \\ -6 & -4 \end{bmatrix} \Omega$$

**(2) 求T形等效电路参数**

T形等效电路由三个阻抗 $Z_1, Z_2, Z_3$（星型结构）与一个受控电压源串联在某一支路中组成。

选用常见模型（受控源在右侧支路）：

$Z_3 = Z_{12} = 5\Omega$

$Z_1 = Z_{11} - Z_{12} = 3 - 5 = -2\Omega$

$Z_2 = Z_{22} - Z_{12} = -4 - 5 = -9\Omega$

由于 $Z_{21} \neq Z_{12}$（非互易），需要在右支路（串联于 $Z_2$）附加一个受控电压源 $U_{dep} = (Z_{21} - Z_{12})I_1 = (-6 - 5)I_1 = -11I_1$（极性与 $U_2$ 同向上正下负）。

**答案：**

(1) Z参数为 $Z_{11}=3\Omega, Z_{12}=5\Omega, Z_{21}=-6\Omega, Z_{22}=-4\Omega$。

(2) T型等效参数为：水平左臂阻抗 $Z_1 = -2\Omega$，公共接地臂阻抗 $Z_3 = 5\Omega$，水平右臂阻抗 $Z_2 = -9\Omega$，同时右臂还串联一个向下的受控电压源，电压值为 $-11I_1$。

**5. 题目 (16分)：**

正弦稳态电路如图2-5所示，已知 $i_S(t) = 5\sqrt{2}\cos(2\times 10^6 t)\text{ mA}$。求 $R$、 $L$ 为何值时电阻 $R$ 可获得最大功率，求出此最大功率。

**解答：**

角频率 $\omega = 2 \times 10^6 \text{ rad/s}$。将电流源转化为相量： $\dot{I}_S = 5\angle0^\circ \text{ mA}$。

对各储能元件计算复阻抗：

$0.25\text{nF}$ 电容： $Z_{C1} = \frac{1}{j\omega C_1} = \frac{1}{j \times 2\times10^6 \times 0.25\times10^{-9}} = -j2000\Omega = -j2\text{k}\Omega$

$0.6\text{mH}$ 电感： $Z_{L1} = j\omega L_1 = j \times 2\times10^6 \times 0.6\times10^{-3} = j1200\Omega = j1.2\text{k}\Omega$

$\frac{1}{3}\text{nF}$ 电容： $Z_{C2} = \frac{1}{j\omega C_2} = \frac{1}{j \times 2\times10^6 \times (1/3)\times10^{-9}} = -j1500\Omega = -j1.5\text{k}\Omega$

化简待求支路以外的电路（求戴维南等效电路）：

由电源变换，左侧的 $\dot{I}_S$ 与 $1\text{k}\Omega$ 并联，等效为 $\dot{V}_S' = \dot{I}_S \times 1\text{k}\Omega = 5\text{V}$，串联阻抗为 $1\text{k}\Omega$。

随后与电容 $C_1$ 串联，故戴维南模型的等效电源内阻左侧分支为： $Z_{\text{left}} = 1000 - j2000 \ (\Omega)$。

右侧部分为 $2\text{k}\Omega$ 电阻串联后续 $L_1$ 与 $C_2$ 的并联组合。

$L_1 // C_2$ 阻抗为： $Z_p = \frac{j1200 \times (-j1500)}{j1200 - j1500} = \frac{1800000}{-j300} = j6000\Omega = j6\text{k}\Omega$。

右侧分支总阻抗为： $Z_{\text{right}} = 2000 + j6000 \ (\Omega)$。

求由待求支路 ($R+j\omega L$) 两端看入的戴维南等效内阻 $Z_{th}$：

$$Z_{th} = Z_{\text{left}} // Z_{\text{right}} = \frac{(1000 - j2000)(2000 + j6000)}{(1000 - j2000) + (2000 + j6000)} = \frac{14000 + j2000}{3 + j4} = 2000 - j2000 \ (\Omega)$$

求开路电压 $\dot{U}_{th}$：

$$\dot{U}_{th} = \dot{V}_S' \frac{Z_{\text{right}}}{Z_{\text{left}} + Z_{\text{right}}} = 5 \times \frac{2 + j6}{(1-j2) + (2+j6)} = 5 \times \frac{2+j6}{3+j4} = 6 + j2 \text{ (V)}$$

开路电压模的平方： $|\dot{U}_{th}|^2 = 6^2 + 2^2 = 40$。

要使负载 $R$ 获得最大功率，负载应满足共轭匹配，即 $Z_{\text{load}} = Z_{th}^*$。

$$R + j\omega L = 2000 + j2000 \ (\Omega)$$

解得：

$$R = 2000\Omega = 2\text{k}\Omega$$

$$L = \frac{2000}{\omega} = \frac{2000}{2 \times 10^6} = 1\times 10^{-3}\text{H} = 1\text{mH}$$

最大功率为：

$$P_{\max} = \frac{|\dot{U}_{th}|^2}{4R} = \frac{40}{4 \times 2000} = 0.005\text{W} = 5\text{mW}$$

**答案：** 当 $R = 2\text{k}\Omega$、 $L = 1\text{mH}$ 时电阻 $R$ 获得最大功率，此最大功率为 $5\text{mW}$。

**6. 题目 (13分)：**

电路如图2-6所示，网络N是线性无独立源网络。在图(a)电路中，以电压 $u$ 为输入，电流 $i$ 为输出时，它的单位冲激响应 $h(t) = (3e^{-5t} + 4e^{-4t})\epsilon(t)\text{ A}$。今在网络N的a, b端接上R和C，如图(b)所示，规定 $i_1$ 为输入， $u_1$ 为输出，若 $i_1(t) = 20\sqrt{2}\cos t\text{ A}$，求正弦稳态响应 $u_1(t)$。

**解答：**

由图(a)可知输入为端口电压 $u$，输出为端口流入电流 $i$。网络N的导纳传递函数等于其冲激响应的拉普拉斯变换：

$$Y_N(s) = H(s) = \mathscr{L}\{3e^{-5t} + 4e^{-4t}\} = \frac{3}{s+5} + \frac{4}{s+4} = \frac{7s+32}{s^2+9s+20}$$

图(b)中，信号角频率 $\omega = 1 \text{ rad/s}$。则 $s = j1$。代入求此时网络N的复导纳：

$$Y_N(j) = \frac{7(j) + 32}{(j)^2 + 9(j) + 20} = \frac{32 + j7}{-1 + j9 + 20} = \frac{32 + j7}{19 + j9} \text{ S}$$

在图(b)中，电流源 $i_1$ 从右侧注入，串联经过电阻 $R=1\Omega$，然后分流进入相互并联的电容 $C=1\text{F}$ 和网络N。

电容C的导纳 $Y_C = j\omega C = j1 \text{ S}$。

并联部分的等效导纳为：

$$Y_p(j) = Y_N(j) + Y_C(j) = \frac{32 + j7}{19 + j9} + j = \frac{32 + j7 + j(19 + j9)}{19 + j9} = \frac{32 + j7 + j19 - 9}{19 + j9} = \frac{23 + j26}{19 + j9} \text{ S}$$

并联部分的等效阻抗为：

$$Z_p(j) = \frac{1}{Y_p(j)} = \frac{19 + j9}{23 + j26} \Omega$$

输入端口处看到的总等效阻抗 $Z_{in}$ 为：

$$Z_{in}(j) = R + Z_p(j) = 1 + \frac{19 + j9}{23 + j26} = \frac{(23 + j26) + (19 + j9)}{23 + j26} = \frac{42 + j35}{23 + j26} \Omega$$

将 $Z_{in}$ 化简：

$$Z_{in}(j) = \frac{(42 + j35)(23 - j26)}{23^2 + 26^2} = \frac{966 - j1092 + j805 + 910}{529 + 676} = \frac{1876 - j287}{1205} \Omega$$

输入电流的相量 $\dot{I}_1 = 20\angle0^\circ \text{ A}$。输出电压相量 $\dot{U}_1$ 为：

$$\dot{U}_1 = \dot{I}_1 Z_{in}(j) = 20 \times \frac{1876 - j287}{1205} = \frac{4(1876 - j287)}{241} = \frac{7504 - j1148}{241} \text{ V}$$

化为极坐标形式，模值为：

$$|\dot{U}_1| = \frac{\sqrt{7504^2 + (-1148)^2}}{241} = \frac{\sqrt{56310016 + 1317904}}{241} = \frac{\sqrt{57627920}}{241} \approx 31.50 \text{ V}$$

相角为：

$$\theta = \arctan\left(\frac{-1148}{7504}\right) \approx -8.70^\circ$$

所以，正弦稳态响应的时域表达式为：

$$u_1(t) = 31.50\sqrt{2}\cos(t - 8.70^\circ)\text{ V}$$

**答案：** $u_1(t) \approx 31.50\sqrt{2}\cos(t - 8.7^\circ)\text{ V}$
