  ### 题目一：动态电路分析（图 2-4）
  
  这是一道含有受控源的动态电路题，求解的关键是准确找到初始状态、稳态，并在求时间常数时正确处理受控源。
  
  为了方便分析，我们先设定参考节点：
  
  - 取电路最下方的整条导线为**参考地 (0V)**。
  - 电容左侧、连接着导线 $i_1$ 的节点记为**节点 A**。由于它被一根导线直接接地，因此电位始终被钳位在 $V_A = 0\text{V}$。
  - 电容右侧的节点记为**节点 B**。根据题目对 $u_C$ 的极性标注（左负右正），可知 $u_C = V_B - V_A = V_B$。
  
  **1. 求初始值 $u_C(0^+)$**
  
  在 $t < 0$ 时，开关 $S$ 处于**断开**状态，电路已达直流稳态。
  
  - 此时最左侧的 2V 电压源被断开。
  
  - 直流稳态下，电容相当于**开路**。因此，节点 A 只连接着接地的导线，没有任何电流流入，所以导线电流 $i_1(0^-) = 0\text{A}$。
  
  - 因为 $i_1 = 0$，受控电流源 $4i_1 = 0$（相当于开路）。
  
  - 观察节点 B：电容开路、受控源开路，因此连接在节点 B 右侧的 2Ω 电阻中也没有电流流过，电阻上无压降。
  
  - 节点 B 的电位直接等于最右侧电压源的电位：$V_B(0^-) = 2\text{V}$。
  
  - 根据电容电压不能突变的换路定则：
  
    $$u_C(0^+) = u_C(0^-) = V_B(0^-) = \mathbf{2\text{V}}$$
  
  **2. 求稳态值 $u_C(\infty)$**
  
  在 $t \to \infty$ 时，开关 $S$ **闭合**，电路再次达到直流稳态，电容再次相当于**开路**。
  
  - 最左侧支路导通，由于节点 A 为 0V，从左侧 2V 电源流向节点 A 的电流为 $(2 - 0) / 2 = 1\text{A}$。
  
  - **对节点 A 列 KCL：** 左侧流入 1A，右侧电容开路无电流。所以这 1A 只能全部向下流过导线，即 $i_1(\infty) = 1\text{A}$。
  
  - **对节点 B 列 KCL：** 受控源向下抽取的电流为 $4i_1(\infty) = 4\text{A}$。这 4A 电流必须由右侧的 2V 电源支路提供。
  
    $$\frac{2 - V_B(\infty)}{2} = 4$$
  
    $$2 - V_B(\infty) = 8 \implies V_B(\infty) = -6\text{V}$$
  
  - 所以，稳态电压 $u_C(\infty) = \mathbf{-6\text{V}}$。
  
  **3. 求时间常数 $\tau$**
  
  我们需要求出 $t > 0$ 时，从电容两端看进去的等效电阻 $R_{eq}$。
  
  - 将独立电源置零：最左侧和最右侧的 2V 电压源均视为短路。
  
  - 使用**外加测试电源法**：在电容处接入测试电压 $U_0$（正极接节点 B，负极接节点 A），设从正极流入节点 B 的电流为 $I_0$。注意此时 $V_A = 0\text{V}$，$V_B = U_0$。
  
  - **对节点 A 列 KCL（网络内部）：** 左侧 2Ω 电阻两端均接地，无电流；流入节点 A 的测试电流为 $I_0$；向下流出的电流为 $i_1$。
  
    $$0 + i_1 + I_0 = 0 \implies i_1 = -I_0$$
  
  - **对节点 B 列 KCL（网络内部）：** 外部注入电流 $I_0$，向下流出 $4i_1$，向右流出 $\frac{V_B}{2}$（因为右侧电源已短路接地）。
  
    $$I_0 = 4i_1 + \frac{V_B}{2}$$
  
    代入 $i_1 = -I_0$ 和 $V_B = U_0$：
  
    $$I_0 = -4I_0 + \frac{U_0}{2} \implies 5I_0 = \frac{U_0}{2} \implies R_{eq} = \frac{U_0}{I_0} = 10\Omega$$
  
  - 时间常数 $\tau = R_{eq}C = 10 \times 0.01 = \mathbf{0.1\text{s}}$。
  
  **4. 求解最终响应**
  
  - 根据三要素法公式：
  
    $$u_C(t) = -6 + [2 - (-6)]e^{-t/0.1} = \mathbf{-6 + 8e^{-10t} \text{ V} \quad (t \ge 0)}$$
  
  - 求电流 $i_1(t)$：在 $t > 0$ 任意时刻，对节点 A 列 KCL，流入的电流等于流出的电流 $i_1$。
  
    左侧支路恒定流入 1A；电容支路流入节点 A 的电流为 $C \frac{du_C}{dt}$。
  
    $$i_1(t) = 1 + C \frac{du_C}{dt} = 1 + 0.01 \times \frac{d}{dt}(-6 + 8e^{-10t})$$
  
    $$i_1(t) = 1 + 0.01 \times (-80e^{-10t}) = \mathbf{1 - 0.8e^{-10t} \text{ A} \quad (t \ge 0)}$$
  
  ### 题目二：含理想变压器的串联谐振电路（图 1-3）
  
  这道题考察了阻抗折算和谐振的基本公式。
  
  **1. 阻抗折算**
  
  根据理想变压器的特性，次级负载 $R$ 阻抗折算到初级线圈一侧，相当于一个等效电阻 $R_{eq}$：
  
  $$R_{eq} = n^2 R = 5^2 R = 25R$$
  
  折算后，整个电路等效为一个纯粹的 $L$、$C$、$R_{eq}$ 串联电路。
  
  **2. 利用谐振角频率求电感 $L$**
  
  已知串联谐振角频率 $\omega_0 = 10^4\text{ rad/s}$，电容 $C = 0.1\mu\text{F} = 10^{-7}\text{F}$。
  
  根据串联谐振公式：
  
  $$\omega_0 = \frac{1}{\sqrt{LC}}$$
  
  两边平方并代入数值：
  
  $$10^8 = \frac{1}{L \times 10^{-7}}$$
  
  解得：
  
  $$L = \frac{1}{10^8 \times 10^{-7}} = \mathbf{0.1\text{H}}$$
  
  **3. 利用品质因数求电阻 $R$**
  
  已知品质因数 $Q = 10$。串联谐振电路的品质因数公式为：
  
  $$Q = \frac{\omega_0 L}{R_{eq}}$$
  
  将已知数据代入：
  
  $$10 = \frac{10^4 \times 0.1}{25R}$$
  
  $$10 = \frac{1000}{25R} \implies 250R = 1000 \implies R = \mathbf{4\Omega}$$
  
  **最终答案填写：**
  
  - 电阻 $R = \mathbf{4\Omega}$
  - 电感 $L = \mathbf{0.1\text{H}}$

1. (12分) 电路如图2-1所示，求各独立电源发出的功率。   

- **解答步骤：**

  1. **设定参考节点**：设底层导线为参考节点（0V）。

  2. **节点定义与分析**：

     - 设左上角节点（5A电流源、4V电压源正极、5Ω电阻交汇处）为节点 A，电压为 $V_A$。
     - 设中上节点（5Ω电阻、6Ω电阻、受控压源交汇处）为节点 B，电压为 $V_B$。
     - 设右上节点（4V电压源负极、6Ω电阻、8Ω电阻交汇处）为节点 C，电压为 $V_C$。

  3. **利用支路关系列方程**：

     - 对节点 C 向下的 8Ω 支路 ，电流为 $I_1$，因此 $V_C = 8I_1$。  
     - 节点 B 的电压由受控电压源（5$I_1$）决定，且正极在上方 ，故 $V_B = 5I_1$。  
     - 节点 A 与 节点 C 之间有4V独立电压源 ，故 $V_A - V_C = 4 \Rightarrow V_A = 8I_1 + 4$。  

  4. **列写 KCL 方程**：

     - 设流过4V电压源的电流为 $I_{4V}$（方向从 A 流向 C）。

     - 对节点 C 列 KCL（流入 = 流出）：$I_{4V} + \frac{V_B - V_C}{6} = I_1$

       代入电压表达式：$I_{4V} + \frac{5I_1 - 8I_1}{6} = I_1 \Rightarrow I_{4V} - 0.5I_1 = I_1 \Rightarrow I_{4V} = 1.5I_1$。

     - 对节点 A 列 KCL（流入 = 流出）：$5 = \frac{V_A - V_B}{5} + I_{4V}$  代入电压与电流表达式：$5 = \frac{(8I_1 + 4) - 5I_1}{5} + 1.5I_1 = \frac{3I_1 + 4}{5} + 1.5I_1$ $5 = 0.6I_1 + 0.8 + 1.5I_1 \Rightarrow 2.1I_1 = 4.2 \Rightarrow I_1 = 2$A。

     - $I_1 = 2$A，由此得出：$V_A = 20$V， $V_B = 10$V， $V_C = 16$V， $I_{4V} = 3$A。

     - **4V独立电压源**：电流 $I_{4V}=3$A 从其正极（节点A）流出，故发出功率 $P_{4V} = U_{4V} \times I_{4V} = 4 \times 3 = 12$W。

  这是一道非常经典的电路分析综合题。题目要求计算各**独立电源**发出的功率，这就需要我们先求出电路中的所有未知电压和电流。

  按照你的要求，我将分别使用**节点电压法**和另一种最适合的回路电流法（网孔法）为你进行详细解答。两种方法殊途同归，可以互相验证。

  ### 方法一：节点电压法（包含超节点）

  这是求解本题最直接的方法。

  **1. 定义节点和变量**

  - 取电路最下方的公共导线为参考节点（接地，$0\text{V}$）。
  - 设左上角节点电压为 $V_1$。
  - 设中间节点（受控源上方）电压为 $V_2$。
  - 设右上角节点电压为 $V_3$。

  **2. 寻找约束条件**

  - **控制量约束：** $I_1$ 是流过最右侧 $8\Omega$ 电阻的电流，根据欧姆定律：

    $$I_1 = \frac{V_3}{8}$$

  - **受控源约束：** 中间节点直接由受控电压源支撑，因此：

    $$V_2 = 5I_1 = 5 \left(\frac{V_3}{8}\right) = \frac{5}{8}V_3$$

  - **超节点约束（广义节点）：** $V_1$ 和 $V_3$ 之间连接着一个 $4\text{V}$ 的独立电压源（左正右负），因此：

    $$V_1 - V_3 = 4 \implies V_1 = V_3 + 4$$

  **3. 列写节点电压方程（KCL）**

  将 $V_1$ 和 $V_3$ 看作一个整体（超节点），对这个超节点列写 KCL（流出电流之和 = 0）：

  - 从 $V_1$ 向左下流出的电流：$-5\text{A}$（因为 5A 电流源是流入的）。
  - 从 $V_1$ 向右下流出（经过 $5\Omega$）的电流：$\frac{V_1 - V_2}{5}$。
  - 从 $V_3$ 向左下流出（经过 $6\Omega$）的电流：$\frac{V_3 - V_2}{6}$。
  - 从 $V_3$ 向下流出（经过 $8\Omega$）的电流：$\frac{V_3}{8}$。

  将它们相加：

  $$-5 + \frac{V_1 - V_2}{5} + \frac{V_3 - V_2}{6} + \frac{V_3}{8} = 0$$

  **4. 求解方程**

  将 $V_1 = V_3 + 4$ 和 $V_2 = \frac{5}{8}V_3$ 代入上式：

  $$\frac{(V_3 + 4) - \frac{5}{8}V_3}{5} + \frac{V_3 - \frac{5}{8}V_3}{6} + \frac{V_3}{8} = 5$$

  $$\frac{\frac{3}{8}V_3 + 4}{5} + \frac{\frac{3}{8}V_3}{6} + \frac{V_3}{8} = 5$$

  $$\frac{3}{40}V_3 + \frac{4}{5} + \frac{1}{16}V_3 + \frac{V_3}{8} = 5$$

  将 $\frac{4}{5}$ 移到右边，左边找公分母 80：

  $$\left(\frac{6}{80} + \frac{5}{80} + \frac{10}{80}\right)V_3 = 5 - \frac{4}{5}$$

  $$\frac{21}{80}V_3 = \frac{21}{5}$$

  解得：

  $$V_3 = 16\text{V}$$

  由此可得所有节点的电压：

  - $V_1 = 16 + 4 = 20\text{V}$
  - $V_2 = \frac{5}{8} \times 16 = 10\text{V}$

  ### 方法二：回路电流法（网孔法）

  本题平面结构非常清晰，只有 3 个网孔，且左侧网孔含有独立电流源，这使得网孔法也非常高效。

  **1. 定义网孔电流（均设为顺时针方向）**

  - 左侧网孔电流设为 $i_1$。由于左侧边缘是向上流动的 $5\text{A}$ 电流源，所以直接得出：$i_1 = 5\text{A}$。
  - 右侧网孔电流设为 $i_2$。观察最右侧支路，向下流动的 $I_1$ 刚好等于该网孔电流，即：$i_2 = I_1$。
  - 顶部网孔电流设为 $i_3$。

  **2. 列写 KVL 方程**

  - **对于右侧网孔（$i_2$）：**

    $$-5I_1 + 6(i_2 - i_3) + 8i_2 = 0$$

    代入 $i_2 = I_1$：

    $$-5I_1 + 6(I_1 - i_3) + 8I_1 = 0 \implies 9I_1 - 6i_3 = 0 \implies i_3 = 1.5I_1$$

  - **对于顶部网孔（$i_3$）：**

    顺时针绕行，依次经过 $4\text{V}$ 电源（+ 到 -，降压）、$6\Omega$ 电阻、$5\Omega$ 电阻：

    $$4 + 6(i_3 - i_2) + 5(i_3 - i_1) = 0$$

    代入 $i_1 = 5, i_2 = I_1, i_3 = 1.5I_1$：

    $$4 + 6(1.5I_1 - I_1) + 5(1.5I_1 - 5) = 0$$

    $$4 + 3I_1 + 7.5I_1 - 25 = 0$$

    $$10.5I_1 = 21 \implies I_1 = 2\text{A}$$

  **3. 计算各处电压电流**

  - 既然 $I_1 = 2\text{A}$，那么 $i_3 = 3\text{A}$。
  - $V_3$ 节点电位 = $8\Omega \times I_1 = 16\text{V}$，结果与节点法完全一致！

  ### 最终计算：各独立电源发出的功率

  计算“发出功率”时，我们需要判断电流是否从电源的正极（+）流出。

  公式：$P_{\text{发出}} = U \times I_{\text{流出正极}}$

  **1. $5\text{A}$ 独立电流源**

  - 该电源连接在接地端与 $V_1$ 之间。$V_1 = 20\text{V}$，因此电源上方的端点电位比下方高 $20\text{V}$（上正下负）。
  - $5\text{A}$ 电流的方向是向上的，也就是**从正极流出**，符合发出功率的参考方向。
  - $P_{5A} = 20\text{V} \times 5\text{A} = \mathbf{100\text{W}}$
  - **结论：$5\text{A}$ 电流源发出功率 $100\text{W}$。**

  **2. $4\text{V}$ 独立电压源**

  - 通过方法一的 KCL 或方法二的网孔电流可知，流过该 $4\text{V}$ 电源的电流是 $i_3 = 3\text{A}$。
  - 因为 $i_3$ 是顺时针的，它在顶层支路中是从左向右流动的。
  - $4\text{V}$ 电压源的极性是左正（+）右负（-）。因此，这 $3\text{A}$ 的电流是**从正极流入**的。
  - 这说明该电源实际上是在**吸收**功率（充当了负载）。
  - $P_{4V(\text{发出})} = - (4\text{V} \times 3\text{A}) = \mathbf{-12\text{W}}$
  - **结论：$4\text{V}$ 电压源发出功率 $-12\text{W}$（或者说吸收了 $12\text{W}$ 的功率）。**

- **解答步骤：**

  1. **求初始状态 $u_C(0^+)$**：

- (12分) 正弦稳态电路如图2-3所示，已知电压源 $u_{s}(t)=25\sqrt{2}\cos(5t)$ V。 (1)画出电路的相量模型；(2)求电流 $i_L(t)$。   

- **解答步骤：**

  1. **电路相量模型参数计算**：

     - 激励角频率 $\omega = 5$ rad/s。激励电压相量 $\dot{U}_S = 25\sqrt{2}\angle 0^\circ$ V (采用振幅相量)。
     - 5Ω电阻阻抗不变：$Z_R = 5$Ω 。  
     - 0.1F电容阻抗：$Z_C = \frac{1}{j\omega C} = \frac{1}{j \times 5 \times 0.1} = -j2$Ω 。  
     - 0.8H电感阻抗：$Z_L = j\omega L = j \times 5 \times 0.8 = j4$Ω 。  
     - (1) 相量模型图的文字描述：包含电压源 $\dot{U}_S$ 串联 $5\Omega$ 电阻，其后分为两条并联支路。一条为 $-j2\Omega$ 的电容，另一条为串联了 $j4\Omega$ 电感及 $0.4\dot{U}$ 压控电压源的支路。其中 $\dot{U}$ 为 $5\Omega$ 电阻上的电压（左正右负）。

  2. **求解电流 $i_L(t)$**：

     - 设电容与电感交汇节点为 A，电压为 $\dot{V}_A$。根据题意， $\dot{U} = \dot{U}_S - \dot{V}_A$ 。  

     - 受控源电压（正极朝上）为 $0.4\dot{U} = 0.4(\dot{U}_S - \dot{V}_A)$ 。  

     - 经过电感的电流相量为 $\dot{I}_L = \frac{\dot{V}_A - 0.4\dot{U}}{j4} = \frac{\dot{V}_A - 0.4(\dot{U}_S - \dot{V}_A)}{j4} = \frac{1.4\dot{V}_A - 0.4\dot{U}_S}{j4}$。

     - 对节点 A 应用 KCL：

       $\frac{\dot{U}_S - \dot{V}_A}{5} = \frac{\dot{V}_A}{-j2} + \dot{I}_L \Rightarrow \frac{\dot{U}_S - \dot{V}_A}{5} = \frac{\dot{V}_A}{-j2} + \frac{1.4\dot{V}_A - 0.4\dot{U}_S}{j4}$

     - 等式两边同乘 $j20$：

       $j4(\dot{U}_S - \dot{V}_A) = -10\dot{V}_A + 5(1.4\dot{V}_A - 0.4\dot{U}_S)$

       $j4\dot{U}_S - j4\dot{V}_A = -10\dot{V}_A + 7\dot{V}_A - 2\dot{U}_S$

       $(2 + j4)\dot{U}_S = (-3 + j4)\dot{V}_A \Rightarrow \dot{V}_A = \frac{2 + j4}{-3 + j4}\dot{U}_S$

     - 将 $\dot{V}_A$ 代回 $\dot{I}_L$ 的表达式：

       分子部分 $1.4\dot{V}_A - 0.4\dot{U}_S = \left( 1.4\frac{2 + j4}{-3 + j4} - 0.4\frac{-3 + j4}{-3 + j4} \right) \dot{U}_S = \frac{2.8 + j5.6 + 1.2 - j1.6}{-3 + j4} \dot{U}_S = \frac{4 + j4}{-3 + j4} \dot{U}_S$

       $\dot{I}_L = \frac{1}{j4} \cdot \frac{4 + j4}{-3 + j4} \dot{U}_S = \frac{1 - j}{-4 - j3} \dot{U}_S = \frac{(1 - j)(-4 + j3)}{(-4)^2 + (-3)^2} \dot{U}_S = \frac{-1 + j7}{25} \times 25\sqrt{2} = (-\sqrt{2} + j7\sqrt{2})$ A。

     - 将 $\dot{I}_L$ 化为极坐标形式：

       幅值 $I_m = \sqrt{(-\sqrt{2})^2 + (7\sqrt{2})^2} = \sqrt{2 + 98} = 10$ A。

       相角 $\theta = 180^\circ - \arctan(7) \approx 180^\circ - 81.87^\circ = 98.13^\circ$ (因为实部为负，虚部为正，位于第二象限)。

- **答案：** $i_L(t) = 10\cos(5t + 98.13^\circ)$ A。

- (15分) 电路如图2-5所示，定义网络函数 $H(s)=U(s)/U_{S}(s)$。(1)画出电路的复频域模型，求网络函数 $H(s)$；(2)若电压源 $u_{s}(t)=50\sqrt{2}\cos(2t)$ V，求正弦稳态响应 $u(t)$。   

- **解答步骤：**

  1. **第(1)问**：

     - 复频域阻抗：$1\Omega \rightarrow 1\Omega$ ，$2\text{F} \rightarrow \frac{1}{2s}\Omega$ ，$2\text{H} \rightarrow 2s\Omega$ 。  

     - 设节点 A 为输入电阻与电容连接处，节点 B 为电感与输出端连接处。

     - 节点 A 的 KCL 方程： $\frac{U_S - U_C}{1} = U_C \cdot 2s + \frac{U_C - U}{2s}$

     - 节点 B 的 KCL 方程： $\frac{U_C - U}{2s} = 0.5U_C + \frac{U}{1}$   

     - 化简节点 B 方程：$U_C - U = sU_C + 2sU \Rightarrow U_C(1 - s) = U(2s + 1) \Rightarrow U_C = \frac{2s + 1}{1 - s}U$

     - 将上述 $\frac{U_C - U}{2s} = 0.5U_C + U$ 代入节点 A 方程右侧：

       $U_S - U_C = 2sU_C + (0.5U_C + U) \Rightarrow U_S = (2s + 1.5)U_C + U$

     - 将 $U_C$ 与 $U$ 的关系式代入：

       $U_S = (2s + 1.5)\frac{2s + 1}{1 - s}U + U = \frac{(4s^2 + 2s + 3s + 1.5) + (1 - s)}{1 - s}U = \frac{4s^2 + 4s + 2.5}{1 - s}U$

     - 得出网络函数： $H(s) = \frac{U(s)}{U_S(s)} = \frac{1 - s}{4s^2 + 4s + 2.5} = \frac{-2s + 2}{8s^2 + 8s + 5}$。

  2. **第(2)问**：

     - 激励角频率 $\omega = 2$ rad/s，即 $s = j2$。代入网络函数：

       $H(j2) = \frac{1 - j2}{4(j2)^2 + 4(j2) + 2.5} = \frac{1 - j2}{4(-4) + j8 + 2.5} = \frac{1 - j2}{-13.5 + j8}$

     - 分子分母同乘 2：$H(j2) = \frac{2 - j4}{-27 + j16}$

     - 有理化：$H(j2) = \frac{(2 - j4)(-27 - j16)}{(-27)^2 + 16^2} = \frac{-54 - j32 + j108 - 64}{729 + 256} = \frac{-118 + j76}{985}$。

     - 化为极坐标：幅值 $|H| = \frac{\sqrt{(-118)^2 + 76^2}}{985} = \frac{\sqrt{19700}}{985} = \frac{10\sqrt{197}}{5 \times 197} = \frac{2}{\sqrt{197}}$。

     - 相角 $\theta = 180^\circ - \arctan(76/118) \approx 147.22^\circ$。

     - 输出电压相量振幅 $U_m = |H| \cdot 50\sqrt{2} = \frac{100\sqrt{2}}{\sqrt{197}} \approx 10.08$ V。
