### 一、填空题

#### 1. 电路如图1-1所示，此单口网络的诺顿等效电路参数 $I_{SC} = \_\_\_\_\_$， $G_i = \_\_\_\_\_$

**【解答】**

- **原理**：求诺顿等效电路，需计算端口的短路电流 $I_{SC}$ 和除源后的等效电导 $G_i$。理想电流源串联电阻对外等效为该电流源；理想电压源并联电阻对外等效为该电压源。

- **计算 $G_i$**：

  将独立源置零（4A电流源开路，30V电压源短路）。

  由于30V电压源短路，与其并联的10Ω电阻也被短路。

  从端口看进去，左侧支路开路，剩下的电路为 3Ω电阻与6Ω电阻并联。

  等效电阻 $R_{eq} = 3\Omega \parallel 6\Omega = \frac{3 \times 6}{3 + 6} = 2\Omega$。

  等效电导 $G_i = \frac{1}{R_{eq}} = \mathbf{0.5 \, S}$。

- **计算 $I_{SC}$**：

  将上下端口短路，由于短路，3Ω电阻中无电流。

  左侧支路的4A电流源不受串联20Ω电阻影响，直接向短路端提供向下的 4A 电流。

  右侧部分，30V电压源（上正下负）并联10Ω电阻，整体等效为一个30V的理想电压源。短路后，该30V电压源直接加在6Ω电阻上。流过6Ω电阻的电流为 $I = \frac{30V}{6\Omega} = 5A$，方向为从上向下。

  根据KCL，流过短路导线（从上到下）的总电流为 $4A + 5A = 9A$。

  观察题目给定的诺顿等效电路图，**$I_{SC}$ 的参考方向是向上的**，因此 $I_{SC} = \mathbf{-9A}$。

  *(注：若部分教材习惯定义电流源方向向外输出为正，请注意参考方向)*

#### 2. 电路如图1-2所示...

#### 3. 电路如图1-3所示，已知电压源有效值相量 $\dot{U}_S = 10\angle30^{\circ}V$，当理想变压器的变比 $n = \_\_\_\_\_$， $8\Omega$ 电阻可获得最大功率 $P_{max} = \_\_\_\_\_$

**【解答】**

- **原理**：根据最大功率传输定理，当负载阻抗等于电源内阻的模时（对于纯电阻负载通过理想变压器匹配的情况），负载可获得最大功率。

- **计算**：

  从文本中读取到电源内阻为 $Z_S = (16+j12)k\Omega$。其模长 $|Z_S| = \sqrt{16^2 + 12^2} = 20k\Omega = 20000\Omega$。

  将副边的 $8\Omega$ 负载折算到原边，等效电阻 $R_L' = n^2 \times 8 \Omega$。

  令 $R_L' = |Z_S|$，即 $8n^2 = 20000$，解得 $n^2 = 2500$，故 $\mathbf{n = 50}$。

  此时原边回路的总阻抗为 $Z_{total} = Z_S + R_L' = (16000 + 20000) + j12000 = 36000 + j12000 \Omega$。

  回路电流有效值为 $I = \frac{U_S}{|Z_{total}|} = \frac{10}{\sqrt{36000^2 + 12000^2}} = \frac{10}{12000\sqrt{3^2+1^2}} = \frac{1}{1200\sqrt{10}} A$。

  负载获得的最大功率 $P_{max} = I^2 R_L' = \left(\frac{1}{1200\sqrt{10}}\right)^2 \times 20000 = \frac{20000}{14400000} = \mathbf{\frac{1}{720} \, W} \approx 1.39 \, mW$。

  *(若原题文本中的k为笔误，即阻抗为$16+j12\Omega$，则 $n=\sqrt{2.5}$， $P_{max}=\frac{25}{18}W$)*

#### 4. 电路如图1-4所示，已知 $i_S = e^{-10t}A$，则电压 $u_1 = \_\_\_\_\_$， $u_2 = \_\_\_\_\_$

**【解答】**

- **原理**：含有互感的动态电路，利用 $v = L\frac{di}{dt} \pm M\frac{di}{dt}$ 求解。

- **分析与计算**：

  观察电路，右侧端口开路，因此右侧水平 3H 电感的电流 $i_2 = 0$。

  根据图中电流源方向（箭头向下），$i_S$ 从上节点抽出。故流过 $10\Omega$ 电阻（从左向右）及中间竖直 3H 电感（从上向下）的电流 $i_1 = -i_S = -e^{-10t} A$。

  电流变化率：$\frac{di_1}{dt} = 10e^{-10t} A/s$。

  分析互感线圈：竖直电感（同名端在下），电流 $i_1$ 从非同名端流入；水平电感（同名端在右），电流 $i_2$ (虽为0，但参考方向设为向右) 从非同名端流入。因此互感电压为正号。

  竖直线圈上的电压（上正下负）：$v_1 = L_1 \frac{di_1}{dt} + M \frac{di_2}{dt} = 3 \times 10e^{-10t} + 0 = 30e^{-10t} V$。

  水平线圈上的电压（左正右负）：$v_2 = M \frac{di_1}{dt} + L_2 \frac{di_2}{dt} = 2 \times 10e^{-10t} + 0 = 20e^{-10t} V$。

  计算端口电压：

  $u_2$ 为右侧开路电压（右正左负）。$u_2 = -v_2 + v_1 = -20e^{-10t} + 30e^{-10t} = \mathbf{10e^{-10t} \, V}$。

  $u_1$ 为电流源两端电压（上正下负）。$u_1 = 10i_1 + v_1 = 10(-e^{-10t}) + 30e^{-10t} = \mathbf{20e^{-10t} \, V}$。

#### 5. 电路如图1-5所示，电路原处于稳态， $t=0$ 时断开开关S，则在 $0+$ 时刻， $\frac{di_L}{dt}\big|_{0+} = \_\_\_\_\_$

**【解答】**

- **原理**：换路定律及电感特性 $v_L = L\frac{di_L}{dt}$。

- **分析与计算**：

  $t < 0$ 时开关闭合，电路达到直流稳态。电感相当于短路，电容相当于开路。

  由于电感与 $1\mu F$ 电容及 $20\Omega$ 电阻完全并联（右侧三个支路），电感短路将电容和并联电阻一并短路。

  因此，稳态时电容电压 $u_C(0^-) = 0V$。

  根据换路定律，电容电压不能跃变：$u_C(0^+) = u_C(0^-) = 0V$。

  $t = 0$ 时开关断开，断开瞬间 ($t=0^+$)，由 R、L、C 构成的并联回路开始自由响应。

  在此并联回路中，电感两端的电压 $v_L(0^+)$ 等于电容两端的电压 $u_C(0^+)$。

  所以 $v_L(0^+) = u_C(0^+) = 0V$。

  根据 $v_L = L\frac{di_L}{dt}$，可得 $\frac{di_L}{dt}\big|_{0+} = \frac{v_L(0^+)}{L} = \mathbf{0 \, A/s}$。

### 二、计算题

#### 1. (12分) 电路如图2-1所示，求各受控电源发出的功率。

**【解答】**

**步骤1：使用节点电压法求解电路基础变量**

设电路底部导线为参考节点（0V），左上节点（1Ω电阻左侧）为节点A，右上节点（1Ω电阻右侧）为节点B。

$1\Omega$ 电阻上的电流为 $I$，方向向右，故 $I = \frac{V_A - V_B}{1} = V_A - V_B$。同时也推导出 $U = V_A - V_B = I$。

对节点A列 KCL 方程（流出为正）：

$2 + \frac{V_A - 10}{4} + I = 0$  ...... (式1)

对节点B列 KCL 方程：

$-I + \frac{V_B - 2I}{5} + 2U = 0$

因 $U=I$，代入得：$-I + \frac{V_B - 2I}{5} + 2I = 0$  ...... (式2)

**步骤2：解方程组求 $V_A$, $V_B$ 和 $I$**

化简式2：$I + \frac{V_B - 2I}{5} = 0 \Rightarrow 5I + V_B - 2I = 0 \Rightarrow V_B = -3I$

由 $I = V_A - V_B$ 得：$V_A = V_B + I = -3I + I = -2I$

将 $V_A$ 代入式1：

$2 + \frac{-2I - 10}{4} + I = 0$

$2 - 0.5I - 2.5 + I = 0$

$0.5I = 0.5 \Rightarrow I = 1A$

由此得出：$V_A = -2V$，$V_B = -3V$，$U = 1V$。

**步骤3：计算受控源发出功率**

- **受控电压源 (2I)**：

  电压值为 $2I = 2 \times 1 = 2V$（上正下负）。

  流过它的电流为中间支路向下的电流：$I_{mid} = \frac{V_B - 2I}{5} = \frac{-3 - 2}{5} = -1A$。

  该电流从电压源正极流出，故发出的功率 $P_{v\_source} = U \cdot I_{out} = 2V \times (-1A) = \mathbf{-2W}$（即吸收2W）。

- **受控电流源 (2U)**：

  电流值为 $2U = 2 \times 1 = 2A$（方向向下）。

  该支路中，电流源上方有 $10\Omega$ 电阻，因此电流源顶端的电压为 $V_{mid} = V_B - I_{right} \times 10 = -3 - 2 \times 10 = -23V$。

  电流源两端电压降（上正下负）为 $V_{mid} - 0 = -23V$。

  电流从正极流入，故吸收功率为 $P_{abs} = -23V \times 2A = -46W$。

  因此发出的功率 $P_{i\_source} = -P_{abs} = \mathbf{46W}$。

#### 2. (10分) 工频正弦电流电路如图2-2所示，已知电路消耗的总功率 $P=2000W$，求元件参数 $R_1$、$R_2$ 和 $L$。

**【解答】**

**步骤1：求取电路总阻抗**

总电压有效值 $V = 200V$，总电流有效值 $I = \frac{20}{\sqrt{3}} A$。

视在功率 $S = V \cdot I = 200 \times \frac{20}{\sqrt{3}} = \frac{4000}{\sqrt{3}} VA$。

已知有功功率 $P = 2000W$，则功率因数 $\cos\varphi = \frac{P}{S} = \frac{2000}{4000/\sqrt{3}} = \frac{\sqrt{3}}{2}$。

由于电路包含电感，为感性负载，故阻抗角 $\varphi = 30^{\circ}$。

总阻抗模 $|Z| = \frac{V}{I} = \frac{200}{20/\sqrt{3}} = 10\sqrt{3} \Omega$。

总阻抗 $Z = |Z|(\cos\varphi + j\sin\varphi) = 10\sqrt{3}(\frac{\sqrt{3}}{2} + j\frac{1}{2}) = 15 + j5\sqrt{3} \, \Omega$。

**步骤2：依据电路拓扑计算元件参数**

由图可知 $R_1$、电感 $L$ 和 $R_2$ 构成串联回路，故 $Z = (R_1 + R_2) + j\omega L$。

对照可得：总电阻 $R_1 + R_2 = 15 \Omega$，总电抗 $X_L = \omega L = 5\sqrt{3} \Omega$。

由于是工频交流电（中国标准 $f=50Hz$），角频率 $\omega = 2\pi f = 100\pi \, rad/s$。

解得电感 **$L = \frac{5\sqrt{3}}{100\pi} = \frac{\sqrt{3}}{20\pi} \, H \approx 27.6 \, mH$**。

电压表V2测得 $R_2$ 两端电压有效值 $V_2 = 150V$。由于是串联电路，流过 $R_2$ 的电流即为总电流。

故 **$R_2 = \frac{V_2}{I} = \frac{150}{20/\sqrt{3}} = 7.5\sqrt{3} \, \Omega \approx 12.99 \, \Omega$**。

进而求得 **$R_1 = 15 - R_2 = 15 - 7.5\sqrt{3} \, \Omega \approx 2.01 \, \Omega$**。

#### 3. (10分) 电路如图2-3所示... 求 (1)传输参数矩阵; (2)$R_L$ 取多大时, $U_2=2V$?

**【解答】**

**(1) 求传输参数矩阵 (T参数)**

对于二端口网络，采用标准传输方程（以 $I_2$ 流出端口为准）：

$U_1 = A U_2 + B I_2$

$I_1 = C U_2 + D I_2$

已知 $R_L \rightarrow \infty$ 时（即端口2开路，$I_2 = 0$），$U_1 = 10V, I_1 = 2A, U_2 = 4V$。代入方程：

$10 = A \times 4 + B \times 0 \Rightarrow A = 2.5$

$2 = C \times 4 + D \times 0 \Rightarrow C = 0.5 \, S$

因为网络为**对称二端口网络**，必定满足 $A = D$，所以 $D = 2.5$。

同时，对称无源网络必为互易网络，满足行列式 $|T| = AD - BC = 1$：

$2.5 \times 2.5 - B \times 0.5 = 1 \Rightarrow 6.25 - 0.5B = 1 \Rightarrow 0.5B = 5.25 \Rightarrow B = 10.5 \, \Omega$。

故传输参数矩阵为：**$\begin{bmatrix} 2.5 & 10.5 \\ 0.5 & 2.5 \end{bmatrix}$**。

**(2) 求 $R_L$**

当接上 $R_L$ 时，已知 $U_1 = 10V$，$U_2 = 2V$。

且端口2处有 $I_2 = \frac{U_2}{R_L} = \frac{2}{R_L}$。

代入传输方程第一式 $U_1 = A U_2 + B I_2$：

$10 = 2.5 \times 2 + 10.5 \times I_2 \Rightarrow 10 = 5 + 10.5 I_2 \Rightarrow I_2 = \frac{5}{10.5} = \frac{10}{21} \, A$。

因此，**$R_L = \frac{U_2}{I_2} = \frac{2}{10/21} = 4.2 \, \Omega$**。

#### 4. (14分) 电路如图2-4所示，电路原处于稳态...

**【解答】**

**步骤1：求 $t=0^-$ 时的初始状态**

$t<0$时，开关断开，电容视为开路。设中间靠左的节点为C（电压 $u_1$），靠右的节点为D（电压 $u_C$）。

对节点C列KCL：$4 = \frac{u_1}{2} + \frac{u_1 - u_C}{4} + 0.25u_1 \Rightarrow 4 = u_1 - 0.25u_C$

对节点D列KCL：$\frac{u_1 - u_C}{4} + 0.25u_1 = 0 \Rightarrow 0.5u_1 - 0.25u_C = 0 \Rightarrow u_C = 2u_1$

联立解得：$u_1(0^-) = 8V$，$u_C(0^-) = 16V$。

根据电容电压不突变规律：$u_C(0^+) = u_C(0^-) = 16V$。

**步骤2：求 $t \rightarrow \infty$ 时的稳态值**

开关S闭合，电容再次视为开路，但节点D通过 $8\Omega$ 电阻接地。

节点C方程不变：$4 = u_1 - 0.25u_C$

节点D新方程：$\frac{u_1 - u_C}{4} + 0.25u_1 = \frac{u_C}{8} \Rightarrow 0.5u_1 - 0.25u_C = 0.125u_C \Rightarrow u_1 = 0.75u_C$

代入C点方程：$4 = 0.75u_C - 0.25u_C = 0.5u_C \Rightarrow u_C(\infty) = 8V$。

对应得出：$u_1(\infty) = 6V$。

**步骤3：求时间常数 $\tau$**

独立源置零（4A开路），将测试电压 $V_t$ 加在电容所在位置（D与地之间），求输入电流 $I_t$。

KCL(节点C): $\frac{u_1}{2} + \frac{u_1 - V_t}{4} + 0.25u_1 = 0 \Rightarrow u_1 = 0.25V_t$

KCL(节点D): $I_t + \frac{u_1 - V_t}{4} + 0.25u_1 = \frac{V_t}{8}$

将 $u_1 = 0.25V_t$ 代入得到：$I_t + 0.25(0.25V_t - V_t) + 0.0625V_t = 0.125V_t \Rightarrow I_t = 0.25V_t$

等效电阻 $R_{eq} = \frac{V_t}{I_t} = 4\Omega$。

时间常数 $\tau = R_{eq}C = 4 \times 0.75 = 3s$。

**步骤4：写出动态响应方程**

由三要素法，电容电压为：

$u_C(t) = u_C(\infty) + [u_C(0^+) - u_C(\infty)] e^{-t/\tau} = 8 + (16 - 8)e^{-t/3} = \mathbf{8 + 8e^{-t/3} \, V \quad (t \ge 0)}$

对于 $u_1(t)$，在任何时刻节点C的KCL都成立（电容在此不影响C点瞬时欧姆关系）：

$4 = u_1(t) - 0.25u_C(t) \Rightarrow u_1(t) = 4 + 0.25u_C(t)$

代入 $u_C(t)$ 得：

$u_1(t) = 4 + 0.25(8 + 8e^{-t/3}) = \mathbf{6 + 2e^{-t/3} \, V \quad (t \ge 0)}$

#### 5. (14分) 电路如图2-5所示...

**【解答】**

**(1) 画出电路的复频域模型**

- **计算初始状态**：$t<0$ 开关闭合，稳态时电感短路，节点B电压 $V_B=0$，$u_C(0^-) = 0$。节点A电压 $V_A = 10V$，流过 $2\Omega$ 的电流 $i = \frac{10}{2} = 5A$。受控源电压 $5i = 25V$。支路电流 $i_L(0^-) = \frac{10 - 25 - 0}{7} = -15/7 \, A$（方向向下）。

- **复频域模型绘制说明**（文字描述）：

  开关闭合被断开，10V电源被移除。

  电路保留右侧部分，构成两个节点的复频域网络：节点A(左)、节点B(右)以及公共参考地。

  - 节点A到地：阻抗 $2 \, \Omega$，向下电流为 $I(s)$；
  - 节点A到B支路：串联一受控电压源 $5I(s)$（左正右负）与阻抗 $7 \, \Omega$；
  - 节点B到地包含两条并联支路：一条为电容阻抗 $\frac{40}{s} \, \Omega$，另一条为电感阻抗 $\frac{5s}{3} \, \Omega$ 并联一个向下的独立电流源 $\frac{15}{7s} \, A$（代表初始电流）。

**(2) 求换路后电流 $i(t)$ 的变化规律**

在复频域中列写节点电压方程。由于A节点无其他支路，从地经 $2\Omega$ 流向A的电流为 $-I(s)$，这等于流向B的电流：

$-I(s) = \frac{V_A(s) - 5I(s) - V_B(s)}{7}$

且已知 $V_A(s) = 2 I(s)$，代入上式化简得：

$-I(s) = \frac{2I(s) - 5I(s) - V_B(s)}{7} \Rightarrow -7I(s) = -3I(s) - V_B(s) \Rightarrow 4I(s) = V_B(s) \Rightarrow I(s) = 0.25 V_B(s)$

对节点B列写复频域 KCL：

$I_{AB}(s) = \frac{V_B(s)}{40/s} + \frac{V_B(s)}{5s/3} + \frac{15}{7s}$

由于 $I_{AB}(s) = -I(s) = -0.25 V_B(s)$，代入得：

$-0.25 V_B(s) = V_B(s) \frac{s}{40} + V_B(s) \frac{3}{5s} + \frac{15}{7s}$

提出 $V_B(s)$ 整理：

$V_B(s) \left( \frac{s}{40} + \frac{1}{4} + \frac{3}{5s} \right) = -\frac{15}{7s}$ *(注：参考方向使得初值等效源在方程右侧产生该项)*

等式两边同乘 $40s$：

$V_B(s) (s^2 + 10s + 24) = -\frac{600}{7}$

所以 $V_B(s) = \frac{-600/7}{s^2 + 10s + 24}$。

由 $I(s) = 0.25 V_B(s)$（注意图中的 $i$ 方向是向下的，所以在A点处 $i(t)$ 在上述 $I(s)$ 取反，即 $I(s)_{实际} = \frac{150/7}{s^2 + 10s + 24}$）。

分母因式分解：$s^2 + 10s + 24 = (s+4)(s+6)$。

利用部分分式展开：

$I(s) = \frac{150/7}{(s+4)(s+6)} = \frac{150}{7} \times \frac{1}{2} \left( \frac{1}{s+4} - \frac{1}{s+6} \right) = \frac{75}{7} \left( \frac{1}{s+4} - \frac{1}{s+6} \right)$

进行拉普拉斯反变换得时域响应：

**$i(t) = \frac{75}{7} \left( e^{-4t} - e^{-6t} \right) u(t) \, A$**。

#### 6. (13分) 若图2-6所示电路的网络函数... 试求:(1)$\omega_0$ ; (2)求Q和$H_0$ 的值。

**【解答】**

**(1) 求 $\omega_0$**

对图2-6列节点电压方程。设中间节点为 $V_A$，输出节点为 $U_2$。

节点 $V_A$ 方程: $(V_A - U_1) sC_1 + \frac{V_A}{R_1} + \frac{V_A - U_2}{R_2} = 0$

节点 $U_2$ 方程: $\frac{U_2 - V_A}{R_2} + U_2 sC_2 = 0 \Rightarrow V_A = U_2(1 + sR_2C_2)$

代入消去 $V_A$ 并整理，得到传递函数 $H(s) = \frac{U_2(s)}{U_1(s)}$:

$H(s) = \frac{s \frac{1}{R_2 C_2}}{s^2 + s\left(\frac{1}{R_1 C_1} + \frac{1}{R_2 C_1} + \frac{1}{R_2 C_2}\right) + \frac{1}{R_1 R_2 C_1 C_2}}$

将 $s=j\omega$ 代入，对照题目给定的标准带通滤波器函数形式 $H(j\omega) = \frac{H_0 \cdot j\frac{\omega_0}{Q}\omega}{(\omega_0^2 - \omega^2) + j\frac{\omega_0}{Q}\omega}$，比较分母常数项可知：

**$\omega_0 = \frac{1}{\sqrt{R_1 R_2 C_1 C_2}}$**

**(2) 求 Q 和 $H_0$**

当 $R_1 = R_2 = R, C_1 = C_2 = C$ 时：

$\omega_0 = \frac{1}{RC}$。

由一次项系数对比得带宽项 $\frac{\omega_0}{Q} = \frac{1}{RC} + \frac{1}{RC} + \frac{1}{RC} = \frac{3}{RC}$。

因此 $\frac{1/RC}{Q} = \frac{3}{RC}$，解得品质因数 **$Q = \frac{1}{3}$**。

对比分子项系数：已知分子应为 $H_0 \cdot j\frac{\omega_0}{Q}\omega = H_0 \cdot j\left(\frac{3}{RC}\right)\omega$。

而实际推导得出的分子项为 $j\omega \frac{1}{RC}$。

令 $H_0 \cdot \frac{3}{RC} = \frac{1}{RC}$，解得增益常数 **$H_0 = \frac{1}{3}$**。
