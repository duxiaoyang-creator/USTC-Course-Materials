7. 这是一道极其经典的交流电路分析题！它利用了无源元件（电感和电容）的特定组合，巧妙地构造出了一个**恒流源**电路（在工程上常被称为 Boucherot cell）。

   题目的核心破题点就在于那句“若改变电阻 $R_L$ 时，电流 $i$ 不变”。我们要做的就是通过列出电路方程，在数学上找出让电流表达式与 $R_L$ 无关的条件。

   下面我为你从头到尾详细拆解这道题的求解步骤：

   ### 第一步：提取已知条件，建立相量模型

   从电源表达式 $u_S(t) = 10\sqrt{2}\cos(1000t)\text{V}$ 中，我们可以提取出：

   - **角频率：** $\omega = 1000 \text{ rad/s}$
   - **电源电压相量：** $\dot{U}_S = 10\angle 0^\circ \text{ V}$

   接下来写出电感和电容的复阻抗：

   - **电感阻抗：** $Z_L = j\omega L = j(1000 \times 0.1) = j100 \Omega$
   - **电容阻抗：** $Z_C = \frac{1}{j\omega C} = -j\frac{1}{1000C} \Omega$
   - **负载阻抗：** $Z_R = R_L$

   ### 第二步：推导负载电流 $\dot{I}$ 的表达式

   为了求出流过 $R_L$ 的电流 $\dot{I}$，我们可以使用节点电压法。

   设电感、电容与电阻相交的那个节点（即 $R_L$ 上方的节点）的电压为 $\dot{U}_A$。

   根据欧姆定律，流过负载的电流就是：

   $$\dot{I} = \frac{\dot{U}_A}{R_L}$$

   对节点 A 列写 KCL 方程（流入 = 流出）：

   $$\frac{\dot{U}_S - \dot{U}_A}{Z_L} = \frac{\dot{U}_A}{R_L} + \frac{\dot{U}_A}{Z_C}$$

   我们需要把 $\dot{U}_A$ 用 $\dot{I}$ 替换掉，以便直接观察 $\dot{I}$ 和 $R_L$ 的关系。将 $\dot{U}_A = \dot{I} \cdot R_L$ 代入上式：

   $$\frac{\dot{U}_S - \dot{I}R_L}{Z_L} = \dot{I} + \frac{\dot{I}R_L}{Z_C}$$

   等式两边同乘 $Z_L$，展开：

   $$\dot{U}_S - \dot{I}R_L = \dot{I}Z_L + \frac{\dot{I}R_L Z_L}{Z_C}$$

   把含有 $\dot{I}$ 的项全部移到等式右边并提取公因式 $\dot{I}$：

   $$\dot{U}_S = \dot{I}Z_L + \dot{I}R_L + \frac{\dot{I}R_L Z_L}{Z_C} = \dot{I} \left( Z_L + R_L + \frac{R_L Z_L}{Z_C} \right)$$

   $$\dot{U}_S = \dot{I} \left[ Z_L + R_L \left( 1 + \frac{Z_L}{Z_C} \right) \right]$$

   $$\dot{U}_S = \dot{I} \left[ Z_L + R_L \left( \frac{Z_C + Z_L}{Z_C} \right) \right]$$

   最终得到负载电流的表达式：

   $$\dot{I} = \frac{\dot{U}_S}{Z_L + R_L \left( \frac{Z_L + Z_C}{Z_C} \right)}$$

   ### 第三步：应用“电流不变”条件求电容 $C$

   仔细观察上面求出的电流表达式。题目要求：**无论 $R_L$ 怎么变，$\dot{I}$ 都不变。**

   从数学角度来看，一个分数如果它的值与分母中的变量 $R_L$ 无关，**唯一的可能就是 $R_L$ 前面的系数为 0**。

   因此，我们得到电路实现“恒流”的绝对条件：

   $$\frac{Z_L + Z_C}{Z_C} = 0 \implies Z_L + Z_C = 0$$

   *(物理意义：这说明电感和电容发生了串联谐振，它们的阻抗相互抵消了。)*

   将阻抗代入：

   $$j100 + \left( -j\frac{1}{1000C} \right) = 0$$

   $$100 = \frac{1}{1000C}$$

   $$C = \frac{1}{100 \times 1000} = 10^{-5}\text{F}$$

   化为微法：

   $$C = \mathbf{10\mu\text{F}}$$

   ### 第四步：计算恒定电流 $i(t)$

   既然 $Z_L + Z_C = 0$，我们把它代回第二步推导出的电流表达式中，含有 $R_L$ 的那一项就瞬间消失了：

   $$\dot{I} = \frac{\dot{U}_S}{Z_L + R_L \times 0} = \frac{\dot{U}_S}{Z_L}$$

   *(物理意义：在这个特定频率下，负载电流只由电源电压和串联电感决定，跟负载本身完全没关系，这就是一个完美的恒流源！)*

   代入具体数值计算相量：

   $$\dot{I} = \frac{10\angle 0^\circ}{j100} = \frac{10\angle 0^\circ}{100\angle 90^\circ} = 0.1\angle -90^\circ \text{ A}$$

   最后，将相量还原为时域表达式（注意乘以 $\sqrt{2}$ 恢复为峰值）：

   $$i(t) = \mathbf{0.1\sqrt{2}\cos(1000t - 90^\circ) \text{ A}}$$

   *(如果你习惯写正弦，也可以写成 $0.1\sqrt{2}\sin(1000t) \text{ A}$，两者完全等价。)*

   **最终填空答案：**

   - 电容 $C = \mathbf{10\mu\text{F}}$ (或 $10^{-5}\text{F}$)
   - 电流 $i = \mathbf{0.1\sqrt{2}\cos(1000t - 90^\circ) \text{ A}}$

### 二、计算题

这是一道非常经典的电路分析题。含有独立电压源和受控电压源的电路，最适合使用**包含广义节点（超节点）的节点电压矩阵**来进行系统求解。

以下是详细的矩阵化求解过程：

### 一、 节点定义与预处理

1. **设置参考节点：** 取电路最下方的公共导线为参考地（$0\text{V}$）。

2. **定义节点电压：** * 设左上角节点电压为 $V_1$（连接 $6\Omega$、$2\Omega$ 和 $6\text{V}$ 电源）。

   - 设中间节点电压为 $V_2$（受控源 $6u$ 的正极）。
   - 设右上角节点电压为 $V_3$（连接 $3\Omega$、$6\text{V}$ 电源负极和 $2\text{A}$ 电流源）。

3. **处理控制量 $u$：**

   观察 $3\Omega$ 电阻，其两端标记为左负右正，因此控制电压 $u = V_3 - V_2$。

4. **处理受控源约束：**

   中间支路的受控电压源直接连接在 $V_2$ 与地之间，且正极向上，因此：

   $$V_2 = 6u = 6(V_3 - V_2)$$

   整理得：

   $$7V_2 - 6V_3 = 0 \quad \text{--- (约束方程 1)}$$

### 二、 建立节点电压矩阵方程

由于 $6\text{V}$ 独立电压源连接在 $V_1$ 和 $V_3$ 之间，我们将其视为一个广义节点（超节点）来列写 KCL 方程，以避开未知的电压源电流。

1. **对广义节点 $(V_1, V_3)$ 列 KCL：**

   流出 $V_1$ 的电流 + 流出 $V_3$ 的电流 = 流入广义节点的电流

   $$\frac{V_1}{6} + \frac{V_1 - V_2}{2} + \frac{V_3 - V_2}{3} = 2$$

   等式两边同乘 6 进行化简：

   $$V_1 + 3(V_1 - V_2) + 2(V_3 - V_2) = 12$$

   $$4V_1 - 5V_2 + 2V_3 = 12 \quad \text{--- (主节点方程)}$$

2. **$6\text{V}$ 独立电压源的约束方程：**

   电源正极在 $V_1$，负极在 $V_3$，因此：

   $$V_1 - V_3 = 6 \quad \text{--- (约束方程 2)}$$

3. **写成标准矩阵形式：**

   将上述三个方程联立，即可得到该电路完整的节点电压矩阵形式：

   $$\begin{bmatrix} 4 & -5 & 2 \\ 1 & 0 & -1 \\ 0 & 7 & -6 \end{bmatrix} \begin{bmatrix} V_1 \\ V_2 \\ V_3 \end{bmatrix} = \begin{bmatrix} 12 \\ 6 \\ 0 \end{bmatrix}$$

### 三、 解矩阵方程求节点电压

根据第二行的约束可知 $V_1 = V_3 + 6$。

根据第三行的约束可知 $V_2 = \frac{6}{7}V_3$。

将它们代入第一行的主节点方程中：

$$4(V_3 + 6) - 5\left(\frac{6}{7}V_3\right) + 2V_3 = 12$$

$$4V_3 + 24 - \frac{30}{7}V_3 + 2V_3 = 12$$

$$6V_3 - \frac{30}{7}V_3 = -12$$

$$\frac{42 - 30}{7}V_3 = -12 \implies \frac{12}{7}V_3 = -12$$

解得各节点电压为：

- **$V_3 = -7\text{V}$**
- **$V_2 = -6\text{V}$**
- **$V_1 = -1\text{V}$**

### 四、 计算各独立电源发出的功率

电源**发出功率**的判定标准是：电流是否从其**正极流出**（$P_{\text{发}} = U \times I_{\text{流出正极}}$）。

**1. 求 $6\text{V}$ 独立电压源发出的功率**

- 设流过 $6\text{V}$ 电源的电流为 $I_{6V}$（方向由 $V_1$ 指向 $V_3$）。

- 对 $V_3$ 节点列 KCL，求 $I_{6V}$：

  $$\frac{V_3 - V_2}{3} - I_{6V} - 2 = 0$$

  $$I_{6V} = \frac{-7 - (-6)}{3} - 2 = -\frac{1}{3} - 2 = -\frac{7}{3}\text{A}$$

- 因为 $I_{6V}$ 是负值，说明实际的物理电流是 $\frac{7}{3}\text{A}$，方向由 $V_3$ 流向 $V_1$。

- 对于该 $6\text{V}$ 电源，正极在 $V_1$，电流恰好从正极 $V_1$ **流出**。

- **$P_{6V(\text{发})} = 6\text{V} \times \frac{7}{3}\text{A} = \mathbf{14\text{W}}$**

**2. 求 $2\text{A}$ 独立电流源发出的功率**

- 该电源连接在 $0\text{V}$（参考地）和 $V_3$ 之间，电流方向向上（流入 $V_3$）。

- 电流是从其顶部端点流出的，此时顶部端点的电压即为 $V_3 = -7\text{V}$。

- 该电流源两端的压降（以电流流出端相对流入端）为 $V_3 - 0 = -7\text{V}$。

- **$P_{2A(\text{发})} = U \times I = (-7\text{V}) \times 2\text{A} = \mathbf{-14\text{W}}$**

  *(注：发出功率为负，说明该电流源实际上是在吸收能量，充当了负载。)*

**最终答案：**

- $6\text{V}$ 独立电压源发出的功率为 **$14\text{W}$**。

- $2\text{A}$ 独立电流源发出的功率为 **$-14\text{W}$**。

3. 题目： 电路如图2-2所示,已知电压源有效值相量 $\dot{U}_{s}=4\angle0^{\circ}V$。求电压源发出的有功功率。  **解答：** 设经过串联电感 $j2\Omega$ 之后的中间上方节点为B，节点电压为 $\dot{V}_B$，底层导线接地。 各支路电流关系如下：  

- 流入B点的总电流（即电源发出的电流）：$\dot{I}_1 = \frac{4 - \dot{V}_B}{j2} \Rightarrow \dot{V}_B = 4 - j2\dot{I}_1$
- 经中支路（容抗与流控电压源）流向地的电流：$\dot{I}_m = \frac{\dot{V}_B - j2\dot{I}_1}{-j1}$
- 经右侧支路流向地的电流：$\dot{I}_r = \frac{\dot{V}_B}{3 - j2}$

对节点B应用KCL ($\dot{I}_1 = \dot{I}_m + \dot{I}_r$)，并代入 $\dot{V}_B$ 的表达式化简：

$\dot{I}_1 = \frac{4 - j2\dot{I}_1 - j2\dot{I}_1}{-j1} + \frac{4 - j2\dot{I}_1}{3 - j2} = j(4 - j4\dot{I}_1) + \frac{4 - j2\dot{I}_1}{3 - j2}$

$-3\dot{I}_1 - j4 = \frac{4 - j2\dot{I}_1}{3 - j2}$

两边同乘 $(3 - j2)$ 并解关于 $\dot{I}_1$ 的一元一次方程：

$(-3\dot{I}_1 - j4)(3 - j2) = 4 - j2\dot{I}_1$

$-9\dot{I}_1 + j6\dot{I}_1 - j12 - 8 = 4 - j2\dot{I}_1$

$(-9 + j8)\dot{I}_1 = 12 + j12 \Rightarrow \dot{I}_1 = \frac{12 + j12}{-9 + j8}$

### 核心方法：含受控源电路的戴维南等效电阻求解法

当电路中含有受控源时，**绝对不能**直接用电阻串并联的方法去求等效电阻，因为受控源不是被动元件，它会动态地改变电路的状态。

必须使用“外加测试电源法”（或称为伏安法），步骤如下：

1. **独立源置零：** 将电路中所有的**独立电压源短路**（变导线），所有的**独立电流源开路**（断开）。
2. **保留受控源：** 受控源（不论是电压源还是电流源）**必须原封不动地保留**在电路中，不能置零！
3. **外加测试电源：** 在要求等效电阻的端口（例如 $a-b$ 端）外加一个测试电压 $U_{test}$。
4. **计算测试电流：** 通过 KVL/KCL 计算出从测试电源正极流入该端口的电流 $I_{test}$。
5. **求得等效电阻：** $R_{th} = \frac{U_{test}}{I_{test}}$。

掌握了这个“杀手锏”，我们来拆解这道题。

### 第一问：（1）求图(a)一端口网络的戴维南等效电路

为了方便描述，我们将 $10\Omega$ 电阻正上方的节点命名为**节点 C**，底部公共导线设为**参考地 (0V)**。

#### 第一步：求开路电压 $U_{oc}$

此时 $a-b$ 端开路，没有电流流向外部。

我们先对节点 C 左侧的电路进行一个非常巧妙的**电源等效变换**，化繁为简：

- 观察左侧支路中，受控电流源 $2i$ 与 $5\Omega$ 电阻并联。根据电源等效变换，它可以转换为一个**受控电压源与电阻串联**的形式。
- 受控电压源大小为：$5\Omega \times 2i = 10i$。因为电流源方向朝右，所以电压源极性为**左负右正**。
- 现在，左侧支路变成了一条纯串联支路：$10\text{V}$ 独立电源 $\rightarrow$ $15\Omega$ 电阻 $\rightarrow$ $10i$ 受控电压源 $\rightarrow$ $5\Omega$ 电阻 $\rightarrow$ 节点 C。
- 合并这条串联支路：等效电压为 $10 + 10i$（极性朝向节点 C），等效电阻为 $15 + 5 = 20\Omega$。

因为 $a-b$ 开路，左侧支路的所有电流只能全部向下流过 $10\Omega$ 电阻。根据欧姆定律：

$$i = \frac{\text{左侧等效总电压}}{\text{左侧等效电阻} + 10\Omega} = \frac{10 + 10i}{20 + 10} = \frac{10 + 10i}{30}$$

解这个方程：

$$30i = 10 + 10i \implies 20i = 10 \implies \mathbf{i = 0.5\text{A}}$$

知道了 $i$，我们就能求节点电压了：

- 节点 C 的电压 $V_C = 10\Omega \times i = 10 \times 0.5 = 5\text{V}$。

- 再看节点 C 到端口 a：经过一个 $2\Omega$ 电阻和一个 $15\text{V}$ 电压源。由于是开路，$2\Omega$ 上没有电流也没有压降。

- $15\text{V}$ 独立电压源的极性是左负右正，所以电位在经过它时会升高 $15\text{V}$。

  $$U_{oc} = V_a = V_C + 15\text{V} = 5 + 15 = \mathbf{20\text{V}}$$

#### 第二步：求等效电阻 $R_{th}$（使用外加测试电源法）

1. **独立源置零：** 左侧 $10\text{V}$ 和右侧 $15\text{V}$ 的独立电压源全部短路（变导线）。

2. **应用测试电源：** 在 $a-b$ 端外加电压 $U_{test}$，设流入 a 端的电流为 $I_{test}$。

3. **找关系式：**

   - 因为 $15\text{V}$ 电源被短路，$I_{test}$ 直接流过 $2\Omega$ 电阻到达节点 C。

   - 节点 C 的电压：$V_C = U_{test} - 2 I_{test}$。

   - 注意题目定义的控制量 $i$：它是向下流过 $10\Omega$ 电阻的电流，所以 **$i = \frac{V_C}{10}$**。

   - 对节点 C 列 KCL：流入的 $I_{test}$ 等于向下流的 $i$ 加上向左流的电流 $I_{left}$。

     $$I_{test} = i + I_{left}$$

   - **关键一步（算 $I_{left}$）：** 我们继续用刚才等效好的左侧支路。独立源 $10\text{V}$ 没了，左侧支路现在是一个 $20\Omega$ 电阻串联一个 $10i$ 的受控电压源。

     向左流的电流 $I_{left} = \frac{V_C - 10i}{20}$。

   - 把 $i = \frac{V_C}{10}$ 代入 $I_{left}$ 的式子里：

     $$I_{left} = \frac{V_C - 10 \times (\frac{V_C}{10})}{20} = \frac{V_C - V_C}{20} = \mathbf{0}$$

   - *（这是一个非常神奇且常见的结果：受控源恰好提供了完美的抵消电压，导致这条支路对测试电源呈现无穷大的阻抗，不吸取任何电流！）*

4. **计算 $R_{th}$：**

   既然向左的电流为 0，那么测试电流 $I_{test}$ 全部流向了 $10\Omega$ 电阻。

   $$I_{test} = i = \frac{V_C}{10}$$

   $$10 I_{test} = V_C$$

   代回 $V_C$ 的表达式：

   $$10 I_{test} = U_{test} - 2 I_{test} \implies 12 I_{test} = U_{test}$$

   $$\mathbf{R_{th} = \frac{U_{test}}{I_{test}} = 12\Omega}$$

**结论：图(a)的戴维南等效电路为一个 $20\text{V}$ 的电压源串联一个 $12\Omega$ 的电阻。**

### 第二问：（2）求电容、电感在直流稳态时各自储存的能量

将化简后的(a)与(b)连接，电路变成了一个极度清爽的串联回路：

**$20\text{V}$ 电压源 $\rightarrow$ $12\Omega$ 戴维南电阻 $\rightarrow$ $L$ $\rightarrow$ ($8\Omega$ 电阻 $\parallel$ $C$)**

#### 第一步：分析直流稳态

在直流稳态下（经过足够长的时间，波形不再变化）：

- **电感 $L$ 相当于短路（变导线）。**
- **电容 $C$ 相当于开路（断开）。**

此时，整个电路只有一条通路：电流从 $20\text{V}$ 电源出发，流过 $12\Omega$ 等效电阻，穿过短路的电感，流过 $8\Omega$ 电阻，回到负极。

- 电路总电流（即流过电感的电流）：

  $$I_L = \frac{20\text{V}}{12\Omega + 8\Omega} = \frac{20}{20} = \mathbf{1\text{A}}$$

- 电容两端的电压（即并联的 $8\Omega$ 电阻两端的电压）：

  $$U_C = I_L \times 8\Omega = 1\text{A} \times 8\Omega = \mathbf{8\text{V}}$$

#### 第二步：计算储存能量

已知 $C = 0.1\text{F}$， $L = 1\text{H}$。

直接套用储能公式：

- **电感储能：**

  $$W_L = \frac{1}{2} L I_L^2 = \frac{1}{2} \times 1 \times 1^2 = \mathbf{0.5\text{J}}$$

- **电容储能：**

  $$W_C = \frac{1}{2} C U_C^2 = \frac{1}{2} \times 0.1 \times 8^2 = 0.05 \times 64 = \mathbf{3.2\text{J}}$$

### （1）画出电路的复频域模型

4. **右侧支路：** $6\Omega$ 电阻与 $1\text{H}$ 电感的串联。
   - 电阻阻抗 $Z_{R2}(s) = \mathbf{6\Omega}$。

### （2）求冲激响应 $u_C(t)$ 和 $i_L(t)$

#### 第一步：列写节点电压方程求 $U_C(s)$

对顶端公共节点应用 KCL（流出节点的各支路电流之和等于流入节点的电流源电流）：

$$\frac{U_C(s)}{4} + \frac{U_C(s)}{\frac{4}{s}} + \frac{U_C(s)}{s + 6} = I_S(s)$$

代入 $I_S(s) = 3$，并提取公因式 $U_C(s)$：

$$U_C(s) \left( \frac{1}{4} + \frac{s}{4} + \frac{1}{s + 6} \right) = 3$$

将括号内的导纳项进行通分化简：

$$\frac{1}{4} + \frac{s}{4} + \frac{1}{s + 6} = \frac{s + 1}{4} + \frac{1}{s + 6} = \frac{(s + 1)(s + 6) + 4}{4(s + 6)} = \frac{s^2 + 7s + 6 + 4}{4(s + 6)} = \frac{s^2 + 7s + 10}{4(s + 6)}$$

将化简后的导纳代回原方程：

$$U_C(s) \left[ \frac{s^2 + 7s + 10}{4(s + 6)} \right] = 3$$

$$U_C(s) = \frac{12(s + 6)}{s^2 + 7s + 10}$$

对分母进行因式分解：$s^2 + 7s + 10 = (s + 2)(s + 5)$。

$$U_C(s) = \frac{12(s + 6)}{(s + 2)(s + 5)}$$

#### 第二步：部分分式展开求 $u_C(t)$

设 $U_C(s) = \frac{A}{s + 2} + \frac{B}{s + 5}$，利用留数法求解待定系数：

$$A = \left. \frac{12(s + 6)}{s + 5} \right|_{s = -2} = \frac{12(-2 + 6)}{-2 + 5} = \frac{48}{3} = 16$$

$$B = \left. \frac{12(s + 6)}{s + 2} \right|_{s = -5} = \frac{12(-5 + 6)}{-5 + 2} = \frac{12}{-3} = -4$$

因此：

$$U_C(s) = \frac{16}{s + 2} - \frac{4}{s + 5}$$

查表进行拉普拉斯反变换，得到电容电压的冲激响应：

$$\mathbf{u_C(t) = (16e^{-2t} - 4e^{-5t})\varepsilon(t) \text{ V}}$$

#### 第三步：求电感电流 $I_L(s)$ 及 $i_L(t)$

观察 s 域模型，流过右侧支路的电流 $I_L(s)$ 直接等于该支路两端的电压除以其阻抗：

$$I_L(s) = \frac{U_C(s)}{Z_{R2} + Z_L} = \frac{U_C(s)}{s + 6}$$

我们将刚才求得的未经部分分式展开的 $U_C(s)$ 代入（你会发现分子里的 $(s+6)$ 被完美约掉了！）：

$$I_L(s) = \frac{1}{s + 6} \cdot \frac{12(s + 6)}{(s + 2)(s + 5)} = \frac{12}{(s + 2)(s + 5)}$$

再次对 $I_L(s)$ 进行部分分式展开：

设 $I_L(s) = \frac{C}{s + 2} + \frac{D}{s + 5}$

$$C = \left. \frac{12}{s + 5} \right|_{s = -2} = \frac{12}{3} = 4$$

$$D = \left. \frac{12}{s + 2} \right|_{s = -5} = \frac{12}{-3} = -4$$

因此：

$$I_L(s) = \frac{4}{s + 2} - \frac{4}{s + 5}$$

进行拉普拉斯反变换，得到电感电流的冲激响应：

$$\mathbf{i_L(t) = (4e^{-2t} - 4e^{-5t})\varepsilon(t) \text{ A}}$$
