**题目 6** 电路如图1-6所示,二端口网络的导纳参数矩阵 Y= 混合参数矩阵 H=   

**解答：** 图1-6为一个“L”型网络：串联臂阻抗为 $Z_1 = j\omega L$，并联臂导纳为 $Y_2 = j\omega C$ 。 根据基尔霍夫定律列出端口方程： 端口1电压 $U_1 = I_1(j\omega L) + U_2$ 端口2电流 $I_2 = U_2(j\omega C) - I_1$  

- **求 H 矩阵：**

  由方程 $U_1 = (j\omega L)I_1 + 1 \cdot U_2$ 和 $I_2 = -1 \cdot I_1 + (j\omega C)U_2$ 直接可得混合参数：

  $$H = \begin{bmatrix} j\omega L & 1 \\ -1 & j\omega C \end{bmatrix}$$

- **求 Y 矩阵：**

  将 H 参量或直接通过节点电压法转换为 Y 参量：

  $I_1 = \frac{1}{j\omega L} U_1 - \frac{1}{j\omega L} U_2$

  $I_2 = -\frac{1}{j\omega L} U_1 + (\frac{1}{j\omega L} + j\omega C) U_2$

  $$Y = \begin{bmatrix} \frac{1}{j\omega L} & -\frac{1}{j\omega L} \\ -\frac{1}{j\omega L} & j\omega C + \frac{1}{j\omega L} \end{bmatrix}$$

**答案：** $Y = \begin{bmatrix} \frac{1}{j\omega L} & -\frac{1}{j\omega L} \\ -\frac{1}{j\omega L} & j\omega C + \frac{1}{j\omega L} \end{bmatrix}$ ； $H = \begin{bmatrix} j\omega L & 1 \\ -1 & j\omega C \end{bmatrix}$

这是一道非常经典的动态电路分析题。分别使用常规时域法（三要素法+微分方程）**和**拉普拉斯变换法（复频域）来求解，是对这两种电路分析体系最好的对照和复习。

下面为你详细写出两种方法的完整过程。

### 方法一：常规做法（时域分析法）

#### 1. 求阶跃响应 $i(t)$（使用三要素法）

当激励为单位阶跃电流 $i_S(t) = \varepsilon(t)\text{A}$ 时，我们要计算流过电感的电流 $i(t)$。

- **初始值 $i(0^+)$：** 换路前（$t < 0$），电路无激励，处于零状态，即 $i(0^-) = 0\text{A}$。根据电感电流不突变原则，$i(0^+) = i(0^-) = 0\text{A}$。
- **稳态值 $i(\infty)$：** 当 $t \to \infty$ 时，直流阶跃激励已达到稳态。电感在直流稳态下相当于**短路**。此时所有的电流 $1\text{A}$ 都会从没有电阻的电感支路流过（电阻 $1\Omega$ 被短接），因此 $i(\infty) = 1\text{A}$。
- **时间常数 $\tau$：** 从电感两端看进去的等效电阻 $R_{eq} = 1\Omega$。时间常数 $\tau = \frac{L}{R_{eq}} = \frac{0.1}{1} = 0.1\text{s}$。

将这三要素代入标准公式：

$$i(t) = i(\infty) + [i(0^+) - i(\infty)]e^{-t/\tau}$$

$$i(t) = 1 + [0 - 1]e^{-t/0.1} = 1 - e^{-10t}$$

**结果：** 阶跃响应 $i(t) = \mathbf{(1 - e^{-10t})\varepsilon(t) \text{ A}}$

#### 2. 求冲激响应 $u(t)$（利用微积分关系）

当激励为单位冲激电流 $i_S(t) = \delta(t)\text{A}$ 时，求电感电压 $u(t)$。

在线性电路中，**冲激响应是阶跃响应的导数**。

我们先求激励为 $\delta(t)$ 时，电感电流的冲激响应 $i_{impulse}(t)$：

$$i_{impulse}(t) = \frac{d}{dt} [i_{step}(t)] = \frac{d}{dt} [(1 - e^{-10t})\varepsilon(t)]$$

根据求导法则：

$$i_{impulse}(t) = 10e^{-10t}\varepsilon(t) + (1 - e^{-10t})\delta(t)$$

由于在 $t=0$ 时 $(1 - e^{-10t}) = 0$，所以第二项消去：

$$i_{impulse}(t) = 10e^{-10t}\varepsilon(t) \text{ A}$$

接着，根据电感的伏安特性求电感两端的电压 $u(t)$：

$$u(t) = L \frac{d}{dt} i_{impulse}(t) = 0.1 \frac{d}{dt} [10e^{-10t}\varepsilon(t)]$$

$$u(t) = 0.1 \left[ -100e^{-10t}\varepsilon(t) + 10e^{-10t}\delta(t) \right]$$

$$u(t) = -10e^{-10t}\varepsilon(t) + e^{-10t}\delta(t)$$

利用冲激函数的取样性质 $f(t)\delta(t) = f(0)\delta(t)$，这里的 $e^{-10t}\delta(t)$ 等价于 $e^0\delta(t) = \delta(t)$。整理得到：

**结果：** 冲激响应 $u(t) = \mathbf{\delta(t) - 10e^{-10t}\varepsilon(t) \text{ V}}$

### 方法二：拉普拉斯变换法（复频域分析法）

拉普拉斯变换法能完美避开时域中处理 $\delta(t)$ 函数求导的繁琐细节，直接用代数方法求解。

**构建 s 域等效模型：**

- 电阻阻抗：$Z_R(s) = 1\Omega$

- 电感阻抗：$Z_L(s) = sL = 0.1s \Omega$

- 二者并联，总阻抗为：

  $$Z(s) = \frac{Z_R(s) Z_L(s)}{Z_R(s) + Z_L(s)} = \frac{1 \cdot 0.1s}{1 + 0.1s} = \frac{s}{s + 10} \Omega$$

#### 1. 求阶跃响应 $i(t)$

当 $i_S(t) = \varepsilon(t)$ 时，其拉普拉斯变换为 $I_S(s) = \frac{1}{s}$。

根据分流定理，流过电感的电流 $I(s)$ 为：

$$I(s) = I_S(s) \frac{1}{1 + 0.1s} = \frac{1}{s} \cdot \frac{10}{s + 10} = \frac{10}{s(s + 10)}$$

进行部分分式展开：

$$I(s) = \frac{1}{s} - \frac{1}{s + 10}$$

查表进行反变换：

**结果：** 阶跃响应 $i(t) = \mathbf{(1 - e^{-10t})\varepsilon(t) \text{ A}}$

#### 2. 求冲激响应 $u(t)$

当 $i_S(t) = \delta(t)$ 时，其拉普拉斯变换为 $I_S(s) = 1$。

电路两端的总电压（即电感电压）$U(s)$ 等于总电流乘以总阻抗：

$$U(s) = I_S(s) Z(s) = 1 \cdot \frac{s}{s + 10} = \frac{s}{s + 10}$$

这是一个假分式（分子分母同阶），为了反变换，我们需要凑一项将其化为真分式：

$$U(s) = \frac{s + 10 - 10}{s + 10} = 1 - \frac{10}{s + 10}$$

查表进行反变换（注意常数 $1$ 的反变换是冲激函数 $\delta(t)$）：

**结果：** 冲激响应 $u(t) = \mathbf{\delta(t) - 10e^{-10t}\varepsilon(t) \text{ V}}$（第4填空题不同方法·解析）

### 二、计算题

**题目 1** 电路如图2-1所示,求各独立电压源发出的功率。   

**解答：**

采用节点电压法。设底端公共线为参考节点（0V）。电路有三个非参考节点：

- 节点A（左上）：电压设为 $V_A$。图中控制电压 $u_1$ 标在左侧支路，$+$ 在节点A，$-$ 在地，故 $u_1 = V_A$。
- 节点B（中上）：电压设为 $V_B$。
- 节点C（右上）：电压设为 $V_C$。

根据基尔霍夫电流定律（KCL）列方程：

1. **节点 A：**

   $\frac{V_A - 1}{1} + \frac{V_A - V_B}{1} + \frac{V_A - V_C}{2} = 0$

   化简得：$2.5V_A - V_B - 0.5V_C = 1$  (式1)

2. **节点 B：**

   $\frac{V_B - V_A}{1} + \frac{V_B - V_C}{1} + \frac{V_B - 3u_1}{1} = 0$

   代入 $u_1 = V_A$ 得：$-4V_A + 3V_B - V_C = 0$  (式2)

3. **节点 C：**

   观察最右侧支路，10V电压源的负极在上，正极在下，即等电位为 $-10\text{V}$。

   $\frac{V_C - V_A}{2} + \frac{V_C - V_B}{1} + \frac{V_C - (-10)}{2} = 0$

   化简得：$-V_A - 2V_B + 4V_C = -10$  (式3)

**联立求解方程组：**

由(式2)得 $V_C = -4V_A + 3V_B$。

代入(式1)和(式3)：

$2.5V_A - V_B - 0.5(-4V_A + 3V_B) = 1 \implies 4.5V_A - 2.5V_B = 1 \implies 9V_A - 5V_B = 2$

$-V_A - 2V_B + 4(-4V_A + 3V_B) = -10 \implies -17V_A + 10V_B = -10$

解得：$V_A = -6\text{V}$， $V_B = -11.2\text{V}$， $V_C = -9.6\text{V}$。

**计算功率：**

- **1V独立电压源：**

  流出其正极（向上）的电流为：$I_{1V} = \frac{1 - V_A}{1} = \frac{1 - (-6)}{1} = 7\text{A}$。

  发出的功率 $P_{1V} = U \times I_{1V} = 1\text{V} \times 7\text{A} = 7\text{W}$。

- **10V独立电压源：**

  该电源为上负下正结构，流出其正极（向下）的电流为右侧支路电流：$I_{10V} = \frac{V_C - (-10)}{2} = \frac{-9.6 + 10}{2} = 0.2\text{A}$。

  发出的功率 $P_{10V} = 10\text{V} \times 0.2\text{A} = 2\text{W}$。

答：1V电压源发出 $7\text{W}$ 功率，10V电压源发出 $2\text{W}$ 功率。

**题目 2** 电路如图 2-2 所示,已知电压源有效值相量 $\dot{U}_{S}=6\angle0^{\circ}V$,(1)求ab左侧电路的戴维南等效电路;(2)阻抗 $Z_{L}$ 为何值时可获得最大功率,求出此最大功率。   

**解答：**

**(1) 求戴维南等效电路：**

- **求开路电压 $\dot{U}_{oc}$：**

  断开 $Z_L$，端点a、b开路。由于b端开路，右下角的 $-j5\Omega$ 电容中无电流流过，因此 $V_b = 0\text{V}$（选取下端公共线为参考节点）。

  此时，左侧闭合回路电流 $\dot{I} = \frac{\dot{U}_S}{6 + j10 + 6} = \frac{6}{12 + j10} \text{A}$。

  受控电压源节点（记为节点2，在 $6\Omega$ 和 $j10\Omega$ 中间）的电压 $V_2 = \dot{I} \times 6 = \frac{36}{12 + j10}$。

  由于a端开路，无电流流经受控电压源，故 $V_a = V_2 + j5\dot{I}$ (注意图中极性)。

  $\dot{U}_{oc} = V_a - V_b = V_2 + j5\dot{I} - 0 = (6 + j5)\dot{I} = (6 + j5)\frac{6}{2(6 + j5)} = 3\angle0^{\circ} \text{V}$。

- **求等效阻抗 $Z_{th}$：**

  将独立电压源 $\dot{U}_S$ 短路。在 a、b 端施加测试电流 $\dot{I}_{test}$（由 a 流入，由 b 流出）。

  由 a 看入的无源网络等效阻抗包括：受控源、并联的 $6\Omega$ 与 $(6+j10)\Omega$（因为电源短路），以及 b 端的 $-j5\Omega$ 电容。

  由于 $\dot{U}_{oc}$ 的计算中分子分母完美消去，可以用公式 $V_{ab} = 3\dot{I}_{test} - j5\dot{I}_{test}$ 推导。

  等效阻抗 $Z_{th} = 3 - j5 \ \Omega$。

**(2) 求最大功率：**

当负载阻抗等于戴维南等效阻抗的共轭时，获得最大功率。

即 $Z_L = Z_{th}^* = 3 + j5 \ \Omega$。

最大功率 $P_{max} = \frac{|\dot{U}_{oc}|^2}{4 \times Re(Z_{th})} = \frac{3^2}{4 \times 3} = \frac{9}{12} = 0.75 \text{ W}$。

答：戴维南等效电路为电压源 $3\angle0^{\circ}\text{V}$ 串联阻抗 $(3-j5)\Omega$；当 $Z_L = 3+j5\Omega$ 时获最大功率 $0.75\text{W}$。

**题目 3** 正弦稳态电路如图 2-3所示,(1)画出电路的相量模型;(2)求网络函数 $H(j\omega)=\dot{U_{2}}/\dot{U_{1}}$; (3) 若 $u_{1}(t)=2\sqrt{2}\cos 2t \ V$,求正弦稳态响应 $u_{2}(t)$。   

**解答：**

**(1) 相量模型：**

将所有元件用阻抗/导纳表示，电源用相量表示。（文字描述：输入 $\dot{U}_1$，输出 $\dot{U}_2$；顶部跨接电阻为 $1\Omega$；T型网络两串联臂为电容 $1/(j\omega C) = 1/(j\omega)$，并联臂为电阻 $1\Omega$）

**(2) 求网络函数 $H(j\omega)$：**

设 T 型网络中心节点电压为 $\dot{V}_m$。列节点电压方程：

节点 $V_m$: $(\dot{V}_m - \dot{U}_1)j\omega + (\dot{V}_m - \dot{U}_2)j\omega + \frac{\dot{V}_m}{1} = 0 \implies \dot{V}_m(1 + 2j\omega) = j\omega(\dot{U}_1 + \dot{U}_2)$

输出节点 $U_2$ (开路，电流为0): $\frac{\dot{U}_2 - \dot{U}_1}{1} + (\dot{U}_2 - \dot{V}_m)j\omega = 0 \implies \dot{U}_2(1 + j\omega) - \dot{U}_1 = j\omega\dot{V}_m$

代入 $\dot{V}_m$：

$\dot{U}_2(1 + j\omega) - \dot{U}_1 = \frac{(j\omega)^2(\dot{U}_1 + \dot{U}_2)}{1 + 2j\omega} = \frac{-\omega^2(\dot{U}_1 + \dot{U}_2)}{1 + 2j\omega}$

整理合并 $\dot{U}_1$ 和 $\dot{U}_2$ 项，化简得到：

$$H(j\omega) = \frac{\dot{U}_2}{\dot{U}_1} = \frac{1 - \omega^2 + j2\omega}{1 - \omega^2 + j3\omega}$$

**(3) 求正弦稳态响应 $u_2(t)$：**

已知激励 $u_1(t) = 2\sqrt{2}\cos(2t) \text{ V}$，则 $\omega = 2 \text{ rad/s}$，相量 $\dot{U}_1 = 2\sqrt{2}\angle0^{\circ} \text{ V}$。

代入 $\omega = 2$ 计算频率响应：

$$H(j2) = \frac{1 - 4 + j4}{1 - 4 + j6} = \frac{-3 + j4}{-3 + j6} = \frac{(-3 + j4)(-3 - j6)}{3^2 + 6^2} = \frac{9 + 24 + j18 - j12}{45} = \frac{33 + j6}{45} = \frac{11 + j2}{15}$$

计算幅值和相角：

$|H(j2)| = \frac{\sqrt{11^2 + 2^2}}{15} = \frac{\sqrt{125}}{15} = \frac{5\sqrt{5}}{15} = \frac{\sqrt{5}}{3}$

$\angle H(j2) = \arctan(\frac{2}{11}) \approx 10.3^{\circ}$

输出相量：

$$\dot{U}_2 = H(j2)\dot{U}_1 = (\frac{\sqrt{5}}{3}\angle10.3^{\circ}) \times (2\sqrt{2}\angle0^{\circ}) = \frac{2\sqrt{10}}{3}\angle10.3^{\circ} \text{ V}$$

转换回时域：

$$u_2(t) = \frac{2\sqrt{10}}{3} \cos(2t + 10.3^{\circ}) \text{ V}$$

**题目 4** 电路如图2-4所示,电路原处于稳态, $t=0$ 时开关S从位置a合至位置b。 (1)求换路后电容电压 $u_{c}$ 和电流 $i$;(2)求出为何值时电容的储能为零。   

**解答：**

**(1) 求换路后的 $u_c(t)$ 和 $i(t)$：**

- **$t < 0$ 稳态：** 开关在 a 处，电容连接右侧直流电路，视为开路。

  电容电压等于右侧节点 a 电压，即 $u_c(0^-) = -5\text{V}$。

  根据换路定则：$u_c(0^+) = u_c(0^-) = -5\text{V}$。

- **$t \ge 0$ 时：** 开关在 b 处。建立电容与左侧电路的微分方程。

  设受控电流源上方节点电压为 $V_m$。由 10V 电压源（左负右正）可知，电容电压 $u_c = V_m + 10 \implies V_m = u_c - 10$。

  流过左侧 $10\Omega$ 电阻向右的电流 $i = \frac{0 - V_m}{10} = -0.1V_m = -0.1(u_c - 10) = 1 - 0.1u_c$。

  在节点 $V_m$ 处应用 KCL：进入节点的电流 $i$ 等于离开的电流 $0.2i$ 加上流向电容的电流 $i_c$。

  $i = 0.2i + i_c \implies i_c = 0.8i = 0.8(1 - 0.1u_c) = 0.8 - 0.08u_c$

  代入 $i_c = C \frac{du_c}{dt} = 0.01 \frac{du_c}{dt}$：

  $0.01 \frac{du_c}{dt} + 0.08u_c = 0.8 \implies \frac{du_c}{dt} + 8u_c = 80$

  解此一阶常系数微分方程：

  稳态值 $u_c(\infty) = 10\text{V}$，时间常数 $\tau = \frac{1}{8} = 0.125\text{s}$。

  $$u_c(t) = u_c(\infty) + [u_c(0^+) - u_c(\infty)]e^{-t/\tau} = 10 + (-5 - 10)e^{-8t} = 10 - 15e^{-8t} \text{ V} \quad (t \ge 0)$$

  电流 $i(t) = 1 - 0.1u_c(t) = 1 - 0.1(10 - 15e^{-8t}) = 1.5e^{-8t} \text{ A} \quad (t \ge 0)$。

**(2) 求电容储能为零的时刻 $t$：**

电容储能为零即 $u_c(t) = 0$。

$$10 - 15e^{-8t} = 0 \implies 15e^{-8t} = 10 \implies e^{-8t} = \frac{2}{3}$$

$$t = -\frac{1}{8}\ln\left(\frac{2}{3}\right) = \frac{1}{8}\ln(1.5) \text{ s} \approx 0.0507 \text{ s}$$

**题目 5** 电路如图2-5所示,电路原处于稳态,t=0时开关闭合。(1)画出电路的复频域模型;(2)求换路后电流i₂(t).   

**解答：**

**(1) 复频域模型：**

- **$t < 0$：** 开关断开，右侧无电流。左侧和中间支路构成回路。稳态时电感相当于短路。

  流过中间支路电感（向下）的初始电流 $i_1(0^-) = \frac{1}{1 + 2/3} = 0.6 \text{ A}$。右侧支路 $i_2(0^-) = 0$。

- **$t \ge 0$ 复频域模型（文字描述）：**

  三个并联支路连接在顶端节点（设电压为 $V_A(s)$）与底端接地点之间。

  - **左侧支路：** 电压源 $\frac{1}{s}$ 串联 $1\Omega$ 电阻。
  - **中间支路：** $\frac{2}{3}\Omega$ 电阻 串联 $\frac{2}{3}s$ 电感阻抗，再串联一个附加电压源 $L_1 i_1(0^-) = \frac{2}{3} \times 0.6 = 0.4\text{V}$（极性上负下正，表示释放能量），或者采用并联电流源模型。
  - **右侧支路：** $6\Omega$ 电阻 串联 $2s$ 电感阻抗。

**(2) 求换路后电流 $i_2(t)$：**

对顶端节点应用复频域 KCL：

$$\frac{V_A(s) - 1/s}{1} + \frac{V_A(s) + 0.4}{2/3 + 2s/3} + \frac{V_A(s)}{6 + 2s} = 0$$

整理化简该方程解出节点电压 $V_A(s)$：

$$V_A(s) \left[ 1 + \frac{3}{2(s+1)} + \frac{1}{2(s+3)} \right] = \frac{1}{s} - \frac{0.6}{s+1}$$

左括号内通分化简为 $\frac{(s+2)(s+4)}{(s+1)(s+3)}$，等式右侧通分为 $\frac{0.4s+1}{s(s+1)}$。

解得：$V_A(s) = \frac{(0.4s+1)(s+3)}{s(s+2)(s+4)}$。

右侧支路的电流（即 $i_2$ 的拉普拉斯变换）：

$$I_2(s) = \frac{V_A(s)}{6 + 2s} = \frac{V_A(s)}{2(s+3)} = \frac{0.4s+1}{2s(s+2)(s+4)} = \frac{0.2s+0.5}{s(s+2)(s+4)}$$

利用部分分式展开法：

$$I_2(s) = \frac{A}{s} + \frac{B}{s+2} + \frac{C}{s+4}$$

求得留数：

$A = \left. \frac{0.2s+0.5}{(s+2)(s+4)} \right|_{s=0} = \frac{0.5}{8} = 0.0625$

$B = \left. \frac{0.2s+0.5}{s(s+4)} \right|_{s=-2} = \frac{0.1}{-4} = -0.025$

$C = \left. \frac{0.2s+0.5}{s(s+2)} \right|_{s=-4} = \frac{-0.3}{8} = -0.0375$

反拉普拉斯变换回时域：

$$i_2(t) = \left( 0.0625 - 0.025e^{-2t} - 0.0375e^{-4t} \right) \varepsilon(t) \text{ A}$$
