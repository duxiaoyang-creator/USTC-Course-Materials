### 一、填空题

**1. 题目提取：** 电路如图1-1所示，图中电压 $u_1=$ ______， $u_2=$ ______ 。  

**详细解答：**

- **分析：** 观察图1-1，左侧回路包含 $6\text{V}$ 电压源、 $1\Omega$ 电阻和 $3\Omega$ 电阻；中间支路包含 $1\text{A}$ 电流源（方向向上）；右侧回路包含 $2\Omega$ 电阻、 $1\Omega$ 电阻和 $2\text{A}$ 电流源（方向向下）。设左侧网孔电流为 $i_1$（顺时针），右侧网孔电流为 $i_2$（顺时针）。
- 根据右侧支路的电流源，可知 $i_2 = 2\text{A}$。
- 根据中间支路的电流源，网孔电流满足 $i_1 - i_2 = -1\text{A}$，代入 $i_2$ 得 $i_1 = 1\text{A}$。
- **求 $u_1$：** 对左侧网孔列写KVL方程： $6\text{V} - i_1 \times 1\Omega - u_1 - i_1 \times 3\Omega = 0$。代入 $i_1 = 1\text{A}$，得到 $6 - 1 - u_1 - 3 = 0$，解得 **$u_1 = 2\text{V}$**。
- **求 $u_2$：** 对右侧网孔列写KVL方程： $u_1 - i_2 \times 2\Omega - u_2 - i_2 \times 1\Omega = 0$。代入 $u_1 = 2\text{V}$ 和 $i_2 = 2\text{A}$，得到 $2 - 4 - u_2 - 2 = 0$，解得 **$u_2 = -4\text{V}$**。

**2. 题目提取：** 电路如图1-2所示，当负载电阻 $R_L=$ ______ 时可获得最大功率，最大功率为 ______ 。  

**详细解答：**

- **分析：** 图1-2左侧是由三个完全相同的含源支路并联而成的网络。每个支路是一个 $2\text{V}$ 电压源与一个 $3\Omega$ 电阻串联。
- 利用诺顿等效，每个支路可等效为一个电流源 $I_s = \frac{2\text{V}}{3\Omega} = \frac{2}{3}\text{A}$ 和一个 $3\Omega$ 的并联电阻。
- 三个这样的支路并联，总等效电流源 $I_{eq} = 3 \times \frac{2}{3}\text{A} = 2\text{A}$，总等效并联电阻 $R_{eq} = 3\Omega \parallel 3\Omega \parallel 3\Omega = 1\Omega$。
- 再将其转换为戴维南等效电路：戴维南等效电压 $U_{oc} = I_{eq} \times R_{eq} = 2\text{V}$，戴维南等效电阻 $R_{th} = R_{eq} = 1\Omega$。
- 根据最大功率传输定理，当 **$R_L = R_{th} = 1\Omega$** 时，负载获得最大功率。
- 最大功率为 **$P_{max} = \frac{U_{oc}^2}{4 R_{th}} = \frac{2^2}{4 \times 1} = 1\text{W}$**。

**3. 题目提取：** 电路如图1-3所示，该电路的谐振角频率 $\omega_0=$ ______，品质因数 $Q=$ ______ 。  

**详细解答：**

- 

  **分析：** 观察图1-3，次级线圈接有一个 $0.5\text{mH}$ 的电感 。理想变压器的变比为 $2:1$（初级匝数比次级匝数） 。  

- 将次级侧的电感折算到初级侧，折算后的阻抗为 $Z' = n^2 Z_L = 2^2 \times (j\omega \times 0.5\text{mH}) = j\omega (2\text{mH})$。即折算后相当于在初级并联了一个 $2\text{mH}$ 的等效电感。

- 折算后的等效电感与原初级侧的 $2\text{mH}$ 电感并联，总等效电感 $L_{eq} = 2\text{mH} \parallel 2\text{mH} = 1\text{mH} = 10^{-3}\text{H}$。

- 整个电路简化为一个串联RLC电路： $R = 1\Omega$， $L_{eq} = 10^{-3}\text{H}$， $C = 10\mu\text{F} = 10^{-5}\text{F}$。

- 谐振角频率： **$\omega_0 = \frac{1}{\sqrt{L_{eq} C}} = \frac{1}{\sqrt{10^{-3} \times 10^{-5}}} = 10000 \text{ rad/s}$**。

- 串联谐振的品质因数： **$Q = \frac{\omega_0 L_{eq}}{R} = \frac{10000 \times 10^{-3}}{1} = 10$**。

**4. 题目提取：** 电路如图1-4所示，当开关S断开时，端口等效阻抗 $Z_{eq}=$ _____*，当开关闭合时，端口等效阻抗 $Z*{eq}=$ ______ 。  

**详细解答：**

- **开关S断开时：** 次级线圈开路，次级电流为0，互感不起作用。此时端口只看初级侧，等效阻抗为初级电阻和自感阻抗的串联： **$Z_{eq} = 1 + j3\ (\Omega)$**。

- 

  **开关S闭合时：** 次级线圈接通 $1\Omega$ 电阻 。已知 $Z_{11} = 1 + j3\ (\Omega)$，次级回路自阻抗 $Z_{22} = 1 + j2\ (\Omega)$ 。互感抗 $\omega M = 2\Omega$ 。  

- 利用去耦等效（反映阻抗法），次级回路对初级回路的反映阻抗为 $Z_r = \frac{(\omega M)^2}{Z_{22}} = \frac{2^2}{1 + j2} = \frac{4(1 - j2)}{1^2 + 2^2} = \frac{4 - j8}{5} = 0.8 - j1.6\ (\Omega)$。

- 由于次级回路是无源闭合回路，总输入等效阻抗等于初级自阻抗加上反映阻抗（反映阻抗始终为加上其值，与同名端无关）：

  **$Z_{eq} = Z_{11} + Z_r = (1 + j3) + (0.8 - j1.6) = 1.8 + j1.4\ (\Omega)$**。

**5. 题目提取：** 电路如图1-5所示，已知 $u_s(t)=40\cos(2t+12.5^\circ)\text{V}$。则RC串联电路的功率因数 $\lambda=$ ______，电压源 $u_s$ 发出的复功率 $\tilde{S}=$ ______ 。  

**详细解答：**

- 

  **分析：** $R = 12\Omega$ ， $C = \frac{1}{32}\text{F}$ ，角频率 $\omega = 2\text{ rad/s}$。  

- 电容阻抗 $Z_C = \frac{1}{j\omega C} = \frac{1}{j \times 2 \times (1/32)} = -j16\Omega$。总阻抗 $Z = R + Z_C = 12 - j16\ (\Omega)$。

- 阻抗的模 $|Z| = \sqrt{12^2 + (-16)^2} = 20\Omega$，阻抗角 $\phi_Z = \arctan(\frac{-16}{12}) = -53.13^\circ$。

- **求功率因数：** $\lambda = \cos(\phi_Z) = \cos(-53.13^\circ) = \frac{12}{20} =$ **$0.6$**。

- **求复功率：** 电压有效值相量 $\dot{U}_s = \frac{40}{\sqrt{2}} \angle 12.5^\circ\text{ V}$。

  复功率 $\tilde{S} = \frac{U_{rms}^2}{Z^*} = \frac{|\dot{U}_s|^2}{|Z|} \angle \phi_Z = \frac{(40/\sqrt{2})^2}{20} \angle -53.13^\circ = \frac{800}{20} \angle -53.13^\circ = 40 \angle -53.13^\circ\text{ VA}$。

  转换为直角坐标形式： **$\tilde{S} = 40(0.6 - j0.8) = 24 - j32\text{ (VA)}$**。

**6. 题目提取：** 电路如图1-6所示，已知网络N的网络函数 $H(j\omega)=\frac{\dot{U}_2}{\dot{U}_1}=\frac{1}{3+j\omega}$ 。则当 $u_1(t)=30\sqrt{2}\cos3t\text{ V}$ 时，正弦稳态响应 $u_2(t)=$ ______；当 $u_1(t)=\delta(t)\text{ V}$ 时，单位冲激响应 $u_2(t)=$ ______ 。  

**详细解答：**

- **求正弦稳态响应：** 输入信号角频率 $\omega = 3\text{ rad/s}$，相量 $\dot{U}_1 = 30\sqrt{2}\angle 0^\circ\text{ V}$。

  在该频率下的网络函数： $H(j3) = \frac{1}{3 + j3} = \frac{1}{3\sqrt{2}\angle 45^\circ} = \frac{1}{3\sqrt{2}} \angle -45^\circ$。

  输出相量 $\dot{U}_2 = \dot{U}_1 \times H(j3) = (30\sqrt{2}\angle 0^\circ) \times (\frac{1}{3\sqrt{2}}\angle -45^\circ) = 10\angle -45^\circ\text{ V}$。

  对应时域响应为： **$u_2(t) = 10\cos(3t - 45^\circ)\text{ V}$**。

- **求单位冲激响应：** 由频域网络函数可得拉普拉斯域传递函数 $H(s) = \frac{1}{s+3}$。

  进行拉普拉斯逆变换，得到时域单位冲激响应： **$u_2(t) = e^{-3t}\varepsilon(t)\text{ V}$** （其中 $\varepsilon(t)$ 为单位阶跃函数）。

### 二、计算题

**1. 题目提取：** 电路如图2-1所示，网络N为线性含源电阻网络，已知当 $I_{S1}=1\text{A}$, $I_{S2}=4\text{A}$ 时， $U_1=4\text{V}$；当 $I_{S1}=1\text{A}$, $I_{S2}=0$ 时， $U_1=2\text{V}$；当 $I_{S1}=0$, $I_{S2}=4\text{A}$ 时， $U_1=1\text{V}$。求当 $I_{S1}=2\text{A}$, $I_{S2}=8\text{A}$ 时电压 $U_2$ 的值 。  

**详细解答：**

- **利用叠加定理分析网络N：** 由于网络N是线性“含源”电阻网络，输出电压 $U_1$ 是两个外部独立源 $I_{S1}$、$I_{S2}$ 以及网络内部独立源共同作用的结果。设其线性关系为：

  $$U_1 = K_1 I_{S1} + K_2 I_{S2} + U_{10}$$

  将已知的三组数据代入该方程：

  (1) $K_1(1) + K_2(4) + U_{10} = 4$

  (2) $K_1(1) + K_2(0) + U_{10} = 2 \implies K_1 + U_{10} = 2$

  (3) $K_1(0) + K_2(4) + U_{10} = 1 \implies 4K_2 + U_{10} = 1$

- **求解系数：** 联立方程(2)和(3)代入(1)可得：

  $(2 - U_{10}) + (1 - U_{10}) + U_{10} = 4 \implies 3 - U_{10} = 4 \implies U_{10} = -1\text{V}$。

  进而得到： $K_1 = 3\text{ V/A}$， $K_2 = 0.5\text{ V/A}$。

  所以， $U_1$ 与激励的关系式为： $U_1 = 3I_{S1} + 0.5I_{S2} - 1$。

- **计算目标状态下的 $U_1$：** 当 $I_{S1}=2\text{A}$, $I_{S2}=8\text{A}$ 时：

  $$U_1 = 3(2) + 0.5(8) - 1 = 6 + 4 - 1 = 9\text{V}$$

- **分析 $U_1$ 与 $U_2$ 的关系：** 分析图2-1右侧电路拓扑：

  - 位于 $U_1$ 和压控电压源 $1.5U_1$ 之间的 $1\Omega$ 电阻上，电流 $I$ 向左流动。该支路电流 $I = \frac{1.5U_1 - U_1}{1} = 0.5U_1$。
  - 电路最右侧存在一个受控电流源 $5I$（方向向左），它抽取出右侧 $2\Omega$ 和 $3\Omega$ 并联支路的电流。
  - 对 $U_2$ 所在节点列写KCL：流向地面的总电流等于进入该节点的电流。由于 $5I$ 是向左抽出，即流入并联电阻的电流为 $-5I$。并联等效电阻为 $R_{eq} = 2\Omega \parallel 3\Omega = 1.2\Omega$。
  - 因此， $U_2 = (-5I) \times 1.2 = -6I$。
  - 代入 $I = 0.5U_1$，得到 $U_2 = -6(0.5U_1) = -3U_1$。

- **最终计算：** $U_2 = -3 \times 9\text{V} = -27\text{V}$。

  **答：电压 $U_2$ 的值为 -27V。**

**2. 题目提取：** 正弦稳态电路如图2-2所示，已知 $u_s(t)=8\sqrt{2}\cos5t\text{ V}$， $i_s(t)=4\sqrt{2}\cos5t\text{ A}$。(1) 画出电路的相量模型；(2) 求电流 $\dot{I}_1$ 和 $\dot{I}_2$ 。  

**详细解答：**

- **(1) 画出电路的相量模型：**

  - 角频率 $\omega = 5\text{ rad/s}$。

  - 独立电源的相量表示（有效值）： $\dot{U}_s = 8\angle 0^\circ\text{ V}$， $\dot{I}_s = 4\angle 0^\circ\text{ A}$。

  - 电感阻抗： $Z_L = j\omega L = j(5 \times 0.8) = j4\Omega$。

  - 电容阻抗： $Z_C = \frac{1}{j\omega C} = \frac{1}{j(5 \times 0.1)} = -j2\Omega$。

  - 受控源： $2\dot{I}$。

    （注：相量模型图是将原电路中所有时域元件替换为上述相量和复阻抗，此处省略画图步骤，文字描述已完整定义模型）。

- **(2) 求电流 $\dot{I}_1$ 和 $\dot{I}_2$：**

  设电路最下方导线为参考节点（接地，0V）。

  设电感和电容之间的节点电压为 $\dot{V}_3$。

  根据电路结构，受控电压源连接在两段含 $2\Omega$ 电阻的支路右侧，设其正极节点（上）为 $\dot{V}_4$，负极节点（下）为 $\dot{V}_5$。

  流过电容的电流相量 $\dot{I} = \frac{\dot{V}_3}{-j2} = j0.5\dot{V}_3$。

  受控电压源的方程为： $\dot{V}_4 - \dot{V}_5 = 2\dot{I} = j\dot{V}_3$。

  列写节点电压方程：

  - 在节点3（$\dot{V}_3$）处，KCL： $\frac{8 - \dot{V}_3}{j4} + \frac{\dot{V}_5 - \dot{V}_3}{2} = \frac{\dot{V}_3}{-j2}$。化简得： $\dot{V}_3(1 - j2) + j2\dot{V}_5 = -8$。

  - 将包含受控电压源的 $\dot{V}_4$ 和 $\dot{V}_5$ 视为超节点，列写超节点KCL： $\frac{8 - \dot{V}_4}{2} + \frac{\dot{V}_3 - \dot{V}_5}{2} = 4$（向右流出的独立电流源）。化简得： $\dot{V}_3 - \dot{V}_4 - \dot{V}_5 = 0$。

    联立方程解得：

  1. $\dot{V}_4 = \dot{V}_3 - \dot{V}_5$

  2. $(\dot{V}_3 - \dot{V}_5) - \dot{V}_5 = j\dot{V}_3 \implies \dot{V}_5 = 0.5(1-j)\dot{V}_3$

  3. $\dot{V}_3(1 - j2) + j2[0.5(1-j)\dot{V}_3] = -8 \implies \dot{V}_3(1 - j2 + j + 1) = -8 \implies \dot{V}_3(2 - j) = -8$

     解得： $\dot{V}_3 = \frac{-8}{2 - j} = -3.2 - j1.6\text{ V}$。

     进一步求得： $\dot{V}_5 = 0.5(1-j)(-3.2 - j1.6) = -2.4 + j0.8\text{ V}$。

     $\dot{V}_4 = \dot{V}_3 - \dot{V}_5 = -0.8 - j2.4\text{ V}$。

     利用节点电压计算支路电流：

     $\dot{I}_2 = \frac{8 - \dot{V}_4}{2} = \frac{8 - (-0.8 - j2.4)}{2} = 4.4 + j1.2\text{ A}$。

     $\dot{I}_L = \frac{8 - \dot{V}_3}{j4} = \frac{8 - (-3.2 - j1.6)}{j4} = 0.4 - j2.8\text{ A}$。

     $\dot{I}_1 = \dot{I}_L + \dot{I}_2 = (0.4 - j2.8) + (4.4 + j1.2) = 4.8 - j1.6\text{ A}$。

     **答：电流 $\dot{I}_1 = 4.8 - j1.6\text{ A}$， $\dot{I}_2 = 4.4 + j1.2\text{ A}$。**

**3. 题目提取：** 电路如图2-3所示，电路原处于稳态， $t=0$ 时开关S闭合，求换路后电压 $u_C(t)$ 。  

**详细解答：**

- **求解初始状态 $u_C(0^-)$ ($t < 0$)：**

  开关S断开，电路左右两部分分离，电路处于直流稳态。

  - 左侧回路：$8\text{V}$ 源、$2\Omega$、$4\Omega$ 和 $2i$ 受控源构成闭合回路。控制电流 $i$ 即为回路电流。KVL方程： $8 - 2i - 4i - 2i = 0 \implies 8i = 8 \implies i = 1\text{A}$。
  - 右侧回路：电容在直流稳态下相当于开路。因此 $1\Omega$ 支路无电流通过，其节点电压为 $0\text{V}$。电容所在支路由于开路没有电流，电容顶端节点电压经 $6\text{V}$ 源（上正下负）压降后，电容两端电压 $u_C(0^-) = 0 - 6\text{V} = -6\text{V}$。

- **求解最终状态 $u_C(\infty)$ 和时间常数 $\tau$ ($t \ge 0$)：**

  开关S闭合，使用戴维南等效电路法分析电容两端的等效电路。

  首先求断开包含 $6\text{V}$ 源和 $1\text{F}$ 电容支路后，其余电路在公共节点（设为Node 1）的等效参数。

  - **求开路电压 $V_{oc}$**：

    KCL于Node 1：流入的电流 = 流出的电流。 $\frac{8 - V_1}{2} = \frac{V_1 - 2i}{4} + \frac{V_1}{1}$。

    其中控制变量 $i = \frac{8 - V_1}{2}$。

    代入 $i$ 化简： $4 - 0.5V_1 = \frac{V_1 - (8 - V_1)}{4} + V_1 \implies 4 - 0.5V_1 = 1.5V_1 - 2 \implies 2V_1 = 6 \implies V_1 = 3\text{V}$。

    故 $V_{oc} = 3\text{V}$。

  - **求等效电阻 $R_{eq}$**：

    将 $8\text{V}$ 独立源置零（短路），在Node 1外加测试电压 $V_t$，此时 $i = \frac{0 - V_t}{2} = -0.5V_t$。

    流入Node 1的总电流 $I_t = \frac{V_t}{2} + \frac{V_t - 2i}{4} + \frac{V_t}{1} = 0.5V_t + \frac{V_t + V_t}{4} + V_t = 2V_t$。

    故 $R_{eq} = \frac{V_t}{I_t} = 0.5\Omega$。

  - 结合电容支路的 $6\text{V}$ 电源，从电容两端看进去的最终戴维南等效电压为 $u_C(\infty) = V_{oc} - 6\text{V} = 3 - 6 = -3\text{V}$。

  - 电路的等效电阻为 $0.5\Omega$，时间常数 $\tau = R_{eq} \times C = 0.5\Omega \times 1\text{F} = 0.5\text{s}$。

- **三要素法写出响应方程：**

  $u_C(t) = u_C(\infty) + [u_C(0^+) - u_C(\infty)] e^{-t/\tau} = -3 + [-6 - (-3)] e^{-t/0.5} = -3 - 3e^{-2t}$

  **答：换路后电压 $u_C(t) = -3 - 3e^{-2t}\text{ V} \ (t \ge 0)$。**

**4. 题目提取：** 电路如图2-4所示，电路原处于稳态， $t=0$ 时开关闭合。(1) 画出电路的复频域模型；(2) 求换路后电感电流 $i_L$ 。  

**详细解答：**

- **计算初始状态 ($t < 0$)：**

  开关S断开，直流稳态。电容开路，电感短路。

  电流源 $2\text{A}$ 全部向上流过 $2\Omega$ 电阻，由于电容开路，此电流必须通过右侧电感和 $4\Omega$ 电阻所在支路流向地。

  因此初始电感电流 $i_L(0^-) = 2\text{A}$（方向向右）。

  电感支路右侧接有 $12\text{V}$ 电压源，电感两端视为导线，故电容顶端节点电压 $V_C(0^-) = 12\text{V} + i_L(0^-) \times 4\Omega = 12 + 2 \times 4 = 20\text{V}$。

- **(1) 绘制复频域（s域）模型：**

  换路后（$t \ge 0$），开关S闭合，将 $2\text{A}$ 电流源短路。

  - 电容（$0.5\text{F}$）模型：阻抗 $\frac{1}{sC} = \frac{2}{s}$，串联附加初始电压源 $\frac{u_C(0^-)}{s} = \frac{20}{s}$（上正下负）。

  - 电感（$1\text{H}$）模型：阻抗 $sL = s$，串联附加初始电压源 $L i_L(0^-) = 2$（左正右负，与假定电流方向相反的电势升极性）。

  - 右侧独立电压源阶跃转化为 $\frac{12}{s}$。

    （复频域模型文字描述如上）。

- **(2) 求电感电流 $I_L(s)$ 及 $i_L(t)$：**

  设顶部公共节点电压为 $V(s)$。列写节点电压方程：

  $\frac{V(s) - 20/s}{2/s} + \frac{V(s)}{2} + \frac{V(s) + 2 - 12/s}{s + 4} = 0$

  化简过程：

  $\frac{s}{2} V(s) - 10 + 0.5 V(s) + \frac{V(s) + 2 - 12/s}{s + 4} = 0$

  $V(s) \left[ \frac{s + 1}{2} + \frac{1}{s + 4} \right] = 10 - \frac{2 - 12/s}{s + 4} = \frac{10s + 38 + 12/s}{s + 4}$

  $V(s) \left[ \frac{s^2 + 5s + 6}{2(s + 4)} \right] = \frac{10s^2 + 38s + 12}{s(s + 4)} \implies V(s) = \frac{20s^2 + 76s + 24}{s(s + 2)(s + 3)}$

  利用欧姆定律求电感电流：

  $I_L(s) = \frac{V(s) + 2 - 12/s}{s + 4} = \frac{\frac{20s^2 + 76s + 24 + 2s(s^2+5s+6) - 12(s^2+5s+6)}{s(s+2)(s+3)}}{s + 4} = \frac{2s^3 + 18s^2 + 28s - 48}{s(s+2)(s+3)(s+4)}$

  分子可因式分解： $2s^3 + 18s^2 + 28s - 48 = 2(s+4)(s^2+5s-6)$。

  约去 $(s+4)$：

  $I_L(s) = \frac{2(s^2+5s-6)}{s(s+2)(s+3)}$

  进行部分分式展开： $I_L(s) = \frac{-2}{s} + \frac{12}{s + 2} - \frac{8}{s + 3}$。

  进行拉普拉斯逆变换得到时域电流：

  **答： $i_L(t) = -2 + 12e^{-2t} - 8e^{-3t}\text{ (A)} \ (t \ge 0)$。**

**5. 题目提取：** 电路如图2-5所示，网络N为仅含线性电阻的二端口网络，已知当 $R\to\infty$ 时， $U_2=7.5\text{V}$；当 $R=0$ 时， $I_1=3\text{A}$， $I_2=-1\text{A}$。(1) 求二端口网络的传输参数矩阵；(2) 若电阻 $R=3\Omega$，求电流 $I_1$ 。  

**详细解答：**

- **(1) 求传输参数矩阵 (ABCD矩阵)：**

  传输参数方程为：

  $U_1 = A U_2 - B I_2$

  $I_1 = C U_2 - D I_2$

  (注意这里图中 $I_2$ 的方向是流入网络，因此传统公式中流出端口的负载电流为 $-I_2$)。

  已知无论如何接负载，输入端固定接在 $15\text{V}$ 电压源上，故 $U_1 \equiv 15\text{V}$。

  **状态一：** $R \to \infty$（输出端开路）， $I_2 = 0\text{A}$， $U_2 = 7.5\text{V}$。

  代入第一式： $15 = A(7.5) - B(0) \implies A = 2$。

  **状态二：** $R = 0$（输出端短路）， $U_2 = 0\text{V}$。测得 $I_1 = 3\text{A}$， $I_2 = -1\text{A}$。

  代入第一式： $15 = A(0) - B(-1) \implies B = 15\Omega$。

  代入第二式： $3 = C(0) - D(-1) \implies D = 3$。

  **利用互易定理：** 网络N仅由线性电阻组成，必然满足互易条件 $\Delta T = AD - BC = 1$。

  代入已知参数： $2 \times 3 - 15 \times C = 1 \implies 15C = 5 \implies C = \frac{1}{3}\text{ S}$。

  **答：传输参数矩阵为 $T = \begin{bmatrix} 2 & 15 \\ 1/3 & 3 \end{bmatrix}$。**

- **(2) 若 $R=3\Omega$，求电流 $I_1$：**

  当外接 $R=3\Omega$ 时，输出端口特性满足 $U_2 = -I_2 R = -3 I_2$。

  此时网络的输入阻抗 $Z_{in}$ 可通过传输参数求得：

  $Z_{in} = \frac{U_1}{I_1} = \frac{A U_2 - B I_2}{C U_2 - D I_2} = \frac{A(-I_2 R) - B I_2}{C(-I_2 R) - D I_2} = \frac{A R + B}{C R + D}$

  代入具体数值：

  $Z_{in} = \frac{2(3) + 15}{(1/3)(3) + 3} = \frac{6 + 15}{1 + 3} = \frac{21}{4} = 5.25\Omega$。

  已知 $U_1 = 15\text{V}$，则 $I_1 = \frac{U_1}{Z_{in}} = \frac{15}{21/4} = \frac{60}{21} = \frac{20}{7}\text{ A}$。

  **答：电流 $I_1 = \frac{20}{7}\text{ A}$。**
