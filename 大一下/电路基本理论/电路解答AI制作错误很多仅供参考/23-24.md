### 一、填空题

**1. 题目：** 电路如图1-1所示，图中电压 $U=$ _______ ；4V电压源发出的功率为 _______。 **解答：**  

- **电压 $U$ 的计算：** 设定下方的导线（连接1A电流源下端、4V电压源正极、6V电压源负极）为参考节点（$0\text{V}$）。
  - 根据6V电压源（左正右负），左下角的节点电压为 $6\text{V}$。
  - 最左侧支路的 $1\Omega$ 电阻与顶部的 $3\text{A}$ 电流源串联，因此流过 $1\Omega$ 电阻的电流必定为 $3\text{A}$（方向向上）。
  - 左上角节点的电压为 $V_{\text{左上}} = 6\text{V} - (3\text{A} \times 1\Omega) = 3\text{V}$。
  - 最右侧支路为4V电压源（上负下正），故右上角节点电压为 $V_{\text{右上}} = 0\text{V} - 4\text{V} = -4\text{V}$。
  - 3A电流源两端的电压 $U$（左正右负）为：$U = V_{\text{左上}} - V_{\text{右上}} = 3\text{V} - (-4\text{V}) = 7\text{V}$。
- **发出的功率计算：** 对于右上角节点列写KCL，流入该节点的电流为顶部支路的 $3\text{A}$ 和中间支路的 $1\text{A}$，因此流出该节点（即向下流过4V电压源）的电流为 $I = 3\text{A} + 1\text{A} = 4\text{A}$。
  - 该电流从4V电压源的负极流入、正极流出。
  - 4V电压源发出的功率为 $P = V \times I = 4\text{V} \times 4\text{A} = 16\text{W}$。

**2. 题目：** 电路如图1-2所示，已知 $I_{1}=2I_{2}$，则电阻 $R_{L}=$ _______。 **解答：**  

- 设右侧并联部分（$2\Omega$ 电阻与 $R_L$）的两端电压为 $V_2$。因 $I_2$ 为流过 $R_L$ 的电流，则 $V_2 = I_2 R_L$。

- 流过右侧 $2\Omega$ 并联电阻的电流为 $V_2 / 2 = 0.5 I_2 R_L$。

- 流过中间 $2\Omega$ 串联电阻的电流为 $I_{\text{串}} = I_2 + 0.5 I_2 R_L = I_2(1 + 0.5 R_L)$。

- 该 $2\Omega$ 串联电阻左侧节点的电压 $V_1 = V_2 + 2 \times I_{\text{串}} = I_2 R_L + 2 I_2(1 + 0.5 R_L) = I_2(2 R_L + 2)$。

- 流过左侧 $4\Omega$ 并联电阻的电流为 $V_1 / 4 = I_2(0.5 R_L + 0.5)$。

- 总输入电流 $I_1$ 等于左侧并联支路电流与串联支路电流之和：

  $I_1 = I_2(0.5 R_L + 0.5) + I_2(1 + 0.5 R_L) = I_2(R_L + 1.5)$。

- 已知 $I_1 = 2I_2$，故 $R_L + 1.5 = 2$，解得 $R_L = 0.5\Omega$。

**3. 题目：** 电路如图1-3所示，该电路的谐振角频率 $\omega_{0}=$ _______ ；品质因数 $Q=$ _______。 **解答：**  

- 这是一道考查**理想变压器阻抗变换**以及**并联谐振电路**的经典题目。我们可以通过求等效电路来快速得出答案。

  ### 一、 变压器阻抗折算（求等效电感）

  图中的变压器为理想变压器，匝数比为 $n = \frac{N_1}{N_2} = \frac{10}{1} = 10$。

  根据理想变压器的阻抗变换性质，副边（次级）的阻抗折算到原边（初级）时，需要乘以匝数比的平方 $n^2$。

  对于电感，其阻抗为 $Z_L = j\omega L$。折算到原边的等效电感 $L_{eq}$ 为：

  $$L_{eq} = n^2 L_{2} = 10^2 \times 25\mu\text{H} = 100 \times 25 \times 10^{-6}\text{ H} = 2.5 \times 10^{-3}\text{ H} = 2.5\text{ mH}$$

  ### 二、 等效电路分析

  经过折算后，整个电路可以看作是一个简单的 **$RLC$ 并联电路**。

  等效电路的参数为：

  - 电阻 $R = 1\text{ k}\Omega = 1000\Omega$
  - 电容 $C = 1\mu\text{F} = 1 \times 10^{-6}\text{ F}$
  - 等效电感 $L = 2.5\text{ mH} = 2.5 \times 10^{-3}\text{ H}$

  ### 三、 计算谐振角频率 $\omega_0$

  $RLC$ 并联电路发生谐振时，其谐振角频率公式为：

  $$\omega_0 = \frac{1}{\sqrt{LC}}$$

  将数值代入：

  $$\omega_0 = \frac{1}{\sqrt{2.5 \times 10^{-3} \times 1 \times 10^{-6}}}$$

  $$\omega_0 = \frac{1}{\sqrt{25 \times 10^{-10}}}$$

  $$\omega_0 = \frac{1}{5 \times 10^{-5}}$$

  $$\omega_0 = 20000 \text{ rad/s}$$

  ### 四、 计算品质因数 $Q$

  对于 $RLC$ 并联谐振电路，品质因数 $Q$ 的计算公式为：

  $$Q = \omega_0 R C \quad \text{或者} \quad Q = R\sqrt{\frac{C}{L}}$$

  使用第一个公式代入计算：

  $$Q = 20000 \times 1000 \times 1 \times 10^{-6} = 20$$

  ### 最终答案

  - 谐振角频率 $\omega_0 = \mathbf{20000 \text{ rad/s}}$
  - 品质因数 $Q = \mathbf{20}$

**4. 题目：** 电路如图1-4所示，若电路的暂态响应为临界阻尼状态，则电感 $L=$ _______。 **解答：**  

- 求发生暂态响应时LC所在回路的等效电阻。当独立电流源置零（开路）时，左侧串联的 $2\text{k}\Omega$ 电阻所在支路断开。
- 从电感和电容两端看进去的戴维南等效电阻为中间 $2\text{k}\Omega$ 和右侧 $4\text{k}\Omega$ 的串联，即 $R = 2\text{k}\Omega + 4\text{k}\Omega = 6000\Omega$。
- 该电路为RLC串联电路，临界阻尼的条件为衰减系数 $\alpha = \omega_0$，即 $\frac{R}{2L} = \frac{1}{\sqrt{LC}}$。
- 整理可得 $L = \frac{R^2 C}{4} = \frac{(6000)^2 \times 0.1 \times 10^{-6}}{4} = \frac{3600}{4000} \text{ (计算展开: } \frac{36 \times 10^6 \times 10^{-7}}{4}\text{)} = 0.9\text{H}$。

**5. 题目：** 电路如图1-5所示，已知电流 $I_{1}=5A$，$I_{2}=1A$，$I_{3}=2A$，电压 $U_{12}=10V$，$U_{14}=20V$，$U_{32}=5V$，则该四端网络吸收的功率为 _______。 **解答：**

  $I_{1\text{in}} + I_{2\text{in}} + I_{3\text{in}} + I_{4\text{in}} = 0 \implies 5\text{A} + (-1\text{A}) + (-2\text{A}) + I_{4\text{in}} = 0 \implies I_{4\text{in}} = -2\text{A}$。

  - $V_1 = U_{12} + V_2 = 10\text{V}$。
  - $V_3 = U_{32} + V_2 = 5\text{V}$。

- 网络吸收的总功率 $P = \sum V_k I_{k\text{in}} = (10\text{V} \times 5\text{A}) + (0\text{V} \times -1\text{A}) + (5\text{V} \times -2\text{A}) + (-10\text{V} \times -2\text{A}) = 50 + 0 - 10 + 20 = 60\text{W}$。

  ### **第 4 题解析**

  **题目目标：** 求解使电路暂态响应处于临界阻尼状态时的电感 $L$ 值。

  **步骤 1：求暂态响应的等效电路**

  暂态响应（自然响应）的特性仅由电路的结构和无源元件决定。因此，我们需要将电路中的独立电源置零，求出储能元件（$L$ 和 $C$）所“看”到的等效阻抗：

  - 电路最左侧是一个独立的电流源 $\varepsilon(t)\text{ A}$。将其置零，即令电流为 0，相当于**开路**。
  - 左侧支路开路后，与其串联的左上方 $2\text{ k}\Omega$ 电阻中也没有电流流过，相当于从电路中断开。
  - 剩余的部分形成了一个单一的闭合回路：中间的 $2\text{ k}\Omega$ 电阻、右上的 $4\text{ k}\Omega$ 电阻、电感 $L$ 以及电容 $0.1\mu\text{F}$。
  - 这四个元件首尾相连，构成了一个**串联 RLC 回路**。

  回路的总等效电阻为：

  $$R_{eq} = 2\text{ k}\Omega + 4\text{ k}\Omega = 6\text{ k}\Omega = 6000\ \Omega$$

  **步骤 2：应用临界阻尼条件**

  对于串联 RLC 电路，发生临界阻尼的条件是衰减常数 $\alpha$ 等于谐振角频率 $\omega_0$：

  $$\alpha = \frac{R}{2L} \quad, \quad \omega_0 = \frac{1}{\sqrt{LC}}$$

  $$\frac{R}{2L} = \frac{1}{\sqrt{LC}} \implies \frac{R^2}{4L^2} = \frac{1}{LC} \implies L = \frac{R^2 C}{4}$$

  **步骤 3：代入数据计算**

  已知 $R = 6000\ \Omega$，$C = 0.1\mu\text{F} = 0.1 \times 10^{-6}\text{ F}$，代入公式：

  $$L = \frac{(6000)^2 \times 0.1 \times 10^{-6}}{4}$$

  $$L = \frac{36000000 \times 10^{-7}}{4} = \frac{3.6}{4} = 0.9\text{ H}$$

  **答案：** **$0.9\text{ H}$**

  ### **第 5 题解析**

  **题目目标：** 计算该四端网络吸收的总功率。

  **步骤 1：确定所有流入网络的节点电流**

  根据基尔霍夫电流定律（KCL），流入四端网络的总电流必须等于零。我们规定**流入**网络的方向为正：

  - 节点 1：电流 $I_1$ 流入，所以 $I_{in,1} = 5\text{ A}$。

  - 节点 2：电流 $I_2$ 流出，所以 $I_{in,2} = -1\text{ A}$。

  - 节点 3：电流 $I_3$ 流出，所以 $I_{in,3} = -2\text{ A}$。

  - 节点 4：设流入电流为 $I_{in,4}$。

    由 KCL 得：$I_{in,1} + I_{in,2} + I_{in,3} + I_{in,4} = 0$

    $$5 - 1 - 2 + I_{in,4} = 0 \implies I_{in,4} = -2\text{ A}$$

  **步骤 2：确定各节点的电位**

  我们可以任选一个节点作为参考电位（0V），这不会影响最终功率的计算结果。我们不妨选取**节点 4 作为参考地**，即 $V_4 = 0\text{ V}$。

  根据题目给出的电压关系（注：$U_{ab} = V_a - V_b$）：

  - $U_{14} = 20\text{V} \implies V_1 - V_4 = 20 \implies V_1 = 20\text{ V}$
  - $U_{12} = 10\text{V} \implies V_1 - V_2 = 10 \implies 20 - V_2 = 10 \implies V_2 = 10\text{ V}$
  - $U_{32} = 5\text{V} \implies V_3 - V_2 = 5 \implies V_3 - 10 = 5 \implies V_3 = 15\text{ V}$

  **步骤 3：计算网络吸收的总功率**

  多端网络吸收的总功率等于各节点电位与流入该节点电流的乘积之和（满足关联参考方向）：

  $$P_{abs} = V_1 I_{in,1} + V_2 I_{in,2} + V_3 I_{in,3} + V_4 I_{in,4}$$

  代入数值：

  $$P_{abs} = (20\text{ V} \times 5\text{ A}) + (10\text{ V} \times (-1\text{ A})) + (15\text{ V} \times (-2\text{ A})) + (0\text{ V} \times (-2\text{ A}))$$

  $$P_{abs} = 100 - 10 - 30 + 0 = 60\text{ W}$$

  **答案：** **$60\text{ W}$**

### 二、计算题

**1. 题目：** 电路如图2-1所示，求负载电阻 $R_{L}$ 为何值时可获得最大功率，求出此最大功率。 (10分) **解答：**  

1. **求开路电压 $U_{oc}$：** 断开 $R_L$，此时端子开路，流向负载的电流为0。
   - 控制电流 $i$ 流向开路端，因此 $i = 0$。受控电流源 $3i = 0$。
   - 由于无电流流过右侧 $2\Omega$ 电阻，输出端开路电压即为受控源左侧节点（设为A点）的电压。
   - 此时A点仅为左侧电源与电阻的分压：$V_A = 20\text{V} \times \frac{20\Omega}{30\Omega + 20\Omega} = 8\text{V}$。
   - 因此，$U_{oc} = 8\text{V}$。
2. **求短路电流 $I_{sc}$：** 将 $R_L$ 两端短路，输出端电压为 $0\text{V}$。
   - 流过 $2\Omega$ 电阻的电流 $i = V_A / 2$。
   - 对节点A列写KCL：流入A的电流等于流出A的电流，即 $\frac{20 - V_A}{30} + 3i = \frac{V_A}{20} + i$。
   - 代入 $i = V_A / 2$，得 $\frac{20 - V_A}{30} + \frac{3V_A}{2} = \frac{V_A}{20} + \frac{V_A}{2}$，整理得 $\frac{20}{30} = V_A (\frac{1}{20} + \frac{1}{30} - 1)$，即 $\frac{2}{3} = - \frac{11}{12} V_A$。
   - 解得 $V_A = -\frac{8}{11}\text{V}$。
   - 短路电流为流过输出端的净电流：$I_{sc} = i - 3i = -2i = -2 \times (-\frac{8/11}{2}) = \frac{8}{11}\text{A}$。
3. **求戴维南等效电阻及最大功率：**
   - $R_{eq} = \frac{U_{oc}}{I_{sc}} = \frac{8}{8/11} = 11\Omega$。
   - 当 **$R_L = R_{eq} = 11\Omega$** 时获得最大功率。
   - 最大功率 $P_{\max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{8^2}{4 \times 11} = \frac{16}{11}\text{W} \approx 1.45\text{W}$。

**2. 题目：** 电路如图2-2所示，电路原处于稳态，$t=0$ 时开关闭合，求换路后电流 $i_{L}$ 的变化规律，指出的强制分量与自由分量。 (12分) **解答：**  

1. **求初始值 $i_L(0^+)$：**
   - $t < 0$ 时，开关断开，电路处于直流稳态，电感视为短路。
   - 左侧 $20\text{mA}$ 电流源与其并联的 $1\text{k}\Omega$ 电阻可等效为 $20\text{V}$ 电压源串联 $1\text{k}\Omega$ 电阻。
   - 电感所在支路无其他电源，稳态电流 $i_L(0^-) = \frac{20\text{V}}{1\text{k}\Omega + 1\text{k}\Omega} = 10\text{mA}$。
   - 根据换路定则， $i_L(0^+) = i_L(0^-) = 10\text{mA}$。
2. **求稳态值 $i_L(\infty)$ 及时间常数 $\tau$：**
   - $t \ge 0$ 时，开关闭合，右侧 $10\text{V}$ 电源及 $1\text{k}\Omega$ 电阻接入电感节点。
   - 计算电感看进去的戴维南等效电路。左侧等效为 $20\text{V}$ 电源串联 $2\text{k}\Omega$ 电阻，右侧为 $10\text{V}$ 电源串联 $1\text{k}\Omega$ 电阻。
   - 开路电压（节点电位）：$\frac{V - 20}{2\text{k}} + \frac{V - 10}{1\text{k}} = 0 \implies V = \frac{40}{3}\text{V}$。
   - 等效电阻 $R_{eq} = 2\text{k}\Omega \parallel 1\text{k}\Omega = \frac{2}{3}\text{k}\Omega$。
   - 稳态电流 $i_L(\infty) = \frac{V}{R_{eq}} = \frac{40/3\text{V}}{2/3\text{k}\Omega} = 20\text{mA}$。
   - 时间常数 $\tau = \frac{L}{R_{eq}} = \frac{2\text{mH}}{\frac{2}{3}\text{k}\Omega} = 3 \times 10^{-6}\text{s}$。
3. **写出响应方程：**
   - 根据三要素法：$i_L(t) = i_L(\infty) + [i_L(0^+) - i_L(\infty)]e^{-t/\tau} = 20 - 10 e^{-\frac{t}{3\times 10^{-6}}} \text{ (mA)}$。
   - **强制分量** 为稳态部分：$20\text{mA}$。
   - **自由分量** 为暂态部分：$-10 e^{-\frac{t}{3\times 10^{-6}}} \text{ mA}$。

**3. 题目：** 电路如图2-3所示，二端口网络N内仅含线性电阻。若 $I_{s1}=5A$，$U_{S2}=0$ 时测得 $U_{1}=20V$，$I_{2}=-1A$；而 $I_{s1}=0$，$U_{S2}=40V$ 时测得 $I_{2}=2A$。求：(1)二端口网络的H参数；(2)若 $U_{1}=50V$，$I_{2}=5A$，则 $I_{S1}$ 和 $U_{S2}$ 应为何值？ (12分) **解答：** 二端口网络的H参数方程为： $U_1 = h_{11}I_1 + h_{12}U_2$ $I_2 = h_{21}I_1 + h_{22}U_2$ 其中输入输出条件对应为：$I_1 = I_{s1}$，$U_2 = U_{S2}$。  

1. **求H参数：**

   - 当 $I_1 = 5\text{A}, U_2 = 0\text{V}$ 时，$U_1 = 20\text{V}, I_2 = -1\text{A}$。代入方程得：

     $20 = h_{11}(5) + 0 \implies h_{11} = 4\Omega$。

     $-1 = h_{21}(5) + 0 \implies h_{21} = -0.2$。

   - 当 $I_1 = 0\text{A}, U_2 = 40\text{V}$ 时，$I_2 = 2\text{A}$。代入第二方程得：

     $2 = 0 + h_{22}(40) \implies h_{22} = 0.05\text{S}$。

   - 因为网络内仅含线性电阻，网络具有互易性。H参数的互易条件为 $h_{12} = -h_{21}$，所以 $h_{12} = 0.2$。

   - 即H参数矩阵为 $\begin{bmatrix} 4\Omega & 0.2 \\ -0.2 & 0.05\text{S} \end{bmatrix}$。

2. **求解新状态下的激励：**

   - 已知 $U_1 = 50\text{V}$， $I_2 = 5\text{A}$，代入方程得方程组：

     $50 = 4I_{S1} + 0.2U_{S2}$

     $5 = -0.2I_{S1} + 0.05U_{S2}$

   - 解得：$I_{S1} = 6.25\text{A}$， $U_{S2} = 125\text{V}$。

**4. 题目：** 正弦稳态电路如图2-4所示，(1)画出电路的相量模型；(2)求网络函数 $H(j\omega)=\dot{U}_{2}/\dot{U}_{1}$；(3)定性画出幅频特性曲线(标出关键点)，说明网络的特性(低通、高通、带通、带阻)。 (16分) **解答：**  

1. **相量模型：**

   - 将所有变量表示为相量：$u_1 \to \dot{U}_1$，$u_2 \to \dot{U}_2$，$u_3 \to \dot{U}_3$。
   - 电阻 $1\Omega$ 阻抗为 $1$；两个 $1\text{F}$ 电容阻抗均替换为 $1/(j\omega)$。
   - 受控电压源表示为 $2\dot{U}_2$，受控电流源表示为 $2\dot{U}_3$。

2. **求网络函数：**

   - 电容 $C_1$ 上电压 $\dot{U}_3$（左正右负）的节点方程：电容右侧节点与受控电压源 $2\dot{U}_2$ 相连，故 $\dot{U}_3 = \dot{U}_1 - 2\dot{U}_2$。

   - 对输出节点（$\dot{U}_2$）列写KCL：

     流进该节点的电流包括通过电阻的电流 $\frac{\dot{U}_1 - \dot{U}_2}{1}$ 和受控电流源提供的电流 $2\dot{U}_3$。

     流出该节点的电流为通过负载电容的电流 $\frac{\dot{U}_2}{1/(j\omega)} = j\omega\dot{U}_2$。

     $\dot{U}_1 - \dot{U}_2 + 2\dot{U}_3 = j\omega\dot{U}_2$

   - 将 $\dot{U}_3$ 表达式代入：

     $\dot{U}_1 - \dot{U}_2 + 2(\dot{U}_1 - 2\dot{U}_2) = j\omega\dot{U}_2 \implies 3\dot{U}_1 - 5\dot{U}_2 = j\omega\dot{U}_2$

   - 整理得到网络函数：$H(j\omega) = \frac{\dot{U}_2}{\dot{U}_1} = \frac{3}{5 + j\omega}$。

3. **幅频特性及网络特性：**

   - 该函数标准形式为一阶低通滤波器，幅频特性 $|H(j\omega)| = \frac{3}{\sqrt{25 + \omega^2}}$。
   - **关键点：** 当 $\omega=0$ 时，增益达到最大值 $|H(0)| = 0.6$；当 $\omega = 5 \text{ rad/s}$（截止频率）时，增益下降为 $|H(j5)| = \frac{0.6}{\sqrt{2}} \approx 0.424$；当 $\omega \to \infty$ 时，增益趋于 $0$。
   - **网络特性：** **低通滤波器**。

**5. 题目：** 电路如图2-5所示，电路原处于稳态，t=0时开关S闭合。(1)画出电路的复频域模型；(2)求换路后电压 $u_2$ 和电流 $i_1$ 的变化规律。 (17分) **解答：**  

1. **初始状态分析及复频域模型绘制：**

   - $t < 0$ 时，系统处于稳态，电容相当于开路。左侧电路通过分压计算 $u_1(0^-)$，右侧独立放电使得 $u_2(0^-) = 0\text{V}$。
   - 左侧两个串联的 $3\Omega$ 电阻将 $6\text{V}$ 电压等分，因此电容 $C_1$ 两端初始电压 $u_1(0^-) = 6\text{V} \times \frac{3}{3+3} = 3\text{V}$。
   - 复频域（s域）模型替换：直流电压源变为 $6/s$；电容变为 $1/(2s)$ 的阻抗。为了体现 $C_1$ 的初始状态，在其支路串联一个极性向上的电压源 $u_1(0)/s = 3/s$；$C_2$ 初始电压为0，无附加电源。

2. **求解 $u_2(t)$ 和 $i_1(t)$：**

   - 设 $C_1$ 上方节点为 A（电压 $U_A(s)$），$C_2$ 上方节点为 B（电压 $U_B(s)$）。

   - 闭合开关后，支路有6V电源，因此 $U_A(s) - U_B(s) = 6/s \implies U_B(s) = U_A(s) - 6/s$。

   - 对节点 A 和 B 采用节点分析法（合并成超节点或分别代换），整理出KCL方程：

     $\frac{U_A - 6/s}{3} + \frac{U_A}{3} + \frac{U_A - 3/s}{1/(2s)} + \frac{U_B}{1/(2s)} + \frac{U_B}{3} = 0$

   - 代入 $U_B(s)$，解得：

     $(4s + 1)U_A(s) = 18 + \frac{4}{s} \implies U_A(s) = \frac{18s+4}{s(4s+1)}$

     $U_B(s) = U_A(s) - \frac{6}{s} = \frac{-6s-2}{s(4s+1)} = \frac{-1.5s - 0.5}{s(s+0.25)}$

   - 对 $U_2(s) = U_B(s)$ 进行部分分式展开：

     $U_2(s) = -\frac{2}{s} + \frac{0.5}{s+0.25}$。

     反拉普拉斯变换：$u_2(t) = -2 + 0.5 e^{-0.25t} \text{ (V)}$  ($t > 0$)。

   - $I_1(s)$ 是流经左侧电容 $C_1$ 的电流（向下），由导纳及两端压降决定：

     $I_1(s) = \frac{U_A(s) - 3/s}{1/(2s)} = 2s U_A(s) - 6 = \frac{12s+2}{4s+1} = \frac{3s+0.5}{s+0.25}$

   - 对其展开：

     $I_1(s) = 3 - \frac{0.25}{s+0.25}$。

     反拉普拉斯变换：$i_1(t) = 3\delta(t) - 0.25 e^{-0.25t} \text{ (A)}$  ($t \ge 0$)。（注：由于开关瞬间接通包含理想电压源的容性回路，故引起脉冲电流）。

**6. 题目：** 正弦电流电路如图2-6所示，已知三个电流表读数均为1A，$1/\omega C=15\Omega$，$\omega M=5\Omega$，全电路吸收的有功功率 $P=13.66 W$，无功功率 $Q=3.661$ var(感性)，试求各参数值 $R_1$、$R_2$、$\omega L_1$、$\omega L_2$ 及端口电压有效值 $U_S$。 (12分) **解答：**  

- 设总电流 $\dot{I}_1 = 1\angle 0^\circ \text{A}$。根据KCL，支路2与支路3的相量和为 $\dot{I}_1$，且有效值 $|I_2| = |I_3| = 1\text{A}$，故它们构成等边三角形。

- 电容支路(3)呈容性，判断得知 $\dot{I}_3$ 超前，取 $\dot{I}_3 = 1\angle 60^\circ\text{A}$，则 $\dot{I}_2 = 1\angle -60^\circ\text{A}$。

- 并联段端电压 $\dot{U}_p = \dot{I}_3 \times (-j15) = (1\angle 60^\circ)(15\angle -90^\circ) = 15\angle -30^\circ\text{V} = 12.99 - j7.5 \text{ V}$（精确值为 $\frac{15\sqrt{3}}{2} - j\frac{15}{2}$）。

- 注意互感同名端：$L_1$ 的同名端在流入侧，$L_2$ 的同名端在流出侧。因此 $I_1$ 在 $L_2$ 上产生的互感电势为 $-j\omega M \dot{I}_1$。

  支路2电压方程：$\dot{U}_p = (R_2 + j\omega L_2)\dot{I}_2 - j\omega M \dot{I}_1$。

  $(R_2 + j\omega L_2)\dot{I}_2 = 15\angle -30^\circ + j5 = \frac{15\sqrt{3}}{2} - j2.5$。

  $R_2 + j\omega L_2 = \frac{\frac{15\sqrt{3}}{2} - j2.5}{1\angle -60^\circ} = 5\sqrt{3} + j10$。

  由此可得：**$R_2 = 5\sqrt{3} \approx 8.66\Omega$**，**$\omega L_2 = 10\Omega$**。

- 利用全电路有功功率 $P = 13.66\text{W}$，由于 $P = I_1^2 R_1 + I_2^2 R_2$：

  $13.66 = 1^2 R_1 + 1^2 (8.66) \implies $ **$R_1 = 5\Omega$**。

- 利用全电路感性无功功率 $Q = 3.661\text{var}$ 计算 $\omega L_1$。

  总复功率 $S = P + jQ = \dot{U}_S \dot{I}_1^*$，所以输入端口电压 $\dot{U}_S = 13.66 + j3.661 \text{ V}$。

  端口电压有效值 **$U_S = \sqrt{13.66^2 + 3.661^2} = 14.14\text{V}$**（准确值为 $10\sqrt{2}\text{V}$）。

  根据输入方程：$\dot{U}_S = (R_1 + j\omega L_1)\dot{I}_1 - j\omega M \dot{I}_2 + \dot{U}_p$，

  虚部匹配可求出：**$\omega L_1 = 5 + 5\sqrt{3} \approx 13.66\Omega$**。
