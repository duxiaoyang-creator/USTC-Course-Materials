1. 电路如图1-1所示，图中电阻 $R=$ ___， $4\Omega$ 电阻消耗的功率为 ___ 。  

- **解析：**
  - 由KCL（基尔霍夫电流定律）可知，从左侧输入的总电流等于右侧流出的总电流，即 $I_{total} = 0.7\text{ A} + 0.3\text{ A} = 1.0\text{ A}$。
  - 已知上方支路流入 $3\Omega$ 电阻的电流为 $0.6\text{ A}$，则下方支路流入 $4\Omega$ 电阻的电流为 $1.0\text{ A} - 0.6\text{ A} = 0.4\text{ A}$。
  - $4\Omega$ 电阻消耗的功率为 $P = I^2 R = (0.4)^2 \times 4 = 0.64\text{ W}$。
  - 分析右侧节点：上方节点流出 $0.7\text{ A}$，流入 $0.6\text{ A}$，根据KCL，必须有 $0.1\text{ A}$ 的电流从下方节点经电阻 $R$ 流向上方节点。
  - 设左侧输入节点电压为 $V_{in}$，则上方节点电压 $V_{top} = V_{in} - 0.6 \times 3 = V_{in} - 1.8\text{ V}$。
  - 下方节点电压 $V_{bot} = V_{in} - 0.4 \times 4 = V_{in} - 1.6\text{ V}$。
  - 电阻 $R$ 两端的电压差为 $V_{bot} - V_{top} = (V_{in} - 1.6) - (V_{in} - 1.8) = 0.2\text{ V}$。
  - 因此，电阻 $R = \frac{U_R}{I_R} = \frac{0.2}{0.1} = 2\Omega$。
- **答案：** $2\Omega$；$0.64\text{ W}$
- 直流稳态电路如图1-2所示，电路中电容的储能为 ___，电感的储能为 ___ 。  

- **解析：**
  - 在直流稳态下，电容相当于开路，电感相当于短路。
  - 电路退化为一个单回路：$30\text{ V}$ 电源、$5\Omega$ 电阻（左侧）与 $5\Omega$ 电阻（右侧）串联（中间电容支路无电流，顶部电感短路）。
  - 回路电流 $I = \frac{30}{5 + 5} = 3\text{ A}$。
  - 流过 $1\text{H}$ 电感的电流即为回路电流，因此电感储能 $W_L = \frac{1}{2} L I^2 = \frac{1}{2} \times 1 \times 3^2 = 4.5\text{ J}$。
  - 电容并联在中间节点和地（底部导线）之间。设底部导线为 $0\text{ V}$，电源负极侧（即右侧 $5\Omega$ 电阻上方节点）的电位受电流方向影响（电流从右侧电阻向上流，经电感回到电源负极）。
  - 根据KCL和KVL，电流从地（$0\text{ V}$）流经右侧 $5\Omega$ 电阻向上，因此右上方节点电压 $V_R = -3\text{ A} \times 5\Omega = -15\text{ V}$。由于电感短路，电容上端的电压等于 $V_R = -15\text{ V}$。
  - 电容两端电压绝对值为 $15\text{ V}$，电容储能 $W_C = \frac{1}{2} C U^2 = \frac{1}{2} \times 0.2 \times (-15)^2 = 22.5\text{ J}$。
- **答案：** $22.5\text{ J}$；$4.5\text{ J}$
- 电路如图1-3所示，已知 $R_{L}=1\Omega$，理想变压器的匝数比 $n=$ ___ 时，电阻 $R_{L}$ 可获得最大功率，最大功率为 ___ 。  

- **解析：**
  - 根据最大功率传输定理，当负载折算到原边的等效电阻等于原边电源的内阻时，负载获得最大功率。
  - 原边电源为戴维南等效电路：$R_{eq} = 100\Omega$，等效电压 $U_{oc} = 0.1\text{ A} \times 100\Omega = 10\text{ V}$。
  - 副边负载折算到原边的等效电阻 $R'_L = n^2 R_L = n^2 \times 1 = n^2$。
  - 令 $n^2 = 100\Omega$，解得 $n = 10$。
  - 最大功率 $P_{max} = \frac{U_{oc}^2}{4 R_{eq}} = \frac{10^2}{4 \times 100} = \frac{100}{400} = 0.25\text{ W}$。
- **答案：** $10$；$0.25\text{ W}$
- 电路如图1-4所示，开关闭合时，端口等效电感 $L_{eq}=$ __*；开关S断开时，端口等效电感 $L*{eq}=$ ___ 。  

- **解析：**

  - 已知两线圈 $L_1 = 2\text{H}$，$L_2 = 1\text{H}$，互感 $M = 0.5\text{H}$。

  - **开关S闭合时**：$L_2$ 被短路，其两端电压 $u_2 = 0$。

    根据耦合电感方程（注意同名端：$L_1$ 电流流入同名端，$L_2$ 短路环路电流流出同名端，互感取负）：

    $u_1 = L_1 \frac{di_1}{dt} - M \frac{di_2}{dt}$

    $u_2 = L_2 \frac{di_2}{dt} - M \frac{di_1}{dt} = 0 \Rightarrow \frac{di_2}{dt} = \frac{M}{L_2} \frac{di_1}{dt} = 0.5 \frac{di_1}{dt}$

    代入 $u_1$ 得：$u_1 = (2 - 0.5 \times 0.5) \frac{di_1}{dt} = 1.75 \frac{di_1}{dt}$。等效电感 $L_{eq} = 1.75\text{ H}$。

  - **开关S断开时**：两电感异名端串联。

    等效电感 $L_{eq} = L_1 + L_2 - 2M = 2 + 1 - 2(0.5) = 2\text{ H}$。

- **答案：** $1.75\text{ H}$；$2\text{ H}$

- 电路如图1-5所示，正弦电压源有效值为 $220\text{V}$，频率 $f=50\text{Hz}$，若向 $R$、$L$ 负载提供有功功率 $P=55\text{ W}$，无功功率 $Q=55\sqrt{3}\text{ var}$，则电阻 $R=$ ___，电感 $L=$ ___ 。  

- **解析：**
  - 视在功率 $S = \sqrt{P^2 + Q^2} = \sqrt{55^2 + (55\sqrt{3})^2} = 55 \times 2 = 110\text{ VA}$。
  - 由 $S = U \times I$ 得，电流有效值 $I = \frac{110}{220} = 0.5\text{ A}$。
  - 有功功率 $P = I^2 R \Rightarrow 55 = (0.5)^2 R \Rightarrow R = \frac{55}{0.25} = 220\Omega$。
  - 无功功率 $Q = I^2 X_L \Rightarrow 55\sqrt{3} = (0.5)^2 X_L \Rightarrow X_L = 220\sqrt{3}\Omega$。
  - 又 $X_L = 2\pi f L = 100\pi L$，故 $L = \frac{220\sqrt{3}}{100\pi} = \frac{11\sqrt{3}}{5\pi}\text{ H}$。
- **答案：** $220\Omega$；$\frac{11\sqrt{3}}{5\pi}\text{ H}$ (或近似 $1.21\text{ H}$)
- 电路如图1-6所示，已知 $R=100\Omega$， $L=2\text{ mH}$， $C=0.04\text{ }\mu\text{F}$，则该电路的谐振角频率 $\omega_{0}=$ __*，谐振时端口等效电阻 $R*{0}=$ ___ 。  

- **解析：**
  - 实际电感线圈（$R$与$L$串联）与电容$C$并联的谐振电路。
  - 导纳 $Y = j\omega C + \frac{1}{R + j\omega L} = \frac{R}{R^2 + (\omega L)^2} + j\left(\omega C - \frac{\omega L}{R^2 + (\omega L)^2}\right)$。
  - 谐振时虚部为零：$\omega_0 C = \frac{\omega_0 L}{R^2 + (\omega_0 L)^2} \Rightarrow R^2 + \omega_0^2 L^2 = \frac{L}{C}$。
  - 代入数据：$L/C = \frac{2 \times 10^{-3}}{0.04 \times 10^{-6}} = 50000$。
  - $\omega_0^2 = \frac{1}{LC} - (\frac{R}{L})^2 = 1.25 \times 10^{10} - \frac{10000}{4 \times 10^{-6}} = 10^{10}$。得 $\omega_0 = 10^5\text{ rad/s}$。
  - 谐振时导纳实部 $G_0 = \frac{R}{R^2 + (\omega_0 L)^2} = \frac{R}{L/C}$，等效电阻 $R_0 = \frac{1}{G_0} = \frac{L/C}{R} = \frac{50000}{100} = 500\Omega$。
- **答案：** $10^5\text{ rad/s}$；$500\Omega$

1. 电路如图2-1所示，求电路中两个独立电源各自发出的功率 。  

- **详细解析：**

  设电路底部导线为参考节点（$0\text{V}$）。

  - $2\text{V}$ 电压源的正极节点（记为 $B$ 点）电压 $V_B = 2\text{V}$。

  - 左侧 $0.5\Omega$ 电阻上的电压即为其上方节点（记为 $A$ 点）电压 $V_A = U_1$。

  - 右侧 $1\Omega$ 电阻上的电压即为其上方节点（记为 $C$ 点）电压 $V_C = U_2$。

  - 根据KCL对节点 $C$ 列方程：

    进入 $C$ 点的电流有两路：经中间 $0.5\Omega$ 电阻来自 $B$ 点的电流，以及经上方受控电压源 $4U_2$ 流来的电流 $I_{4U2}$。

    $\frac{V_B - V_C}{0.5} + I_{4U2} = \frac{V_C}{1}$

    因 $V_B = 2\text{V}, V_C = U_2$，代入得：$\frac{2 - U_2}{0.5} + I_{4U2} = U_2 \Rightarrow 4 - 2U_2 + I_{4U2} = U_2 \Rightarrow I_{4U2} = 3U_2 - 4$ （式1）

  - 设电路顶部节点为 $D$，电压为 $V_D$。$4U_2$ 受控源两端电压为 $V_D - V_C = 4U_2$，即 $V_D - U_2 = 4U_2 \Rightarrow V_D = 5U_2$。

  - 对节点 $D$ 列KCL方程：

    受控电流源 $2U_1$ 提供向上流入 $D$ 的电流；左侧 $1\Omega$ 支路流出电流为 $\frac{V_D - V_A}{1}$；向右流向受控电压源的电流为 $I_{4U2}$。

    $2U_1 = \frac{V_D - U_1}{1} + I_{4U2}$ （式2）

  - 对节点 $A$ 列KCL方程：

    从 $B$ 点流入的 $2\text{A}$ 电流，加上从 $D$ 点经 $1\Omega$ 流入的电流，等于流向下方的电流：

    $2 + \frac{V_D - U_1}{1} = \frac{U_1}{0.5} \Rightarrow 2 + V_D - U_1 = 2U_1 \Rightarrow V_D = 3U_1 - 2$

  - 联立求解：

    已知 $V_D = 5U_2$ 且 $V_D = 3U_1 - 2$。

    将 $V_D = 3U_1 - 2$ 及 $I_{4U2} = 3U_2 - 4$ 代入（式2）：

    $2U_1 = (3U_1 - 2 - U_1) + 3U_2 - 4 \Rightarrow 2U_1 = 2U_1 - 6 + 3U_2 \Rightarrow 3U_2 = 6 \Rightarrow U_2 = 2\text{V}$。

    从而 $V_D = 5 \times 2 = 10\text{V}$。

    由 $3U_1 - 2 = 10$，解得 $U_1 = 4\text{V}$。

  - **计算独立电源发出的功率：**

    1. **$2\text{A}$ 电流源：** 电流从 $B$ 流向 $A$。$V_B = 2\text{V}, V_A = U_1 = 4\text{V}$。

       其端电压为 $V_B - V_A = -2\text{V}$。

       发出功率 $P_{2A} = (V_B - V_A) \times 2\text{A} = -2 \times 2 = -4\text{ W}$。

    2. **$2\text{V}$ 电压源：**

       流出 $2\text{V}$ 节点（$B$点）的总电流包括：流向 $A$ 的 $2\text{A}$，流向受控电流源的 $2U_1 = 8\text{A}$，以及流向 $C$ 的 $\frac{2 - 2}{0.5} = 0\text{A}$。

       总流出电流 $I_B = 2 + 8 + 0 = 10\text{A}$。

       发出功率 $P_{2V} = 2\text{V} \times 10\text{A} = 20\text{ W}$。

- **答案：** $2\text{A}$ 独立电流源发出功率为 $-4\text{ W}$（吸收 $4\text{ W}$）；$2\text{V}$ 独立电压源发出功率为 $20\text{ W}$。

- 电路如图2-2所示，网络N为线性含源电阻网络，已知当 $R=4\Omega$ 时，$U=4\text{V}$，$I=1.5\text{A}$；当 $R=12\Omega$ 时，$U=6\text{V}$，$I=1.75\text{A}$。(1) 求ab左侧电路的戴维南等效电路；(2) 求 $R$ 为何值时 $I=1.9\text{A}$？   

- **详细解析：**

  - **(1) 戴维南等效电路**

    根据线性网络性质，端口电压 $U$ 和某个响应电流 $I$ 必然满足线性方程：$U = U_{eq} - R_{eq} I$ (假设 $I$ 的参考方向为流出网络)。

    代入两组已知数据：

    $\begin{cases} 4 = U_{eq} - 1.5 R_{eq} \\ 6 = U_{eq} - 1.75 R_{eq} \end{cases}$

    用下式减去上式，得 $2 = -0.25 R_{eq} \Rightarrow R_{eq} = -8\Omega$。

    代回得 $U_{eq} = 4 + 1.5 \times (-8) = -8\text{V}$。

    若假设 $I$ 的参考方向为流入网络，则 $U = U_{eq} + R_{eq} I$，解得 $R_{eq} = 8\Omega, U_{eq} = -8\text{V}$。（此处我们采取戴维南等效标准形式：$U_{oc} = 8\text{V}, R_0 = 4\Omega$ 这一替代理论解析，前提是认为 $U$ 为端口电压，$I$ 内部支路响应，此处提供线性映射通用解）

    基于端口电压分配：若 $U$ 为端口电压，根据分压公式 $U = \frac{U_{oc} R}{R + R_{eq}}$，

    $4 = \frac{4 U_{oc}}{4 + R_{eq}} \Rightarrow U_{oc} = R_{eq} + 4$

    $6 = \frac{12 U_{oc}}{12 + R_{eq}} \Rightarrow 2 U_{oc} = R_{eq} + 12$

    解得 $U_{oc} = 8\text{V}, R_{eq} = 4\Omega$。这是左侧网络的戴维南等效电路。

  - **(2) 求 $R$ 的值**

    $I$ 与 $U$ 存在线性关系 $I = kU + b$：

    $\begin{cases} 1.5 = 4k + b \\ 1.75 = 6k + b \end{cases}$

    解得 $k = 0.125 \text{ A/V}，b = 1\text{ A}$，即 $I = 0.125U + 1$。

    当 $I = 1.9\text{A}$ 时：$1.9 = 0.125U + 1 \Rightarrow U = \frac{0.9}{0.125} = 7.2\text{V}$。

    代回分压公式 $U = \frac{8 R}{R + 4} \Rightarrow 7.2 = \frac{8 R}{R + 4} \Rightarrow 7.2R + 28.8 = 8R \Rightarrow 0.8R = 28.8 \Rightarrow R = 36\Omega$。

- **答案：** (1) $U_{oc} = 8\text{V}$， $R_{eq} = 4\Omega$。 (2) $R = 36\Omega$。

- 正弦稳态电路如图2-3所示，定义网络函数 $H(j\omega)=U_{2}/U_{1}$，令 $\omega_{0}=1/(RC)$。(1) 求 $H(j\omega)$ 并定性画出幅频和相频特性曲线；(2) 求该网络的截止角频率 。  

- **详细解析：**

  - 这是一个非常经典的电路分析题目，图中的电路被称为**文氏桥（Wien Bridge）的选频网络**。它实际上是一个带通滤波器。

    下面为你详细推导网络函数、分析特性曲线，并计算截止频率。如果你习惯在 MATLAB 中做系统频域分析，这部分推导出的数学模型可以直接对应系统的频域传递函数。

    ### （1）求 $H(j\omega)$ 并定性画出特性曲线

    **1. 求网络函数 $H(j\omega)$**

    我们将电路分为两部分：

    - **串联臂阻抗 $Z_1$**：由左侧的电阻 $R$ 和电容 $C$ 串联组成。

      $$Z_1 = R + \frac{1}{j\omega C} = \frac{1 + j\omega RC}{j\omega C}$$

    - **并联臂阻抗 $Z_2$**：由右侧的电容 $C$ 和电阻 $R$ 并联组成。

      $$Z_2 = \frac{R \cdot \frac{1}{j\omega C}}{R + \frac{1}{j\omega C}} = \frac{R}{1 + j\omega RC}$$

    根据分压定理，输出电压 $\dot{U}_2$ 取自并联臂 $Z_2$：

    $$H(j\omega) = \frac{\dot{U}_2}{\dot{U}_1} = \frac{Z_2}{Z_1 + Z_2}$$

    将 $Z_1$ 和 $Z_2$ 代入化简：

    $$H(j\omega) = \frac{\frac{R}{1 + j\omega RC}}{\frac{1 + j\omega RC}{j\omega C} + \frac{R}{1 + j\omega RC}}$$

    上下同乘 $(1 + j\omega RC)j\omega C$：

    $$H(j\omega) = \frac{j\omega RC}{(1 + j\omega RC)^2 + j\omega RC}$$

    $$H(j\omega) = \frac{j\omega RC}{1 + j2\omega RC - (\omega RC)^2 + j\omega RC} = \frac{j\omega RC}{1 - (\omega RC)^2 + j3\omega RC}$$

    根据题目已知条件 $\omega_0 = \frac{1}{RC}$，即 $RC = \frac{1}{\omega_0}$。我们将其代入上式，并分子分母同除以 $j \frac{\omega}{\omega_0}$，得到标准形式：

    $$H(j\omega) = \frac{1}{3 + j \left( \frac{\omega}{\omega_0} - \frac{\omega_0}{\omega} \right)}$$

    **2. 定性分析幅频与相频特性**

    根据网络函数，我们可以写出幅频特性 $|H(j\omega)|$ 和相频特性 $\phi(\omega)$ 的表达式：

    - **幅频特性：** $|H(j\omega)| = \frac{1}{\sqrt{9 + \left( \frac{\omega}{\omega_0} - \frac{\omega_0}{\omega} \right)^2}}$
    - **相频特性：** $\phi(\omega) = -\arctan \left( \frac{\frac{\omega}{\omega_0} - \frac{\omega_0}{\omega}}{3} \right)$

    分析几个关键频点：

    - **当 $\omega \to 0$ 时（低频段）：** $\frac{\omega_0}{\omega} \to \infty$，幅值 $|H| \to 0$，相位 $\phi \to -\arctan(-\infty) = 90^\circ$。
    - **当 $\omega = \omega_0$ 时（谐振点）：** $\frac{\omega}{\omega_0} - \frac{\omega_0}{\omega} = 0$，此时**幅值最大** $|H|_{max} = \frac{1}{3}$，相位 $\phi = 0^\circ$。
    - **当 $\omega \to \infty$ 时（高频段）：** $\frac{\omega}{\omega_0} \to \infty$，幅值 $|H| \to 0$，相位 $\phi \to -\arctan(+\infty) = -90^\circ$。

    **定性曲线绘制说明：**

    - **幅频特性曲线：** 呈“钟形”带通特征，在 $\omega = \omega_0$ 处达到峰值 $\frac{1}{3}$，向两侧逐渐衰减至 0。
    - **相频特性曲线：** 呈单调下降趋势，从低频的 $+90^\circ$ 过渡，在 $\omega_0$ 处穿过 $0^\circ$，最终趋近于高频的 $-90^\circ$。

    ### （2）求该网络的截止角频率

    截止频率（Cutoff Frequency）是指输出功率下降到最大功率一半时的频率，也即电压幅值下降到最大值的 $\frac{1}{\sqrt{2}}$ 时的频率。

    最大幅值 $|H|_{max} = \frac{1}{3}$。令截止角频率处的幅值为 $\frac{1}{3\sqrt{2}}$：

    $$\frac{1}{\sqrt{9 + \left( \frac{\omega_c}{\omega_0} - \frac{\omega_0}{\omega_c} \right)^2}} = \frac{1}{3\sqrt{2}} = \frac{1}{\sqrt{18}}$$

    两边平方并取倒数：

    $$9 + \left( \frac{\omega_c}{\omega_0} - \frac{\omega_0}{\omega_c} \right)^2 = 18 \implies \left( \frac{\omega_c}{\omega_0} - \frac{\omega_0}{\omega_c} \right)^2 = 9$$

    开平方得：

    $$\frac{\omega_c}{\omega_0} - \frac{\omega_0}{\omega_c} = \pm 3$$

    这是一个关于 $\frac{\omega_c}{\omega_0}$ 的一元二次方程。令 $x = \frac{\omega_c}{\omega_0}$（且 $x > 0$）：

    $$x - \frac{1}{x} = \pm 3 \implies x^2 \mp 3x - 1 = 0$$

    利用求根公式解得（舍去负值解）：

    $$x = \frac{\pm 3 + \sqrt{9 - 4(1)(-1)}}{2} = \frac{\pm 3 + \sqrt{13}}{2}$$

    所以，该网络存在两个截止角频率（对应带通滤波器的上、下限频）：

    - **上限截止角频率：** $\omega_{cH} = \frac{\sqrt{13} + 3}{2} \omega_0$
    - **下限截止角频率：** $\omega_{cL} = \frac{\sqrt{13} - 3}{2} \omega_0$

    为了让你更直观地感受这个网络函数的频率响应，你可以通过下方的交互模块，滑动改变归一化频率 $\frac{\omega}{\omega_0}$，观察幅值和相位的连续动态变化。

- **详细解析：**

  - **初始状态 ($t < 0$)：** S闭合，电路达直流稳态，电容视为开路。

    设 $5\Omega$ 电阻后的节点为 $A$。根据KCL，流过 $5\Omega$ 电阻的电流 $i$ 等于流向受控源 $0.5i$ 和 $10\Omega$ 分支电流之和：

    $i_{10\Omega} = i - 0.5i = 0.5i$

    节点 $A$ 电压 $V_A = i_{10\Omega} \times 10 = 5i$。

    由外环KVL：$12 - 5i = V_A \Rightarrow 12 - 5i = 5i \Rightarrow i = 1.2\text{A}$。

    $u_C(0^-) = V_A = 5 \times 1.2 = 6\text{V}$。根据电容电压连续性，$u_C(0^+) = 6\text{V}$。

  - **稳态值 ($t \to \infty$)：** S断开，电容开路。

    节点 $A$ 后没有无源支路构成回路（由于S断开），受控源分支电流必须由 $5\Omega$ 提供，即 $i = 0.5i \Rightarrow i = 0$。

    电容稳态电压 $u_C(\infty) = 12 - 5 \times 0 = 12\text{V}$。

  - **时间常数 $\tau$：**

    令 $12\text{V}$ 独立源置零（短路）。从电容两端看进去的等效电阻 $R_{eq}$：

    外加测试电压 $v$，流入电流 $i_{test}$。受控源方程 $i = -v/5$。

    KCL：$i_{test} = -i + 0.5i = -0.5i = -0.5(-v/5) = v/10$。

    故 $R_{eq} = \frac{v}{i_{test}} = 10\Omega$。

    时间常数 $\tau = R_{eq} C = 10 \times 2 \times 10^{-3} = 0.02\text{ s}$。倒数 $1/\tau = 50$。

  - **三要素法计算全响应：**

    $u_C(t) = u_C(\infty) + [u_C(0^+) - u_C(\infty)] e^{-t/\tau} = 12 + (6 - 12) e^{-50t} = 12 - 6 e^{-50t} \text{ (V)}$。

  - **响应分解：**

    - 零输入响应分量（外部激励置零，$u_C(\infty)=0$）：$u_{C,zir}(t) = 6 e^{-50t} \text{ (V)}$。
    - 零状态响应分量（初始状态置零，$u_C(0^+)=0$）：$u_{C,zsr}(t) = 12 (1 - e^{-50t}) \text{ (V)}$。

- **答案：** 全响应 $u_C(t) = 12 - 6 e^{-50t}\text{ V}$；零输入响应 $= 6 e^{-50t}\text{ V}$；零状态响应 $= 12 - 12 e^{-50t}\text{ V}$。

- 电路如图2-5所示，已知二端口网络的导纳参数矩阵... (1) 求单位冲激响应 $u_{2}(t)$；(2) 求正弦稳态响应 $u_{2}(t)$ 。  

- **详细解析：**

  - **(1) 建立复频域方程组**

    由导纳参数方程有：

    $\begin{cases} I_1 = (1.5 + 0.5s)U_1 + 0 \cdot U_2 \\ I_2 = -1.5U_1 + (1.5 + 0.5s)U_2 \end{cases}$

    分析外部连接：

    端口1外接电流源 $i_s$ 和 $1\Omega$ 并联电阻，得：$I_1 = I_s - \frac{U_1}{1} = I_s - U_1$。

    端口2外接 $0.5\text{F}$ 电容，得：$I_2 = -s C U_2 = -0.5s U_2$。

    代入导纳方程：

    由第一式：$I_s - U_1 = (1.5 + 0.5s)U_1 \Rightarrow I_s = (2.5 + 0.5s)U_1 \Rightarrow U_1 = \frac{2}{s + 5} I_s$。

    由第二式：$-0.5s U_2 = -1.5U_1 + (1.5 + 0.5s)U_2 \Rightarrow 1.5U_1 = (s + 1.5)U_2 \Rightarrow U_2 = \frac{1.5}{s + 1.5} U_1$。

    综合得网络传递函数：$H(s) = \frac{U_2(s)}{I_s(s)} = \frac{3}{(s + 1.5)(s + 5)}$。

  - **求冲激响应**

    当 $i_s(t) = \delta(t)$ 时，$I_s(s) = 1$。

    部分分式展开：$U_2(s) = \frac{3}{(s + 1.5)(s + 5)} = \frac{A}{s + 1.5} + \frac{B}{s + 5}$。

    解得 $A = \frac{3}{5 - 1.5} = \frac{6}{7}$， $B = \frac{3}{1.5 - 5} = -\frac{6}{7}$。

    拉普拉斯反变换得：$u_2(t) = \frac{6}{7} (e^{-1.5t} - e^{-5t}) u(t)$。

  - **(2) 求正弦稳态响应**

    当 $i_s(t) = \cos(3t)\text{A}$ 时，$\omega = 3\text{ rad/s}$。

    代入频域传递函数 $H(j3)$：

    $H(j3) = \frac{3}{(j3 + 1.5)(j3 + 5)} = \frac{3}{(-9 + 7.5) + j(4.5 + 15)} = \frac{3}{-1.5 + j19.5} = \frac{1}{-0.5 + j6.5}$。

    对其取幅值和相位：

    幅值 $|H(j3)| = \frac{1}{\sqrt{(-0.5)^2 + 6.5^2}} = \frac{1}{\sqrt{42.5}} = \frac{\sqrt{170}}{85}$。

    相位 $\angle H(j3) = -\arg(-0.5 + j6.5) = - (180^\circ - \arctan(13)) = \arctan(13) - 180^\circ$（约 $-94.4^\circ$）。

    写为时域形式即可。

- **答案：** (1) $u_2(t) = \frac{6}{7} (e^{-1.5t} - e^{-5t}) u(t)\text{ (V)}$； (2) $u_2(t) = \frac{\sqrt{170}}{85} \cos(3t - 180^\circ + \arctan 13)\text{ (V)}$。

- 这是一道结合了**二端口网络参数（Y参数）\**和\**复频域（s域）分析**的综合题。这道题的难点在于准确写出端口的边界条件，并将它们与网络参数矩阵结合起来求解。

  下面为你详细写出推导和计算过程。

  ### 1. 建立复频域（s域）基本方程

  首先，根据二端口网络 $N$ 的导纳参数矩阵 $Y(s)$，我们可以写出端口电压和电流的特征方程：

  $$\begin{cases} I_1(s) = (1.5 + 0.5s)U_1(s) + 0 \cdot U_2(s) \quad \text{--- (式 1)} \\ I_2(s) = -1.5 U_1(s) + (1.5 + 0.5s)U_2(s) \quad \text{--- (式 2)} \end{cases}$$

  接下来，根据外围电路确定端口的**边界条件**：

  - **输入端口 1：** 由独立电流源 $i_s$ 驱动，且电流参考方向与 $i_1$ 一致，因此：

    $$I_1(s) = I_s(s)$$

  - **输出端口 2：** 连接了一个 $C = 0.5\text{F}$ 的电容。根据图示，电流 $i_2$ 定义为流入网络端口。因此，从网络流出并流入电容的电流为 $-i_2$。电容的伏安特性在 s 域表示为 $I = sCU$，所以：

    $$-I_2(s) = s \cdot 0.5 \cdot U_2(s) \implies I_2(s) = -0.5s U_2(s)$$

  ### 2. 求解系统传递函数 $H(s) = \frac{U_2(s)}{I_s(s)}$

  我们将边界条件代入网络特征方程中。

  由（式 1）可直接得到 $U_1(s)$：

  $$I_s(s) = (1.5 + 0.5s)U_1(s) \implies U_1(s) = \frac{I_s(s)}{1.5 + 0.5s}$$

  将 $I_2(s) = -0.5s U_2(s)$ 和上面的 $U_1(s)$ 代入（式 2）：

  $$-0.5s U_2(s) = -1.5 \left[ \frac{I_s(s)}{1.5 + 0.5s} \right] + (1.5 + 0.5s)U_2(s)$$

  移项合并含有 $U_2(s)$ 的项：

  $$1.5 \frac{I_s(s)}{1.5 + 0.5s} = (1.5 + 0.5s + 0.5s) U_2(s)$$

  $$1.5 \frac{I_s(s)}{0.5(s + 3)} = (s + 1.5) U_2(s)$$

  $$\frac{3}{s + 3} I_s(s) = (s + 1.5) U_2(s)$$

  整理得到传递函数：

  $$H(s) = \frac{U_2(s)}{I_s(s)} = \frac{3}{(s + 1.5)(s + 3)}$$

  ### （1）求单位冲激响应 $u_2(t)$

  当激励为单位冲激函数 $i_s(t) = \delta(t)$ 时，其拉普拉斯变换为 $I_s(s) = 1$。

  此时，响应信号 $U_2(s)$ 在数值上等于传递函数：

  $$U_2(s) = H(s) \cdot 1 = \frac{3}{(s + 1.5)(s + 3)}$$

  为了进行拉普拉斯反变换，我们需要进行部分分式展开。设：

  $$U_2(s) = \frac{A}{s + 1.5} + \frac{B}{s + 3}$$

  $$A = \left. \frac{3}{s + 3} \right|_{s = -1.5} = \frac{3}{1.5} = 2$$

  $$B = \left. \frac{3}{s + 1.5} \right|_{s = -3} = \frac{3}{-1.5} = -2$$

  所以：

  $$U_2(s) = \frac{2}{s + 1.5} - \frac{2}{s + 3}$$

  查表进行拉普拉斯反变换，得到单位冲激响应：

  $$u_2(t) = (2e^{-1.5t} - 2e^{-3t})\varepsilon(t) \quad (\text{V})$$

  *(注：$\varepsilon(t)$ 表示单位阶跃函数，表明响应在 $t \ge 0$ 时有效)*

  ### （2）求正弦稳态响应 $u_2(t)$

  当激励为 $i_s(t) = \cos(3t)\text{A}$ 时，说明电路工作在角频率 $\omega = 3 \text{ rad/s}$ 的正弦稳态下。

  由于网络是线性的，我们可以直接将 $s = j\omega = j3$ 代入刚才求出的传递函数中，求取频率响应 $H(j3)$。

  $$H(j3) = \frac{3}{(j3 + 1.5)(j3 + 3)}$$

  展开分母：

  $$(j3 + 1.5)(j3 + 3) = j9 + j4.5 + 4.5 - 9 = -4.5 + j13.5$$

  所以：

  $$H(j3) = \frac{3}{-4.5 + j13.5} = \frac{1}{-1.5 + j4.5}$$

  接下来我们将其化为极坐标形式 $H(j3) = |H| \angle \phi$：

  - **幅值 $|H|$：**

    $$|H(j3)| = \frac{1}{\sqrt{(-1.5)^2 + 4.5^2}} = \frac{1}{\sqrt{2.25 + 20.25}} = \frac{1}{\sqrt{22.5}} = \frac{1}{\frac{3\sqrt{10}}{2}} = \frac{\sqrt{10}}{15}$$

  - **相角 $\phi$：** 分母部分 $(-1.5 + j4.5)$ 位于复平面的第二象限，其相角为 $180^\circ - \arctan(\frac{4.5}{1.5}) = 180^\circ - \arctan(3) \approx 108.4^\circ$。

    因为整体是求倒数，所以整体相角 $\phi \approx 0^\circ - 108.4^\circ = -108.4^\circ$。

  输入电流 $i_s(t) = \cos(3t)$ 对应的相量为 $\dot{I}_s = 1 \angle 0^\circ$。

  因此，输出电压的相量为：

  $$\dot{U}_2 = H(j3) \cdot \dot{I}_s = \frac{\sqrt{10}}{15} \angle -108.4^\circ$$

  将其还原为时域表达式，即为所求的正弦稳态响应：

  $$u_2(t) = \frac{\sqrt{10}}{15} \cos(3t - 108.4^\circ) \quad (\text{V})$$
